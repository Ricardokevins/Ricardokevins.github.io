量化面试基础：概率统计与机器学习系统速学

把题目归回少量可迁移的模型。先理解一个数值例子，再手推公式，最后检查条件和反例。

这套教材解决什么问题

量化面试的数学题和模型题看起来很多，但反复出现的动作不多：根据信息更新概率、按状态写递推、用样本反推未知参数、给结论附上不确定性、在未来数据上检验预测。已有量化题库提供大量完整题目；本套基础教材补上这些题目共享的推导和概念依赖，帮助你在换题面时找到同一工具。

例如等待HH、赌徒破产与骰子重掷都能用状态与首步分析；线性回归、条件高斯与平方损失都围绕“最佳均方预测”；贝叶斯先验、岭回归与模型稳定性则由收缩联系在一起。按这些连接学习，比孤立背44条公式更容易迁移。

两本教材，44 个带解答的知识单元

概率论与数理统计 · 24 个可迁移模型

条件概率与计数 → 指标变量与等待 → 递推、随机游走与停时 → 极值与高斯 → 极限定理 → MLE/MAP → 区间、检验与bootstrap → 时间序列与执行。

机器学习理论 · 20 条主线

任务与损失 → 线性/逻辑回归 → 正则与优化 → 树、森林与boosting → PCA/SVM/贝叶斯 → 时间验证与泄漏 → 神经网络、EM与泛化 → 完整研究流程。

三轮学习：先形成模型，再补细节

如果概率、导数或矩阵已经忘了，先读概率统计的数学先修：Σ/Π、条件概率、期望方差、导数积分与log，再读机器学习的数学先修：向量矩阵、投影、特征值与梯度。两本PDF各自包含必要先修；每节也在例子前解释会用到的关键术语。先顺着一个数值例子读到底，再回看公式，不需要先查外链。

第一轮 · 识别工具

概率统计先读01、04、05、08、15、18、19；机器学习先读01、02、03、04、05、13、14。目标是看到题目后，说出随机变量、目标、第一步与假设。

第二轮 · 手推最小例子

用纸笔推HH等待6步、赌徒破产21步、Beta后验9/14、逻辑回归梯度p−y、ridge解、随机森林方差0.208。每题换一个数字重新算，避免把数字记忆当作方法掌握。

第三轮 · 用反例检查迁移

把独立改成相关、有限方差改成重尾、固定样本改成停时、随机划分改成时间部署。能指出失效的是哪一步，并提出替代验证，才算完成这一轮。

跨章节连接：少记公式，多认结构

  • 条件化：贝叶斯更新 → 全期望 → 条件高斯 → 监督学习条件均值。
  • 状态压缩：序列等待 → 赌徒破产 → 最优停止 → 动态规划。
  • 收缩：先验 → MAP → L2/L1 → 降低估计方差。
  • 相关性：组合方差 → 有效样本量 → 集成误差 → 时间验证。
  • 选择后的证据：p值 → 多重比较 → 模型搜索 → 冻结测试与前瞻评估。

证据边界与资料索引

选题依据是官方公开的能力方向与课程知识依赖，不是真题频率统计。Jane Street公开指南明确涉及概率、期望与做市；Citadel研究FAQ列出概率统计、数据分析、预测模型和编程。交易、研究、ML岗位的侧重点不同，这套教材不承诺所有岗位考同一内容。

  • Jane Street · Probability & Markets：官方明确列出概率、期望与做市等基础准备方向；不等于每一道题都会考。
  • Jane Street · Interviewing：区分交易、研究与机器学习面试，研究与交易及工程能力交叉。
  • Citadel · Quantitative Research FAQ：明确概率统计、数据分析、预测模型与编程能力。
  • Citadel · QR interview process：强调编程、研究、数据结构算法与解释解题过程。
  • MIT 6.041SC：概率系统与推断课程。
  • Stanford CS229：机器学习原始课程讲义。
  • ISL作者官网：统计学习教材与章节。

例题、数值与推导为独立教学整理。数学结论按每节假设使用；预测评价须经过执行与成本才能成为净收益证据。
