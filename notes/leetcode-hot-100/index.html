1. 变量、条件与循环：程序怎样一步步执行

total = 0 是把变量total设为0，total += 2 等同于 total = total + 2。if x > 0: 后缩进的代码只在条件成立时执行；== 判断相等，单个 = 则是赋值。and 要求两条件都真，or 要求至少一个真，not 取反。

nums = [2, 7, 11]
total = 0
for i, x in enumerate(nums):
    total += x
# 三轮分别是 (i,x,total)=(0,2,2)、(1,7,9)、(2,11,20)

enumerate 同时给下标i和元素x；range(1,4) 依次给1、2、3，右端4不包含。while 条件: 只要条件仍真就重复，因此循环体必须让状态朝结束方向改变。break 退出当前循环，continue 跳过本轮剩余代码，return 则立即结束整个函数并交回答案。a,b=b,a+b 的右边先用旧值计算，再同时赋值，不会先改a再算b。

2. 列表、字典和集合：分别解决什么问题

列表 list 是有顺序的一排元素，a=[3,1,3] 保留两个3。a.append(5) 尾部追加，a.pop() 删除并返回末项；len(a) 求长度。a[l:r] 复制下标l到r之前的元素，故 a[0:2] 得到 [3,1]，复制多少项就花多少时间和空间。写成区间[l,r)同样表示含左端l、不含右端r，称“半开区间”；[l,r]则两端都含。sorted(a) 返回新排序列表，a.sort() 则修改原列表。

字典 dict 是“键→值”的查询表。seen={2:0,7:1} 表示值2曾在下标0、值7曾在下标1；seen[7] 得1，7 in seen 判断是否有键7，seen.get(11,0) 在键不存在时给默认0。这种默认值常用于计数：count[x]=count.get(x,0)+1。键必须能稳定散列，列表不能直接作键，可改用不允许修改的 tuple（元组）。

集合 set 只回答“在不在”，不记录重复次数。set([3,1,3]) 只有1和3两个成员；add 加成员、remove 删成员。哈希指把键计算成存储位置的办法，字典与集合借它跳到少量候选处，所以平均查询近似一步；若只用列表逐项找，则可能检查整排。需要“出现几次”用字典，需要“出现过没有”才用集合。

字符串可像列表一样按下标读取或切片，但不能执行 s[0]='a' 原地改字符。''.join(parts) 把若干字符串连接起来；ord('a') 为97，所以小写字母c用 ord(c)-97 映射到0至25的计数槽位。Counter 是标准库提供的计数字典，未出现的键读取为0；bisect_left 用二分找第一个大于等于目标的位置；heapq 提供堆，含义在堆章节说明。from collections import Counter 是取用库中已有工具，不是本题另藏一段推导。

列表推导 [x*2 for x in [1,3]] 是“对每项算一次再收集”，得 [2,6]；[0]*3 得三个0。二维表用 [[0]*3 for _ in range(2)] 新建两行，变量 _ 表示本轮序号用不上；不要写 [[0]*3]*2，后者让两行指向同一列表，改第一行会连第二行一起改。a[-1] 读末项；某下标可能是-1时要先判断边界，不能误把不存在的前驱当末项。

3. 引用、链表与树：为什么值一样不等于同一个结点

列表变量指向一个对象：a=[1,2]; b=a 后两变量指向同一列表，改 b[0]=9 会让a也变成 [9,2]；b=a.copy() 才新建外层列表。回溯记录答案用 path.copy()，是为了留下当前内容，而非一直指向正在变化的同一条path。

链表是一串结点对象，每个有 val 存数、next 指向下一个，末尾指向 None（没有对象）。对 1→2→3，变量cur若指着2，则 cur.next 指着3；把 cur.next=None 会断开通往3的链接。反转前先用nxt保存原后继，就不会找不到剩余链。a is b 问是否同一对象；两个分别新建的值8结点并不相交。

树把每个结点的后继改为 left 与 right 两个孩子；root是起点“根”，没有孩子的结点叫叶结点。parent是某结点的直接上层，祖先则包括更远上层。子树是某结点连同其所有后代。BST指二叉搜索树：左子树所有值比根小，右子树所有值比根大，后面的验证题会解释为何仅比较直接孩子还不够。

class 定义一类对象，把一份数据与操作它的函数放在一起。cache = LRUCache(2) 建立一个容量2的实例，初始化函数 __init__ 会运行；self.data 表示“这一个缓存自己的data”，另一个缓存有另一份。cache.get(1) 调用方法时，Python自动把cache作为self传进去；普通函数不用self。node.next 同样只是读取这个对象里名为next的字段。

4. 函数、递归、栈与队列：暂存的到底是什么

def f(x): 定义函数，参数是本次输入，return y 把结果交给调用者。递归是函数把更小的同类问题交给自己，例如树高 height(node)=1+max(height(left),height(right))。到空结点时必须返回0，这个不再继续调用的条件叫“递归出口”。执行父结点时，程序会先等孩子返回，不能凭空同时知道所有子树答案。

栈 像叠盘子，最后放的最先取。求只有根2、左孩子1的树高时，根的调用先暂存“等左边答案”，孩子又暂存自己的现场；空孩子返回0后，孩子算出1交给根，根再算出2。程序保存这些未完成调用的地方是调用栈。nonlocal best 允许内部函数更新外层变量best，常用于“递归返回一条路径，同时更新整棵树答案”。

队列 像排队买票，最先进入的最先出去。deque.append(x) 加到尾部，deque.popleft() 从头取出，适合一层层处理树或图；双端队列 还允许从尾部 pop() 删除。不要把栈、队列与递归当成三个新算法，它们首先是不同的待办顺序：最新的先做，或最早的先做。

5. 状态、不变量与动态规划：把术语换成可以检查的话

状态 是“此刻记住哪些信息，就足以继续计算”。例如当前读到第3项、此前总和5，便可用5继续加下一项；不必把前三项反复重加。不变量 是“每轮开始或结束都保证成立的事实”。移动零时可说“写指针w之前恰好存着已读到的全部非零数”，每写入一项就检查它仍成立；它用来解释代码为什么不会漏、乱或重复。

动态规划（DP） 把相同的小问题答案存起来，让大问题直接复用。比如到第4阶的最后一步，要么从第3阶走1步，要么从第2阶走2步，因此 f[4]=f[3]+f[2]。这里“状态”是到第i阶的方案数f[i]，“转移”是由旧答案算新答案的规则；“初始化”给最小问题答案。滚动数组 只是当新答案仅依赖前两项时，只保留那两项而不保存整张表，并非另一种推导。

6. 大 O：看输入扩大后，操作次数怎样增长

n表示输入规模，例如数组长度。读 nums[3] 不必扫描前3项，访问次数不随n增长，记 O(1)。从头扫描一次需约n步，记 O(n)；两层各枚举n项共约n²对，记 O(n²)。输入从100变1000，一次扫描约放大10倍，枚举所有数对约放大100倍；这比纠结某一步多一次加法更重要。

每次排除一半候选：1024→512→…→1，仅10轮，这种增长记 O(log n)，本书对数可按以2为底理解。排序通常约 O(n log n)；枚举每项选/不选共有 2^n 种；排列n个不同数共有 n! 种（例如4!=4×3×2×1=24）。若输出本来就有这些数量，算法无法凭空省掉写出答案的代价。

额外空间 看除输入与返回结果外，运行时还保留多少东西。两个指针用常量空间，复制n项的列表要O(n)，递归同时挂起h层调用要O(h)。两次顺序扫描是2n，仍记O(n)；嵌套while也未必O(n²)，如果每项总共只进栈一次、出栈一次，合计仍只有约2n次。字典的O(1)通常是平均情形；Python大整数的位数变长后，算术本身也会更贵。

LC 1 两数之和

题意：返回数组中两个不同下标，使对应数之和等于 target。题目保证恰有一解。

推导与核心思路：固定当前数 x 后，唯一需要寻找的是 target-x；用字典保存此前数值到下标。

走一遍：[2,7,11,15], target=9 → [0,1]；读到 7 时，字典已有 2。

具体步骤

  1. 从左到右枚举 i,x
  2. 先查询 target-x，存在就返回两个下标
  3. 查询后才存 x，确保不会用同一个元素两次

Python 实现

def twoSum(nums, target):
    seen = {}
    for i, x in enumerate(nums):
        if target - x in seen:
            return [seen[target - x], i]
        seen[x] = i

复杂度：时间 O(n)，额外空间 O(n)。

易错点与适用边界：[3,3], target=6 需要两个不同位置；先存后查会错误地匹配自己。

LC 49 字母异位词分组

题意：把只因字母排列不同的字符串放在同一组，组的顺序不限。

推导与核心思路：把字符串排序成同一个规范键；相同键对应相同的字母多重集合。

走一遍：["eat","tea","tan","ate"] → [["eat","tea","ate"],["tan"]]。

具体步骤

  1. 为每个单词建立排序后字符串键
  2. 把原单词加入该键的列表
  3. 最后取所有组

Python 实现

def groupAnagrams(strs):
    groups = {}
    for s in strs:
        key = ''.join(sorted(s))
        groups.setdefault(key, []).append(s)
    return list(groups.values())

复杂度：总字符数 L、最长词长 k：时间 O(L log k)，空间 O(L)。

易错点与适用边界：不能用字符集合做键，因为 ab 与 aab 的重复次数不同；空串也必须保留。

LC 128 最长连续序列

题意：无序整数数组中，求数值连续序列的最长长度，不要求原数组相邻。

推导与核心思路：只有没有前驱 x-1 的数才是序列起点；从起点扩张，每个唯一元素只被向后扫描一次。

走一遍：[100,4,200,1,3,2] → 4；只从 1 开始扫描 1,2,3,4。

具体步骤

  1. 去重成集合
  2. 枚举集合中的 x，若 x-1 存在则跳过
  3. 否则从 x 不断找 x+1 并更新长度

Python 实现

def longestConsecutive(nums):
    values = set(nums)
    best = 0
    for x in values:
        if x - 1 not in values:
            y = x
            while y in values:
                y += 1
            best = max(best, y - x)
    return best

复杂度：平均时间 O(n)，空间 O(n)。

易错点与适用边界：必须遍历去重集合；若遍历带大量重复起点的原数组，可能退化为 O(n²)。

02 · 双指针：利用顺序排除候选

先把这类话说懂：这里“指针”通常只是一个下标变量，不是必须掌握的底层内存地址。相向指针从两端向中间走，例如l=0、r=5；同向指针都朝右，一个负责读取、一个负责写入。一次移动必须能说明：被丢掉的候选为什么不会更好。

LC 283 移动零

题意：原地把 0 移到末尾，非零元素相对顺序不变。

推导与核心思路：写指针 w 之前恰好是已经扫描到的全部非零元素。

走一遍：[0,1,0,3,12] → 原数组变成 [1,3,12,0,0]。

具体步骤

  1. 扫描每个 x，非零就写到 nums[w] 并推进 w
  2. 扫描后把 [w,n) 填 0

Python 实现

def moveZeroes(nums):
    w = 0
    for x in nums:
        if x != 0:
            nums[w] = x
            w += 1
    for i in range(w, len(nums)):
        nums[i] = 0

复杂度：时间 O(n)，额外空间 O(1)。

易错点与适用边界：不要边遍历边删除；本实现逐元素赋值，额外空间 O(1)。

LC 11 盛最多水的容器

题意：选两条竖线，与横轴组成容器，求最大容量；中间的线不影响容量。

推导与核心思路：面积由较短边和距离决定。固定短边、缩短距离不可能变好，所以舍弃短边是安全的。

走一遍：[1,8,6,2,5,4,8,3,7] → 49，由下标 1 和 8 的线组成。

具体步骤

  1. 左右端初始化
  2. 计算 min(height[l],height[r])*(r-l)
  3. 移动较短的一端并重复

Python 实现

def maxArea(height):
    l, r, best = 0, len(height) - 1, 0
    while l < r:
        best = max(best, min(height[l], height[r]) * (r - l))
        if height[l] <= height[r]:
            l += 1
        else:
            r -= 1
    return best

LC 15 三数之和

题意：返回和为 0 的不重复三元组，三元组内部顺序不限。

推导与核心思路：排序后固定第一个数，剩余两数和可用相向指针，数值过小左移大、过大右移小。

走一遍：[-1,0,1,2,-1,-4] → [[-1,-1,2],[-1,0,1]]。

具体步骤

  1. 排序并枚举 i，跳过重复首数
  2. 在 i+1 到末尾双指针求 -nums[i]
  3. 命中时记录并越过两端重复值

Python 实现

def threeSum(nums):
    nums = sorted(nums)
    ans = []
    for i in range(len(nums) - 2):
        if i and nums[i] == nums[i - 1]:
            continue
        l, r = i + 1, len(nums) - 1
        while l < r:
            total = nums[i] + nums[l] + nums[r]
            if total < 0:
                l += 1
            elif total > 0:
                r -= 1
            else:
                ans.append([nums[i], nums[l], nums[r]])
                a, b = nums[l], nums[r]
                while l < r and nums[l] == a:
                    l += 1
                while l < r and nums[r] == b:
                    r -= 1
    return ans

复杂度：时间 O(n²)，排序空间 O(n)（Python 排序最坏），结果另计。

易错点与适用边界：去重按数值，不是按下标；同一三元组中的两个 0 仍可以来自不同位置。

题意：每根柱宽为 1，下雨后所有凹槽共能积多少水。

def trap(height):
    l, r = 0, len(height) - 1
    left = right = ans = 0
    while l <= r:
        left = max(left, height[l])
        right = max(right, height[r])
        if left <= right:
            ans += left - height[l]
            l += 1
        else:
            ans += right - height[r]
            r -= 1
    return ans

LC 560 和为 K 的子数组

题意：整数数组中，统计和为 k 的非空连续子数组数量；允许负数。

推导与核心思路：若当前前缀和为 total，要找的旧前缀和就是 total-k；存出现次数而非单一位置。

走一遍：[1,1,1], k=2 → 2；两个位置不同的 [1,1]。

把关键状态走完

  1. 对[1,1,1]、k=2，初始freq={0:1}、total=0、ans=0。读第一项后total=1，要找旧前缀-1，没有；把前缀1记一次。读第二项后total=2，要找旧前缀0，有1次，所以ans=1；再记前缀2。读第三项后total=3，找前缀1，有1次，所以ans=2。
  2. 为何存“次数”而非仅存在性？[0,0]、k=0中，读第一项前旧前缀0有1次，产生1条；读第二项前旧前缀0已有2次，产生2条，共3条。当前前缀必须在查询后才加入，否则会把“当前减当前”的空区间也算进去。

具体步骤

  1. 设空前缀和 0 出现 1 次
  2. 每读一个数更新 total
  3. 先累加 freq[total-k]，再记录 total

Python 实现

def subarraySum(nums, k):
    freq = {0: 1}
    total = ans = 0
    for x in nums:
        total += x
        ans += freq.get(total - k, 0)
        freq[total] = freq.get(total, 0) + 1
    return ans

复杂度：平均时间 O(n)，空间 O(n)。

易错点与适用边界：先记录当前前缀会在 k=0 时计入空子数组；负数使普通滑动窗口失效。

LC 239 滑动窗口最大值

题意：返回每个长度为 k 的连续窗口的最大值。

推导与核心思路：双端队列存下标，数值从队首到队尾递减；新数更大时，旧的小数更早过期且永远不会再是最大值。

走一遍：[1,3,-1,-3,5,3,6,7], k=3 → [3,3,5,5,6,7]。

把关键状态走完

  1. 对[1,3,-1,-3,5]、k=3，队列存下标。读下标0的1得到[0]；读下标1的3，1更小且比3更早离窗，以后不可能赢过3，所以弹0，队列变[1]；读下标2的-1得到[1,2]，窗口[1,3,-1]最大值取nums[1]=3。
  2. 读下标3的-3得到[1,2,3]，最大仍3。读下标4时，下标1已经不在窗口[2,4]，先从队首删除；新5又使尾部-3、-1都失去竞争力，全部弹出，再加4，队列只剩[4]，答案变5。队列里不是整个窗口，只是仍可能当最大值的候选。

具体步骤

  1. 先删除过期队首
  2. 弹出小于等于新值的队尾
  3. 压入当前下标，窗口成形后读队首

Python 实现

def maxSlidingWindow(nums, k):
    from collections import deque
    candidates, ans = deque(), []
    for i, x in enumerate(nums):
        while candidates and candidates[0] <= i - k:
            candidates.popleft()
        while candidates and nums[candidates[-1]] <= x:
            candidates.pop()
        candidates.append(i)
        if i >= k - 1:
            ans.append(nums[candidates[0]])
    return ans

复杂度：时间 O(n)，空间 O(k)。

易错点与适用边界：必须存下标才能判断过期；每个下标最多入队出队各一次，嵌套 while 仍为线性。

LC 76 最小覆盖子串

题意：在 s 中找包含 t 全部字符及其重复次数的最短子串，不存在返回空串。

推导与核心思路：need 保存尚缺数量，missing 保存尚缺的字符总数；右端扩张到覆盖后，左端尽可能收缩。

走一遍：s="ADOBECODEBANC", t="ABC" → "BANC"。

把关键状态走完

  1. 用较短的s="AABBC"、t="ABC"亲手走：初始need={A:1,B:1,C:1}、missing=3。读第一个A后need[A]=0、missing=2；再读A后need[A]=-1、missing仍2，这个负数的意思是“多了一个A”，并非缺少负一个字符。
  2. 接着读B，missing变1；第二个B只是多余；读到C时missing=0，窗口AABBC已覆盖。先记长度5。移出第一个多余A，need[A]由-1变0，仍然覆盖，所以继续缩，记录ABBC长度4。再移出A，need[A]由0变1，missing变1，说明再缩就缺A；停止收缩，最终返回ABBC。
  3. while missing==0不是“多跑几次碰运气”，而是在右端固定时找最靠右的合法左端。内层看似嵌套，但left最多从0走到n，每个字符最多入窗和出窗一次，总时间仍线性。

具体步骤

  1. 右端加入字符，若尚缺则 missing 减一
  2. 当 missing=0 时记录当前窗口
  3. 移出左字符，若使某字符重新短缺则停止收缩

Python 实现

def minWindow(s, t):
    from collections import Counter
    if not t:
        return ''
    need = Counter(t)
    missing, left = len(t), 0
    start, best = 0, len(s) + 1
    for right, c in enumerate(s):
        if need[c] > 0:
            missing -= 1
        need[c] -= 1
        while missing == 0:
            if right - left + 1 < best:
                start, best = left, right - left + 1
            old = s[left]
            need[old] += 1
            if need[old] > 0:
                missing += 1
            left += 1
    return '' if best > len(s) else s[start:start + best]

复杂度：时间 O(len(s)+len(t))，空间 O(字符集大小)。

易错点与适用边界：t="AA" 需要两个 A；覆盖种类数与覆盖字符总数不是一回事。

def rotate(nums, k):
    if not nums:
        return
    def reverse(l, r):
        while l < r:
            nums[l], nums[r] = nums[r], nums[l]
            l += 1
            r -= 1
    k %= len(nums)
    reverse(0, len(nums) - 1)
    reverse(0, k - 1)
    reverse(k, len(nums) - 1)

复杂度：时间 O(n)，额外空间 O(1)。

LC 41 缺失的第一个正数

题意：在 O(n) 时间、O(1) 额外空间内找未出现的最小正整数。

推导与核心思路：长度 n 的数组答案只可能在 1..n+1；将值 x 放到槽位 x-1，数组自己充当哈希表。

走一遍：[3,4,-1,1] 归位后 [1,-1,3,4] → 2。

把关键状态走完

  1. 对[3,4,-1,1]，下标0读到3：3应放下标2，交换得[-1,4,3,1]；当前位置现在是-1，不在1..4，无需再处理。下标1读到4，与下标3交换得[-1,1,3,4]。
  2. 仍停在下标1，因为交换过来的1还没放对；再与下标0交换得[1,-1,3,4]。最后从左检查，1在槽0正确，槽1本应是2却为-1，所以缺2。条件nums[nums[i]-1]!=nums[i]避免[1,1]把两个相同值交换到永远。
  3. 虽然每个i里有while，每一次真正交换至少把一个数送到它自己的最终槽位，最多n个这样的槽，所以交换总量O(n)，不是每个i都各交换n次。

具体步骤

  1. 扫描 i，只要 nums[i] 在 1..n 且目标槽不是相同值就交换
  2. 交换后继续检查当前位置
  3. 最后找首个 nums[i]≠i+1 的位置

def firstMissingPositive(nums):
    n = len(nums)
    for i in range(n):
        while 1 <= nums[i] <= n and nums[nums[i] - 1] != nums[i]:
            j = nums[i] - 1
            nums[i], nums[j] = nums[j], nums[i]
    for i, x in enumerate(nums):
        if x != i + 1:
            return i + 1
    return n + 1

复杂度：时间 O(n)，额外空间 O(1)。

def setZeroes(matrix):

    row0 = any(x == 0 for x in matrix[0])

    for i in range(1, m):

            if matrix[i][j] == 0:
                matrix[i][0] = matrix[0][j] = 0
    for i in range(1, m):

LC 54 螺旋矩阵

题意：按顺时针由外向内输出矩阵元素。

推导与核心思路：维护尚未访问的上、下、左、右四条边，每走完一条就收缩对应边界。

走一遍：[[1,2,3],[4,5,6],[7,8,9]] → [1,2,3,6,9,8,7,4,5]。

具体步骤

  1. 依次走上边、右边
  2. 确认仍有行后走下边
  3. 确认仍有列后走左边，再循环

Python 实现

def spiralOrder(matrix):
    top, bottom, left, right = 0, len(matrix) - 1, 0, len(matrix[0]) - 1
    ans = []
    while top <= bottom and left <= right:
        for j in range(left, right + 1):
            ans.append(matrix[top][j])
        top += 1
        for i in range(top, bottom + 1):
            ans.append(matrix[i][right])
        right -= 1
        if top <= bottom:
            for j in range(right, left - 1, -1):
                ans.append(matrix[bottom][j])
            bottom -= 1
        if left <= right:
            for i in range(bottom, top - 1, -1):
                ans.append(matrix[i][left])
            left += 1
    return ans

复杂度：时间 O(mn)，除输出空间 O(1)。

LC 234 回文链表

题意：判断单链表的结点值序列是否为回文。

推导与核心思路：快慢指针定位后半段；反转后半段后，两端即可同时向中间比较。

走一遍：1→2→2→1 → True；比较后仍保持原链。

具体步骤

  1. 快指针每次两步、慢指针一步
  2. 原地反转慢指针后的半段
  3. 比较，最后再反转回来恢复链表

Python 实现

def isPalindrome(head):
    if not head or not head.next:
        return True
    def rev(node):
        prev = None
        while node:
            nxt = node.next
            node.next = prev
            prev, node = node, nxt
        return prev
    slow = fast = head
    while fast.next and fast.next.next:
        slow, fast = slow.next, fast.next.next
    half = rev(slow.next)
    a, b, ok = head, half, True
    while b:
        if a.val != b.val:
            ok = False
        a, b = a.next, b.next
    slow.next = rev(half)
    return ok

易错点与适用边界：只比较后半段长度；奇数长度的中点不影响；不要提前 return 而忘记恢复原链。

def mergeKLists(lists):
    import heapq
    from itertools import count
    serial, heap = count(), []
    for node in lists:
        if node:
            heapq.heappush(heap, (node.val, next(serial), node))
    dummy = tail = ListNode(0)
    while heap:
        _, _, node = heapq.heappop(heap)
        tail.next = node
        tail = node
        if node.next:

  1. 把循环哨兵记为R。容量2时初始R↔R；put(1,10)后R↔1↔R；put(2,20)后R↔1↔2↔R，左端1最久没用、右端2最新。字典data[1]直接指向结点1，所以get(1)不必从链头搜索。
  2. get(1)先_remove：把1的前驱R的next改到2，把2的prev改到R；再_recent把1接在末尾，得到R↔2↔1↔R。现在put(3,30)得到R↔2↔1↔3↔R，超过容量便删除R.next，也就是2，同时del data[2]。再get(2)才会正确返回-1。
  3. R的值不属于缓存，存在意义是统一首尾操作。删除/移动一个已知结点只改固定几个引用，所以O(1)；若用列表remove(1)，必须先找位置再搬移后续元素，就会随容量增长。

具体步骤

  1. get 命中后摘下结点并接到末尾
  2. put 新写或更新都移到末尾
  3. 超容量时删除 root.next，同时删除其字典项

Python 实现

class LRUCache:
    class _Link:
        def __init__(self, key=None, value=None):
            self.key, self.value = key, value
            self.prev = self.next = self

    def __init__(self, capacity):
        self.capacity = capacity
        self.data = {}
        self.root = self._Link()

    def _remove(self, node):
        node.prev.next = node.next
        node.next.prev = node.prev

    def _recent(self, node):
        tail = self.root.prev
        tail.next = node
        node.prev = tail
        node.next = self.root
        self.root.prev = node

    def get(self, key):
        if key not in self.data:
            return -1
        node = self.data[key]
        self._remove(node)
        self._recent(node)
        return node.value

    def put(self, key, value):
        if key in self.data:
            node = self.data[key]
            node.value = value
            self._remove(node)
        else:
            node = self._Link(key, value)
            self.data[key] = node
        self._recent(node)
        if len(self.data) > self.capacity:
            oldest = self.root.next
            self._remove(oldest)
            del self.data[oldest.key]

复杂度：get/put 平均 O(1)，空间 O(capacity)。

易错点与适用边界：更新已有键也算使用；双向连接要成对修改；淘汰时字典与链表必须同时移除，否则会保留失效结点。

def inorderTraversal(root):
    stack, ans, cur = [], [], root
    while cur or stack:
        while cur:
            stack.append(cur)
            cur = cur.left
        cur = stack.pop()
        ans.append(cur.val)
        cur = cur.right
    return ans

def isSymmetric(root):
    def mirror(a, b):
        if not a or not b:
            return a is b
        return (a.val == b.val and mirror(a.left, b.right)
                and mirror(a.right, b.left))

LC 543 二叉树的直径

题意：求任意两个结点之间最长路径的边数，路径可以不经过根。

推导与核心思路：左右子树高度之和就是经过当前结点的最长路径边数；递归返回值只保留一边高度。

走一遍：[1,2,3,4,5] → 3，路径 4→2→1→3。

具体步骤

  1. 后序取得 left/right 高度
  2. 更新 best=max(best,left+right)
  3. 返回 1+max(left,right)

Python 实现

def diameterOfBinaryTree(root):
    best = 0
    def height(node):
        nonlocal best
        if not node:
            return 0
        left, right = height(node.left), height(node.right)
        best = max(best, left + right)
        return 1 + max(left, right)
    height(root)
    return best

复杂度：时间 O(n)，空间 O(h)。

易错点与适用边界：直径按边数、高度按结点数，这里 left+right 已是边数，不再加 1。

LC 102 二叉树的层序遍历

题意：逐层从左到右输出结点值，每层单独一个列表。

推导与核心思路：处理本层前固定队列长度，新加入孩子留给下一层。

走一遍：[3,9,20,None,None,15,7] → [[3],[9,20],[15,7]]。

具体步骤

  1. 根入队
  2. 每轮读取 len(queue) 次
  3. 出队记录值并按左右顺序入队孩子

Python 实现

def levelOrder(root):
    from collections import deque
    queue = deque([root]) if root else deque()
    ans = []
    while queue:
        level = []
        for _ in range(len(queue)):
            node = queue.popleft()
            level.append(node.val)
            if node.left:
                queue.append(node.left)
            if node.right:
                queue.append(node.right)
        ans.append(level)
    return ans

复杂度：时间 O(n)，空间 O(w)，w 为最大层宽，输出另计。

易错点与适用边界：不能在本层循环中动态改变终止长度；list.pop(0) 会产生线性搬移，改用 deque。

def sortedArrayToBST(nums):
    def build(l, r):
        if l >= r:
            return None
        mid = (l + r) // 2
        root = TreeNode(nums[mid])
        root.left = build(l, mid)
        root.right = build(mid + 1, r)
        return root

LC 437 路径总和 III

题意：统计所有从某结点向下延伸、和值为 targetSum 的非空路径，不要求从根开始。

推导与核心思路：根到当前结点的前缀和减某祖先前缀和等于目标，复用一维前缀和计数。

走一遍：[10,5,-3,3,2,None,11,3,-2,None,1], target=8 → 3。

把关键状态走完

  1. 沿10→5→3这一支，前缀和依次10、15、18。目标8时，到结点3便查询18-8=10；祖先前缀10出现过一次，减掉它，留下5→3这一条和8的路径。counts={0:1}中的空前缀使“从根就开始”的路径也能被同样规则统计。
  2. 退出结点3时把counts[18]减回去，再去兄弟分支。字典应只记录“当前结点的祖先链”，不是此前访问过的所有结点；否则另一支某个前缀恰好差8，会被错误地拼成跨树枝路径。递归返回的是该子树中合格路径的条数，不是前缀和本身。

具体步骤

  1. 维护当前递归路径的前缀计数，初始 {0:1}
  2. 到结点先查询 total-target
  3. 加入当前前缀，递归左右，退出时减回

Python 实现

def pathSum(root, targetSum):
    counts = {0: 1}
    def visit(node, total):
        if not node:
            return 0
        total += node.val
        ans = counts.get(total - targetSum, 0)
        counts[total] = counts.get(total, 0) + 1
        ans += visit(node.left, total) + visit(node.right, total)
        counts[total] -= 1
        return ans
    return visit(root, 0)

复杂度：平均时间 O(n)，空间 O(h)。

易错点与适用边界：回溯减计数必不可少，否则会把另一分支的前缀当作祖先；先查后加避免空路径。

LC 124 二叉树中的最大路径和

题意：求任意非空简单路径的最大结点和值，路径不必经过根。

推导与核心思路：负贡献可以舍弃；经过当前根的答案可连接左右两边，但向父亲返回时只能选一边。

走一遍：[-10,9,20,None,None,15,7] → 42，路径 15→20→7。

把关键状态走完

  1. 对根-10、左9、右20，且20的孩子为15与7这棵树，叶子15向父结点返回15，叶子7返回7。处理20时，完整路径15→20→7得到42，更新best=42；但向-10只能返回20+max(15,7)=35。
  2. 为什么不能向父结点返回42？因为42已用了20的左右两条边；再连到-10，会在20出现三条岔路，已经不是一条简单路径。处理-10时完整候选为-10+9+35=34，向上返回25，但全树最大仍是之前的42。
  3. 若只一个结点-3，左右贡献都是0，完整候选是-3，结果必须-3；这就是best从负无穷开始，而不是允许选一条得0的空路径。

具体步骤

  1. 递归得到左右非负贡献
  2. 用 val+left+right 更新 best
  3. 返回 val+max(left,right)

def maxPathSum(root):
    best = float('-inf')
    def gain(node):
        nonlocal best
        if not node:
            return 0
        left = max(0, gain(node.left))
        right = max(0, gain(node.right))
        best = max(best, node.val + left + right)
        return node.val + max(left, right)
    gain(root)
    return best

def numIslands(grid):
    if not grid:
        return 0
    m, n, ans = len(grid), len(grid[0]), 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] != '1':
                continue
            ans += 1
            grid[i][j] = '0'
            stack = [(i, j)]
            while stack:
                r, c = stack.pop()
                for a, b in ((r-1,c),(r+1,c),(r,c-1),(r,c+1)):

def orangesRotting(grid):
    from collections import deque
    m, n = len(grid), len(grid[0])
    queue = deque()
    fresh = minutes = 0
    for i in range(m):
        for j in range(n):
            if grid[i][j] == 2:
                queue.append((i, j))

题意：[a,b] 表示上 a 前必须先上 b，判断是否能完成全部课程。

  2. 若是0→1与1→0，degree=[1,1]，没有一门可先上，队列一开始就空，done=0小于2。因此“有向环”就是几门课互相等待，不是看到任何连线闭起来都能不分方向地判错。

def canFinish(numCourses, prerequisites):
    from collections import deque
    graph = [[] for _ in range(numCourses)]
    degree = [0] * numCourses
    for a, b in prerequisites:
        graph[b].append(a)
        degree[a] += 1
    queue = deque(i for i, d in enumerate(degree) if d == 0)
    done = 0
    while queue:
        cur = queue.popleft()
        done += 1
        for nxt in graph[cur]:
            degree[nxt] -= 1
            if degree[nxt] == 0:
                queue.append(nxt)
    return done == numCourses

  2. search("ap")走完a、p后确有路径，但当前位置无#，所以不是完整词；startsWith("ap")只要求这段路径存在，因此为True。search("app")则在第二个p处找到#，即使还有l孩子也照样成立。“末尾标记”用于区分“走得到”与“恰有这个词”。

具体步骤

  1. insert 逐字符创建子字典并标记结束
  2. 查询逐字符走边
  3. 完整查找检查结束标记，前缀查找只要路径存在

class Trie:
    def __init__(self):
        self.root = {}

    def insert(self, word):
        node = self.root
        for c in word:
            node = node.setdefault(c, {})
        node['#'] = True

    def _walk(self, text):
        node = self.root
        for c in text:
            if c not in node:
                return None
            node = node[c]
        return node

    def search(self, word):
        node = self._walk(word)
        return node is not None and '#' in node

    def startsWith(self, prefix):
        return self._walk(prefix) is not None

复杂度：每操作时间 O(L)，空间与所有不同前缀总长度成正比。

易错点与适用边界：插入 apple 后 search(app) 应为 False，startsWith(app) 为 True；结束标记不应与合法字符冲突。

def permute(nums):
    ans, path, used = [], [], [False] * len(nums)
    def dfs():
        if len(path) == len(nums):
            ans.append(path.copy())
            return
        for i, x in enumerate(nums):
            if not used[i]:
                used[i] = True
                path.append(x)
                dfs()
                path.pop()
                used[i] = False
    dfs()
    return ans

            return

    m, n = len(board), len(board[0])
    def dfs(r, c, k):
        if not (0 <= r < m and 0 <= c < n) or board[r][c] != word[k]:
            return False
        if k == len(word) - 1:
            return True
        old = board[r][c]
        board[r][c] = None
        ok = any(dfs(a, b, k + 1) for a, b in
                 ((r-1,c),(r+1,c),(r,c-1),(r,c+1)))
        board[r][c] = old
        return ok
    return any(dfs(r, c, 0) for r in range(m) for c in range(n))

    for i in range(n - 1, -1, -1):

            pal[i][j] = s[i] == s[j] and (j - i < 2 or pal[i+1][j-1])

def solveNQueens(n):
    cols, diag1, diag2 = set(), set(), set()
    path, ans = [], []
    def dfs(r):

LC 74 搜索二维矩阵

题意：每行递增，且下一行第一个数大于上一行最后一个数，判断目标是否存在。

推导与核心思路：矩阵按行展开后整体有序；逻辑下标 mid 对应行 mid//n、列 mid%n。

  2. 计算矩阵值
  3. 按与 target 比较排除半边

def searchMatrix(matrix, target):
    if not matrix or not matrix[0]:
        return False
    m, n = len(matrix), len(matrix[0])
    l, r = 0, m * n - 1
    while l <= r:
        mid = (l + r) // 2
        value = matrix[mid // n][mid % n]
        if value == target:
            return True
        if value < target:
            l = mid + 1
        else:
            r = mid - 1
    return False

LC 34 在排序数组中查找元素的第一个和最后一个位置

题意：非降序数组中返回 target 首末下标，不存在则 [-1,-1]；要求 O(log n)。

推导与核心思路：首位置是第一个 ≥target，末位置是第一个 >target 再减 1。

  2. strict=False 时找 ≥target，True 时找 >target
  3. 检查首位置是否越界或不相等

def searchRange(nums, target):
    def boundary(strict):
        l, r = 0, len(nums)
        while l < r:
            mid = (l + r) // 2
            if nums[mid] < target or (strict and nums[mid] == target):
                l = mid + 1
            else:
                r = mid
        return l
    first = boundary(False)
    if first == len(nums) or nums[first] != target:
        return [-1, -1]
    return [first, boundary(True) - 1]

LC 33 搜索旋转排序数组

题意：严格递增数组经一次旋转，返回 target 下标或 -1。

推导与核心思路：每轮左半或右半至少有一半有序；先识别有序半，再判断目标是否落在其数值范围。

走一遍：[4,5,6,7,0,1,2], target=0 → 4。

把关键状态走完

  1. 数组[4,5,6,7,0,1,2]找0：l=0,r=6，mid=3、值7。左半[4,5,6,7]递增，但0不在[4,7)内，所以丢掉含mid的左半，令l=4。
  2. 现在mid=5、值1，左半[0,1]递增且0在[0,1)内，所以r=4。接着mid=4恰好为0，返回4。每步先检查相等，才把mid排除；如果省掉这一顺序或把边界不等号抄错，就会漏掉恰位于中点或端点的目标。

具体步骤

  1. 闭区间二分并先查相等
  2. 若 nums[l]≤nums[mid] 则左半有序
  3. 目标落左半则缩右，否则移左，右半同理

Python 实现

def search(nums, target):
    l, r = 0, len(nums) - 1
    while l <= r:
        mid = (l + r) // 2
        if nums[mid] == target:
            return mid
        if nums[l] <= nums[mid]:
            if nums[l] <= target < nums[mid]:
                r = mid - 1
            else:
                l = mid + 1
        else:
            if nums[mid] < target <= nums[r]:
                l = mid + 1
            else:
                r = mid - 1
    return -1

复杂度：时间 O(log n)，空间 O(1)。

易错点与适用边界：区间端点不等号要与 mid 已排除相配套；本题无重复，有重复时不能直接保证二分效率。

LC 4 寻找两个正序数组的中位数

题意：两个有序数组总长非零，求合并后中位数，要求对数时间。

推导与核心思路：二分短数组切点 i，长数组切点 j 由左半应有的元素数决定；合法切分满足两侧左最大≤右最小。

走一遍：[1,3] 与 [2] → 2；[1,2] 与 [3,4] → 2.5。

把关键状态走完

  1. 取a=[1,3]、b=[2,4]，两边共4项，左半需要2项。假设a切在i=1（左边取1项），那么b必须切在j=2-1=1。四个边界为al=1、ar=3、bl=2、br=4，左边[1,2]、右边[3,4]。
  2. 只要al≤br且bl≤ar，左半任何数都不超过右半任何数，切分就成立。总数偶数，中间两数是左半最大2与右半最小3，中位数(2+3)/2=2.5。若总长奇数，左边预留多1项，直接取左半最大。
  3. 为看懂二分方向，再试a=[1,2]、b=[3,4]的i=1：al=1、ar=2、bl=3、br=4，bl>ar表示a左边取少了，所以增大i；i=2、j=0后边界为2、+∞、-∞、3，切分正确。空侧用无穷表示“没有约束”，不是数组里真的存了无穷。

具体步骤

  1. 确保 a 较短，左边总量 (m+n+1)//2
  2. 越界用 ±∞
  3. 若 a 左过大则 i 左移，若 b 左过大则 i 右移
  4. 奇数取左最大，偶数取左右中值平均

Python 实现

def findMedianSortedArrays(a, b):
    if len(a) > len(b):
        a, b = b, a
    m, n = len(a), len(b)
    l, r = 0, m
    while l <= r:
        i = (l + r) // 2
        j = (m + n + 1) // 2 - i
        al = a[i-1] if i else float('-inf')
        ar = a[i] if i < m else float('inf')
        bl = b[j-1] if j else float('-inf')
        br = b[j] if j < n else float('inf')
        if al > br:
            r = i - 1
        elif bl > ar:
            l = i + 1
        elif (m + n) % 2:
            return max(al, bl)
        else:
            return (max(al, bl) + min(ar, br)) / 2

复杂度：时间 O(log(min(m,n)+1))，空间 O(1)。

易错点与适用边界：空数组可处理；偶数时必须除以 2；比较的是跨数组相邻边界，不是两数组各自中位数。

LC 155 最小栈

题意：支持 push、pop、top、getMin，全部 O(1)，查询和弹出时栈非空。

推导与核心思路：每个栈元素同时存当前值与加入后栈的最小值；删除时历史最小值自动恢复。

  2. pop 直接移除元组
  3. top/getMin 分别读取两个字段

Python 实现

class MinStack:
    def __init__(self):
        self.stack = []

    def push(self, val):
        minimum = min(val, self.stack[-1][1]) if self.stack else val
        self.stack.append((val, minimum))

    def pop(self):
        self.stack.pop()

    def top(self):
        return self.stack[-1][0]

    def getMin(self):
        return self.stack[-1][1]

复杂度：每操作时间 O(1)，空间 O(n)。

易错点与适用边界：重复最小值也要正确保留；只存一个全局最小值无法在 pop 后恢复。

LC 394 字符串解码

题意：将 k[内容] 展开为重复 k 次的内容，允许嵌套和多位数字，输入合法。

推导与核心思路：遇 [ 保存外层已解码前缀和重复次数，转入新层；遇 ] 把内层结果乘次数再接回外层。

  2. 遇 [ 入栈并清空局部状态
  3. 遇 ] 弹出并组合，普通字母追加

def decodeString(s):
    stack, text, number = [], '', 0
    for c in s:
        if c.isdigit():
            number = number * 10 + int(c)
        elif c == '[':
            stack.append((text, number))
            text, number = '', 0
        elif c == ']':
            prefix, repeat = stack.pop()
            text = prefix + text * repeat
        else:
            text += c
    return text

LC 84 柱状图中最大的矩形

题意：柱子宽为 1，求全部柱子围成区域内最大的矩形面积。

推导与核心思路：单调递增高度栈中，遇到更矮柱时，弹出柱的右边界确定；新栈顶给左侧更矮边界。

走一遍：[2,1,5,6,2,3] → 10，来自高度 5、宽度 2。

把关键状态走完

  1. 在[2,1,5,6,2,3]中，栈起始[-1]，-1是不存在的左边界。读下标0高度2入栈；下标1高度1使2出栈，弹后左界-1，宽1-(-1)-1=1，面积2。继续入1，然后下标2的5、下标3的6依次入栈。
  2. 下标4高度2比6矮：弹下标3，左界为2，宽4-2-1=1，面积6；还比5矮，再弹下标2，左界变1，宽4-1-1=2，面积5×2=10。正是弹完后剩余的栈顶告诉我们，向左还能延伸到哪里。
  3. 末尾补0会把仍在等“右边更矮柱子”的高度全部结算；否则单调上升输入[1,2,3]会一直压栈、漏算答案。一次弹出就确定一个高度的最大宽度，不必枚举所有左右端点。

具体步骤

  1. 给末尾加高度 0 清栈
  2. 栈初始 -1 作为左边界
  3. 弹出高度 h 时宽为 i-stack[-1]-1

Python 实现

def largestRectangleArea(heights):
    values = heights + [0]
    stack, best = [-1], 0
    for i, x in enumerate(values):
        while stack[-1] != -1 and values[stack[-1]] > x:
            h = values[stack.pop()]
            best = max(best, h * (i - stack[-1] - 1))
        stack.append(i)
    return best

复杂度：时间 O(n)，空间 O(n)。

易错点与适用边界：宽度要减 1；栈顶弹出后再读取左边界；相等高度可保留，最终仍会算到完整宽度。

def findKthLargest(nums, k):
    import heapq
    heap = nums[:k]

class MedianFinder:
    def __init__(self):
        self.low, self.high = [], []

    def addNum(self, num):
        import heapq
        heapq.heappush(self.low, -num)
        heapq.heappush(self.high, -heapq.heappop(self.low))
        if len(self.high) > len(self.low):
            heapq.heappush(self.low, -heapq.heappop(self.high))

    def findMedian(self):
        if len(self.low) > len(self.high):
            return -self.low[0]
        return (-self.low[0] + self.high[0]) / 2

            if j >= 0 and s[j] == '(':

    return best

    for x in nums:
        for s in range(target, x - 1, -1):

    return dp[target]

先把这类话说懂：子串必须连续，例如abcde中的bcd；子序列可以跳字符但不能换顺序，例如ace。LIS是“最长严格递增子序列”，LCS是“两串的最长公共子序列”。区间DP把一段起终点作为状态；二维前缀DP用“第一串前i项、第二串前j项”作状态，依赖较短前缀的答案。

LC 300 最长递增子序列

题意：求严格递增子序列的最长长度，不要求连续。

推导与核心思路：基础 DP：f[i]=1+max(f[j])，其中 j<i 且 nums[j]<nums[i]。优化保存 tails[len-1] 为该长度递增序列的最小结尾；新 x 替换第一个≥x 的结尾。

走一遍：[10,9,2,5,3,7,101,18]：tails 最终 [2,3,7,18]，长度 4。

把关键状态走完

  1. 把[10,9,2,5,3,7,101,18]逐项读入，tails依次为[10]→[9]→[2]→[2,5]→[2,3]→[2,3,7]→[2,3,7,101]→[2,3,7,18]。数组第j格表示“已见过的长度j+1递增子序列中，最小的末尾值”。
  2. 读3时替换5：同为长度2，[2,3]比[2,5]更容易接上未来4，所以保留较小结尾不会损失最佳长度。读18替换101同理。最后长度4，不表示必须输出tails本身这条序列；本题只问长度。重复数[2,2]必须替换第一个≥2的位置，不能追加，答案才仍为1。

具体步骤

  1. 建立空 tails
  2. 用 lower_bound 找第一个≥x 的位置
  3. 在末尾就追加，否则替换
  4. 最终 tails 长度即答案

Python 实现

def lengthOfLIS(nums):
    from bisect import bisect_left
    tails = []
    for x in nums:
        i = bisect_left(tails, x)
        if i == len(tails):
            tails.append(x)
        else:
            tails[i] = x
    return len(tails)

复杂度：时间 O(n log n)，空间 O(n)；基础 DP 为 O(n²)。

易错点与适用边界：严格递增应找 ≥x，重复数不能增加长度；tails 的值序列不一定是原数组中的同一条实际子序列。

LC 5 最长回文子串

题意：求最长的连续回文子串，若并列可返回任意一个。

推导与核心思路：区间 DP 定义 pal[l][r]=(s[l]=s[r]) 且（长度≤2 或 pal[l+1][r-1]）。等价的中心扩展从单字符和字符间隙出发，省去整张表。

走一遍："babad" → "bab" 或 "aba"；"cbbd" → "bb"，必须考虑偶数中心。

具体步骤

  1. 枚举每个位置的奇数中心 (i,i) 与偶数中心 (i,i+1)
  2. 只要两端相等就扩展
  3. 更新最长合法区间

Python 实现

def longestPalindrome(s):
    start = length = 0
    for i in range(len(s)):
        for l, r in ((i, i), (i, i+1)):
            while l >= 0 and r < len(s) and s[l] == s[r]:
                l -= 1
                r += 1
            if r - l - 1 > length:
                start, length = l + 1, r - l - 1
    return s[start:start+length]

复杂度：时间 O(n²)，额外空间 O(1)（不计返回字符串）。

易错点与适用边界：退出循环时 l、r 已越出合法回文，正确区间是 [l+1,r)，长度 r-l-1。

LC 1143 最长公共子序列

题意：两个字符串中找最长的公共子序列长度，字符可不连续但相对顺序不变。

推导与核心思路：dp[i][j] 表示两个前缀的 LCS。末字符相同则 dp[i-1][j-1]+1；不同则舍弃一边末字符取 max(dp[i-1][j],dp[i][j-1])。

走一遍："abcde" 与 "ace" → 3；ace 可以跳过 b、d。

把关键状态走完

  1. 用text1="ab"、text2="acb"建前缀表。第0行[0,0,0,0]表示空串与任意前缀没有公共字符。处理a后，第1行成为[0,1,1,1]：与a相等时对角+1，接着遇c或b不等便保留已有的1。
  2. 处理b时，第2行是[0,1,1,2]。最后一格对应ab与acb，末字符b相等，所以取上一行上一列（a与ac）的1再加1，得2；若末字符不同，则分别尝试“不要第一串末字”或“不要第二串末字”，取上格与左格较大者。
  3. dp行列比原串多1，是为了把“空前缀”存为第0行/列；因此dp[i][j]的末字符位置是i-1与j-1。子序列允许跳过c，若问连续公共子串则不能沿用这个“不等也保留”的转移。

具体步骤

  1. 建立多一行一列的零表，空前缀 LCS=0
  2. i,j 均从 1 开始
  3. 按相等与否转移

Python 实现

def longestCommonSubsequence(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if text1[i-1] == text2[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

复杂度：时间 O(mn)，空间 O(mn)，可滚动压成 O(min(m,n))。

易错点与适用边界：不是最长公共子串，不同时不能直接清零；字符访问用 i-1,j-1。

LC 72 编辑距离

题意：用插入、删除、替换，每步代价 1，把 word1 变成 word2 的最少操作数。

推导与核心思路：dp[i][j] 是两个前缀的转换代价。末字符相等时沿对角；否则在删除 dp[i-1][j]、插入 dp[i][j-1]、替换 dp[i-1][j-1] 中取最小再加 1。

走一遍："horse"→"ros"：替换 h→r、删掉第三位 r、删 e，共 3 步。

把关键状态走完

  1. 先走最小例子word1="ab"、word2="ac"。空串一行是[0,1,2]，表示插入0、1、2个字符；处理a后为[1,0,1]：a→a不用改，a→ac加一个c。
  2. 处理b的最后一格，对应ab→ac，末字不同。删b后a→ac的代价为dp[1][2]+1=2；给ab增加末字c，则先要ab→a，代价dp[2][1]+1=2；把b替换为c，只要此前a→a，代价dp[1][1]+1=1。所以本格选1。
  3. 三个相邻格不是任意凑出来的：上格少了第一串末字，对应删除；左格少了目标末字，对应插入；左上两边各少一字，对应替换或相同字符直接沿用。空串边界填长度，保证这些操作在第一行第一列也有正确含义。

具体步骤

  1. 空串到长度 j 的串需 j 次插入，反向需 i 次删除
  2. 按 i,j 升序填表
  3. 返回 dp[m][n]

Python 实现

def minDistance(word1, word2):
    m, n = len(word1), len(word2)
    dp = [[0] * (n+1) for _ in range(m+1)]
    for i in range(m+1):
        dp[i][0] = i
    for j in range(n+1):
        dp[0][j] = j
    for i in range(1, m+1):
        for j in range(1, n+1):
            if word1[i-1] == word2[j-1]:
                dp[i][j] = dp[i-1][j-1]
            else:
                dp[i][j] = 1 + min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1])
    return dp[m][n]

复杂度：时间 O(mn)，空间 O(mn)，可滚动压缩。

易错点与适用边界：不同字符时三种操作不能漏；相同字符直接沿对角，不额外加 1。

LC 62 不同路径

题意：m×n 网格从左上走到右下，每步只能向右或向下，求路径条数。

推导与核心思路：到 (i,j) 的最后一步只有从上或从左两种，故 ways[i][j]=ways[i-1][j]+ways[i][j-1]。首行首列各只有 1 条路。

走一遍：m=3,n=3：首行 [1,1,1]，第二行 [1,2,3]，第三行 [1,3,6]。

具体步骤

  1. 用全 1 一维数组表示第一行
  2. 从第二行开始，j 从 1 到 n-1
  3. 令 dp[j]+=dp[j-1]

Python 实现

def uniquePaths(m, n):
    dp = [1] * n
    for _ in range(1, m):
        for j in range(1, n):
            dp[j] += dp[j-1]
    return dp[-1]

复杂度：时间 O(mn)，空间 O(n)。

易错点与适用边界：不能把 dp[0] 改成 0，第一列仍只有一种走法；m,n 的 1×n 边界应返回 1。

LC 64 最小路径和

题意：非负权重网格，只能右移或下移，求左上到右下的最小权重和，含起终点。

推导与核心思路：dp[i][j]=grid[i][j]+min(上方最优,左方最优)，最优子结构来自最后一步只有两个来源。

走一遍：[[1,3,1],[1,5,1],[4,2,1]] → 7，路径 1→3→1→1→1。

具体步骤

  1. dp 初始化无穷
  2. 起点设为自身
  3. 每格以旧 dp[j] 为上方、新 dp[j-1] 为左方更新

Python 实现

def minPathSum(grid):
    n = len(grid[0])
    dp = [float('inf')] * n
    for i, row in enumerate(grid):
        for j, value in enumerate(row):
            if i == 0 and j == 0:
                dp[j] = value
            else:
                left = dp[j-1] if j else float('inf')
                dp[j] = value + min(dp[j], left)
    return dp[-1]

复杂度：时间 O(mn)，空间 O(n)，不修改输入。

易错点与适用边界：边界不存在的来源应设无穷，而非 0；起点不能重复累加。

LC 136 只出现一次的数字

题意：除一个元素只出现一次外，其余均恰出现两次，找单个元素。

推导与核心思路：异或满足 x^x=0、x^0=x、结合交换律，成对元素全部抵消。

具体步骤

  1. ans=0
  2. 依次异或所有数
  3. 返回 ans

def singleNumber(nums):
    ans = 0
    for x in nums:
        ans ^= x
    return ans

复杂度：时间 O(n)，空间 O(1)。

易错点与适用边界：如果其他元素出现三次，这个方法不成立；负整数在 Python 中也可用异或抵消。

LC 169 多数元素

题意：保证有一个元素出现次数大于 n/2，返回它。

推导与核心思路：Boyer–Moore 投票每次抵消一对不同元素，多数元素的剩余票不可能被全部抵消。

走一遍：[2,2,1,1,1,2,2] → 2，票数抵消后候选仍为 2。

具体步骤

  1. count=0 时选当前值为候选
  2. 同候选加一、不同减一
  3. 最终候选就是多数元素

Python 实现

def majorityElement(nums):
    candidate, count = None, 0
    for x in nums:
        if count == 0:
            candidate = x
        count += 1 if x == candidate else -1
    return candidate

复杂度：时间 O(n)，空间 O(1)。

易错点与适用边界：如果题目不保证多数存在，必须再扫描计数验证；不要把“众数”与超过一半的多数混同。

LC 75 颜色分类

题意：只含 0、1、2 的数组，一趟原地排成 0 区、1 区、2 区。

推导与核心思路：维护 [0,low) 为 0，[low,i) 为 1，(high,n) 为 2，[i,high] 未知。

走一遍：[2,0,2,1,1,0] → [0,0,1,1,2,2]。

具体步骤

  1. 遇 0 与 low 交换，low 和 i 前进
  2. 遇 1 仅 i 前进
  3. 遇 2 与 high 交换，high 后退但 i 不动

Python 实现

def sortColors(nums):
    low = i = 0
    high = len(nums) - 1
    while i <= high:
        if nums[i] == 0:
            nums[low], nums[i] = nums[i], nums[low]
            low += 1
            i += 1
        elif nums[i] == 2:
            nums[i], nums[high] = nums[high], nums[i]
            high -= 1
        else:
            i += 1

复杂度：时间 O(n)，空间 O(1)。

易错点与适用边界：交换过来的末尾元素尚未分类，遇 2 后不能立刻 i++；这是最常见漏元素原因。

LC 31 下一个排列

题意：原地改为字典序紧邻的下一个排列；若已最大则变为最小。

推导与核心思路：尽量保持左侧不变：从右找到首个上升对的左元素 pivot，以右侧刚好更大的数替换，再把降序后缀反转成最小。

走一遍：[1,3,2] → [2,1,3]；[3,2,1] → [1,2,3]。

具体步骤

  1. 从右找 nums[i]<nums[i+1]
  2. 若存在，从右找首个 nums[j]>nums[i] 并交换
  3. 反转 i+1..n-1

Python 实现

def nextPermutation(nums):
    i = len(nums) - 2
    while i >= 0 and nums[i] >= nums[i+1]:
        i -= 1
    if i >= 0:
        j = len(nums) - 1
        while nums[j] <= nums[i]:
            j -= 1
        nums[i], nums[j] = nums[j], nums[i]
    l, r = i + 1, len(nums) - 1
    while l < r:
        nums[l], nums[r] = nums[r], nums[l]
        l += 1
        r -= 1

复杂度：时间 O(n)，空间 O(1)。

易错点与适用边界：比较必须严格；全降序时 i=-1，反转整个数组；重复值也能正确处理。

LC 287 寻找重复数

题意：长度 n+1 的数组，每项在 1..n，只有一个重复值但可多次出现；不改数组、O(1) 空间找它。

推导与核心思路：把 i→nums[i] 看成函数图。从 0 出发必入环；0 无入边，重复值对应路径进入环的结点，使用 Floyd 找入口。

走一遍：[1,3,4,2,2] → 函数路径 0→1→3→2→4→2，入口 2 即重复数。

具体步骤

  1. slow=fast=0，先移动至相遇
  2. 一个指针重回 0
  3. 两者同步一步直到相遇，返回下标值

Python 实现

def findDuplicate(nums):
    slow = fast = 0
    while True:
        slow, fast = nums[slow], nums[nums[fast]]
        if slow == fast:
            break
    entry = 0
    while entry != slow:
        entry, slow = nums[entry], nums[slow]
    return entry

复杂度：时间 O(n)，空间 O(1)，不修改输入。

易错点与适用边界：这是数值作为下一结点下标，不是对数组排序；值域 1..n 和 n+1 长度是论证关键。
