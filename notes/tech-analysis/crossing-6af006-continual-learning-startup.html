谷雨：持续学习、电脑操作与研究团队的创业难题

一个从学术研究走向创业的团队，怎样重新判断模型能力、设计连续任务评估，并面对“技术问题成立，却还不知道客户为何购买”的处境？

完整对话脉络 · 持续学习的评估 · 独立判断 · 证据边界

完整对话脉络

这是《十字路口》2026 年终 AI 复盘系列第二期，嘉宾是硅谷 NeoLab 公司 NeoCognition 联合创始人谷雨。主播 Koji 提前看过他的 10 个 Aha Moments，评价这份清单与众不同——像一连串“旧直觉接连被现实打脸”的坦诚复盘。对话从快问快答切入，依序覆盖 RSI、Computer Use 与 ApprenticeBench、数学 Scaling 与 Memory Notes、学术体系坍塌、教授 vs 夜店男模、创业的“灭火器与砖头”、AI 电影、Personal Agent 及 2027 预测。

嘉宾速写谷雨，31 岁，INTP，天蝎座；南京大学本科，俄亥俄州立大学（OSU NLP Lab，师从苏宇/苏昱老师）博士。
公司与定位NeoCognition 联合创始人，一句话定位：“做 continual learning（持续学习）”。
融资与团队种子轮融 4,000 万美元，将启 A 轮；团队 17 名全职 + 4 名实习生。创业前还联合发起过博客/播客（转写记作 On Ground）。
学术代表基准在 OSU NLP Lab 参与发布多模态基准 MMMU、2023 年 5 月早期电脑/网页操作基准 Mind2Web（后续变体 Online-Mind2Web 亦被 OpenAI、Anthropic、Google 默认引用），并与清华合作推出 AgentBench。

1. RSI：为什么从看空创业公司到迅速被打脸？

上个月谷雨还公开表示看不懂为什么会有初创公司去做 RSI（递归自我改进），理由非常直接：第一，做 RSI 本质上是在追逐最前沿的基础模型叙事，别说新成立的创业公司，除了 OpenAI 和 Anthropic，连其他大厂这么长时间都还在后面苦追；第二，既然叫“递归”，总得先有自己的底座模型作为起点。但最近 Recursive 和 MiroMind 发布的新成果彻底扭转了他的看法——甚至有团队只用 3 个多月就训出了比 K3 更强的预训练模型。

他由此重新看懂了 NeoLab（新一代研究型实验室）切入 RSI 的底层逻辑：当 AI 编写 training infra（训练基础设施） 和搜索 training recipe（训练配方） 的能力不断增强、最终超过人类时，大厂过去多年积累起来的庞大系统、既有 SOP 与组织架构反而会变成沉重累赘。他举了一位国内模型厂朋友两周前聊起的真实例子：业内都知道 OpenAI 的 score centering 有效、上了大概能提 1 到 2 个点，但为了把它塞进自家现成的庞大 infra 改造成本实在太高，最后只能放弃。相比之下，从零起步的 NeoLab 毫无历史包袱，可以让 AI 直接搜一套新 recipe、搭一套新 infra，随时迭代也随时丢弃，反倒可能跑出更高加速度。Koji 追问那是不是仍得融大钱买卡买数据？谷雨坦言，只要走完整 full-stack 训练路线，重资本依然是硬门槛，所以 Recursive 和 MiroMind 都拿了巨额融资；除这两家及 Koji 顺带提及的 Gifting、Discovery Loop 外，国内也有一批新团队值得持续观察。

2. Computer Use 与 ApprenticeBench：“手”已泛化，“脑子”与真正长程才是难题

去年行业一直在讨论 Computer Use Agent（电脑操作智能体） 的泛化性与可靠性——今天把流程点对了，明天换个微弱状态就点错。NeoCognition 刚成立时，团队整整花了几个月搭了一套 pipeline：让 Agent 重复尝试多次，把成功的那一次轨迹挑出来封装成 reusable skill（可复用技能）。结果从去年底到今年初，靠 Coding 方向的大规模训练，操作能力竟然直接泛化到了各类软件和网页界面上；如今让 Opus 5.5 自己实现同样的流程，不仅做得极快，还能在途中自己纠错，团队几个月的活几乎白干。谷雨由此将问题清晰分成两层：“手”的操作问题基本解决，真正的瓶颈已转向与之正交（orthogonal）的“脑子”认知层——理解每家公司独特的内部业务流程与规则；虽然认知本身不是电脑操作，但数字世界的工作最终仍要落回软件和网页交互，只要脑子想清楚怎么处理，手就能稳稳做对。

顺着这个判断，Koji 请他展开介绍团队新发布的评测基准 ApprenticeBench，以及团队此前做过的经典工作。谷雨回顾，博士期间在 OSU NLP Lab 他们推出过多模态基准 MMMU（如今 OpenAI、Anthropic、Google 发模型默认采用）、2023 年 5 月发布的早期电脑/网页操作基准 Mind2Web（其变体 Online-Mind2Web 同样成为三大厂发模型标配），还与清华合作推出了早期 Agent 基准 AgentBench。而这一次做 ApprenticeBench，是为了填补“Agent 部署进生产环境后如何边干边学、持续迭代”的评测空白：

  • 高度真实的垂直场景：选定建筑行业会计报账，共 100 道真实任务，每道题都做报账，却分别暗含公司处理惯例（convention）、特定工作流（workflow）与特殊审批流程。
  • 连续任务流（Stream）：区别于传统基准里彼此独立的考题，这 100 道任务必须按顺序在一条流里连续完成，从前面任务中获得的反馈与知识直接决定后面能不能做对。
  • 重新定义 Long-Horizon（长程）与 Lifelong Intelligence（终身智能）：如今不少标榜“长程”的基准走偏了，只找一堆极难的单题让 Agent 闷头做半天，既难找又难规模化；在谷雨看来，真正的长程不是“让一个会计花一周死磕一笔账”，而是“让一个菜鸟会计在几个月到一两年里成长为熟知公司脾气的老员工”。把这种持续迭代规模化，量变引起质变，才能通向像人一样的终身智能。

Koji 提到第一版 ApprenticeBench 里最强的 Claude 模型已经考到约 80 分，追问怎样继续提分？谷雨认为，持续学习能力正成为区分前沿模型与非前沿模型的核心分水岭，关键在于能否更聪明地写和改写 memory notes（记忆笔记）。他听说 OpenAI 和 Anthropic 都有各自训练配方——比如 Claude Code 和 Codex 的长会话（long session）天然就会沉淀这类经验记录数据——但整套配方仍不成熟，NeoCognition 也在探索，并且很快会放出难度大增的新版把现有高分拉下来。至于刷分风险，他靠两道防线兜底：一是测试题未公开，无法对着原题刷；二是测试目标本身是更高层级的 meta-level（元层级）持续学习能力——死背某家建筑公司的报账细则毫无意义，若谁真能把元学习能力刷上去，那反倒是做了件大好事。

3. 数学与 Scaling Law：“苦涩的教训”与拼豆自习室

第三个震动来自数学——去年已见端倪，今年冲击力直接放大 50 到 100 倍。2024 年谷雨与绝大多数研究者一样，笃信攻克高难数学必须靠 Lean 这类形式化验证系统（formalization）提供硬信号，否则纯靠自然语言（informal）训练大模型像“左脚踩右脚”，上限高不到哪去。结果仅靠数据量和质量不断推高，去年模型就已凭纯自然语言拿到 IMO 金牌，今年更把前几年难题逐一横扫，再次印证 AI 界著名的 Bitter Lesson（苦涩的教训）——“不得不信 Scaling 可以解决更多问题”。

Koji 感慨，许多原本站在人类智力之巅的数学家正陷入虚无主义；不过另一种看法认为，解题的真正意义不在最终答案，而在探索过程里积累方法与体验，就像运动员明知跑不过汽车和机器依然不断挑战身体极限，数学以后或许会像棋类运动一样成为人类自我挑战的方式。谷雨深表赞同，觉得做事本身能带来快乐最重要，并顺手讲起最近见识的神奇业态——拼豆自习室：整间大自习室隔出一个个定制小格子，里面备齐几百种颜色的拼豆素材、图纸和工具，按小时收费；放眼望去活像一座安静的工厂，大家专心致志地“付费劳作”却乐在其中。Koji 立刻调侃：“这商业模式不错，我们公司可以退钱，让大家付费来上班。”

4. 公开打脸现场：曾经看低的 Memory Notes

第四个瞬间又回到自家主业，也是一次干脆利落的自我修正。今年上半年谷雨还在各种场合用极“学术派”的逻辑公开看低 memory notes：把经验写进文本再不断改写，压根算不上一个有理论保证的可靠优化算法，而且写法上限必然被模型自身能力卡死。结果随着模型持续 Scaling 跨过临界点，他亲眼看到基于文本记忆笔记的持续学习上限竟相当可观。不过他特意补了一条重要声明：截至目前，他们观察到真正把 memory notes 玩转的只有 Anthropic 和 OpenAI，其他家做得都还不行。Koji 总结道，前四个 Aha Moments 一再印证同一个规律——模型沿着 Scaling 进化的速度，频频击穿人类提前设下的工程补丁。

5. 学术会议体系坍塌，未来如何评人？

从 2023 年萌芽到 2026 年彻底跨过临界点，传统学术会议的投稿、审稿与评价体系已经崩塌。谷雨用脚投票：自己已经一年半没投过任何论文，半年多没审过稿，也没有担任过 Area Chair（AC），觉得这套流程对个人时间极不尊重。现在分到一个 16 篇文章的审稿 batch，满屏都是 AI slop（AI 批量生成的低质水文）和灌水，真正拿得出手的往往只有一两篇。以前他就不认同数论文的做法，如今论文数量与真实能力之间几乎已完全没有相关性。

招聘应届生时，NeoCognition 已不再数论文，而是看重深度交流——追问候选人做过的具体工作、听他对公司当前方向的理解；面试里还会专门安排一场 research presentation（研究报告），逻辑表达、QA 临场反应和对问题本质的穿透力立刻高下立判。谈到旧体系崩塌后什么会取而代之，谷雨认为学术界最好的评估始终是同行评议（peer review），问题在于如今会议审稿毫无门槛，未来应回归由高品味（taste）的资深同行把关，类似美国名校招教职的 job talk。但他也清楚学术圈惯性极大、重建必有滞后；眼下最直观的后果，是中美 AI 博士进大学当教职的意愿都在下滑——去 Frontier Lab 或 NeoLab 创业不仅待遇落差悬殊、资源与算力充沛得多，还不必忍受失灵的考核体制。

6. “教授 vs 夜店男模”，以及读博与创业的个人选择

Koji 抛出一句和朋友开玩笑的夸张对比：“10 年后大学教授和夜店男模谁的社会地位更高？”谷雨毫不犹豫地认真答道：“我真的这么觉得。当智力不再值钱的时候，可能长相和身材会更值钱。”Koji 随即拉长历史视角：人类智力值钱其实没多久——前现代漫长岁月里体力与强壮最值钱，机械革命让体力贬值；数字世界到来后脑力最值钱，而 AI 正是“数字世界的机械”，脑力贬值后短期内最难被机器取代的或许是情绪价值。他还顺带提起一则新闻：眼下全世界卖得最好的两种减肥药收入加起来已超过这些大模型公司；谷雨笑着接话，减肥药只要有效且无副作用，确实最容易把人送上世界首富宝座。

被问到今天若有人咨询还值不值得读 PhD，谷雨拒给通用建议：“我不给建议，自己开心就好——想做一件事就去做，本身就是一种理性；明明想做却算计半天不去，我才不懂那为什么叫理性。”但谈到自己为什么选择创业，他给出了三条极为坦诚的个人剖白：① 虽然一路读计算机，身边同学刚上本科就默认进大厂拿高薪 package，但他“这辈子没有一秒钟想过去大厂”，极度抗拒固定作息和工作日/周末硬边界，渴望在有状态时全力做事、没状态时自由停下；② 看重 ownership（所有权），希望自己决定做什么问题，很难替别人完成使命；③ 对风险几乎没有概念、不精算代价。Koji 敏锐追问这是否源于家庭给的情绪与财务安全感，谷雨承认父母从不对自己强加结婚或任何世俗人生节点要求，确实给了自己很强的底层底气。

7. 学术团队创业交学费：“拿锤子找钉子”与“灭火器 vs 砖头”

创业快满一年，真的拿到当初想要的自由了吗？这引出第七个最扎心的 Aha Moment。过去在 OSU 跟着苏宇老师做学术，团队在圈内口碑极好，大家公认他们有 vision、有 taste，最瞧不上学术界常见的“拿锤子找钉子”（先发明奇怪设计再硬找场景水论文），向来坚持从最根本的技术问题（fundamental issues）切入。可走进创业一年后，谷雨猛然发现自己反倒活成了 SISP（Solutions in Search of Problems，拿方案找问题）：做学术只要在一套技术体系内部逻辑自洽即可闭环；但做公司光自洽就是自娱自乐，必须和真实市场（market）完成闭环，回答 Continual Learning 究竟该长成什么产品、解决谁的痛点、带来什么商业价值。这是团队过去大半年实打实交的学费，“一旦进入做事状态就容易困在自身 bias 里，纸上得来终觉浅”。

Koji 立刻搬出 VC 圈经典理论点破症结：“一个人头上着火了，绝不会站在原地等你造出完美灭火器；手边只要有块砖头，他先抓砖头把火拍灭再说。”学术出身的团队太本分、做事太追求 solid，总想把“灭火器”打磨到自己百分百满意才肯发版，结果还没出厂，卖“砖头”的人早就卖出 100 块跑通了闭环。谷雨深以为然，坦言团队发布标准确实太高、太老实，有时就该先把没那么成熟的版本推出来让用户反馈转起来，甚至适度先把牛吹出去造点声势。Koji 问既能早期造势（momentum）最终又能真交付（deliver）的参考标杆是谁，谷雨脱口而出马斯克——硅谷 “fake it till you make it” 的极致典范。间隙里 Koji 还问起一批高中生不读本科直接入行 AI 的趋势，谷雨觉得在北京、上海等富集教育资源环境下非常合理：传统基础教育前十几年本质偏向筛选而非能力磨练，若能早早投入真实训练，高中阶段做出重要贡献毫不奇怪，只是对环境和资源要求太高，绝不可能大众化。

8. 创业怎么成了“随大流”？20 亿美元估值与时间代价

第八个瞬间让谷雨接连“哈”了好多次：过去很长时间里，创业属于少数想法与众不同的异类走的窄门；可过去一年，身边越来越多人脱口而出“大家都在创业，周围人都在创业，我也想去创业”，创业诡异地变成了随大流。推手极现实——市场里的钱太多了。谷雨原以为硅谷永远比国内钱多：2023、2024 年国内大牛教授出来创业，种子轮也就 500 万到 1,000 万美元，NeoCognition 在硅谷融到 4,000 万美元种子轮已算顶尖大额（硅谷常见仅 500 万–1,000 万美元）；直到今年 6 月他震惊听说，国内有些所谓 NeoLab 起步估值直接干到 20 亿美元（他笑称自己不懂宏观金融，瞎猜或许是国内房地产退潮后大笔资金无处可去）。Koji 觉得让最前沿年轻人无压力地拿到资本试错对社会是好事，而且多不签个人回购和对赌、并无个人财务压力；谷雨冷静补了一刀——真正沉重的是“会不会浪费几年人生时间”的机会成本。

9. B 站 2 小时 AI 僵尸片、“记忆换算力”与“审美和美”

大半年以前 AI 做几分钟视频角色脸都在不停乱变；前阵子谷雨在 B 站刷到 UP 主龙小胖把已故港星林正英“搬回来”做的 2 个多小时完整僵尸片，从头到尾七八个角色的脸、衣着、剧情高度一致，令人彻底沉浸进去当真电影看。尽管 B 站明文声明这是 AI 创作，弹幕里大家几乎全在讨论剧情——观众根本不在乎怎么拍出来的，只在乎最终交付（deliverable）够不够好看。谷雨自己也跃跃欲试，引用 Alexandr Wang 的话“everyone can dream”，感叹这是极度利好创作者的时代。聊到兴头上，他讲起一位好朋友最近借 AI 辅助写的悲伤科幻小说：未来人类实现永生，但算力极其昂贵，想换取更多算力享受当下娱乐，唯一筹码是卖掉自己的记忆——因为持续进化的模型仍要不断吃掉人类独有的记忆数据。再对照现实市场：去年听说 60 集×1 分钟的 AI 短剧剧本报价差不多 7 万元人民币，如今 AI 一天就能写 100 个。兜回“智力不再值钱”的命题，谷雨抛出一句自称极“粗暴”的结论：AI 时代人类最终只需要两样东西——“审美”（决定正确前进方向）与“美”（情绪价值）。

10. Personal Agent 为何真有用？以及 2027 关键词预测

最后一个 Aha Moment 落在年底爆红的 Personal Agent（个人智能体）。谷雨敏锐点破：它突然起飞并非某项神秘技术跨过门槛——Coding 与 Computer Use 变强固然是底盘，至于圈内热捧的 proactiveness（主动推送），年初的 OpenClaw 以及 ChatGPT、Claude 的 scheduled tasks（定时任务）早就都能定时查邮件推送。真正改变体验的，是两个极聪明的产品交互设计：① 抛弃 ChatGPT 和 Claude 那种每干一件事就新开窗口的 session-based（多窗口会话），改成类似微信跟真人聊天的 persistent 单一持续对话流（如 Muse），一个助手就是一条贯通到底的窗口，才有真实“人”的感觉；② 通过卡通形象强化拟人感，例如 Muse 的毛绒形象和配套 PR。他自己目前同时开着 Muse 和 Instinct，因国内本地生活平台（外卖、订酒店、订机票）还不太打得通，主要用来盯海量邮件和消息——它们真能精准挑出高优先级邮件主动推送，极省精力；他预计尝鲜期过后，一旦养成生活依赖最终会收敛到只留一个入口。

节目尾声展望 2027 年，谷雨先打趣“我们公司被高价收购了——开玩笑”，随后正经说“明年肯定再老一岁”（AI 也许将来能造长生不老药，但大概不是明年的事）。给年轻人的职业规划，他梳理了一条清晰的年度技术关键词轨迹：2024 到 2025 年是 VLM / World Model，2025 年底到 2026 年是 Coding，2026 到明年下半年之前一定是 Continual Learning；临别前还补了一个声明纯属“瞎预测”的大胆猜想——明年或许真会出现来自 RSI 创业公司的最强前沿（SOTA 级）模型（Koji 追问是否指 SSI，谷雨回应至少是前沿 SOTA 级）。

持续学习的评估机制：拆开“真学会”与“死记硬背”

ApprenticeBench 把评测从静态单题改成按时间展开的经验流：接收任务与环境 → 执行操作 → 获取反馈 → 写入记忆载体（文本笔记、工作流状态或参数）→ 处理后续任务，核心衡量前期踩坑能否沉淀为可迁移规则。

本文自拟对照算例：检验报账规则泛化

连续任务流中，第 1 题处理 1,500 元差旅报销被打回，反馈称“单笔差旅超 1,000 元须追加部门总监二级审批”，系统写入记忆笔记。随后依次来三题：800 元差旅、1,200 元差旅、1,200 元设备采购（非差旅）。若只死记“所有报销都要找总监”，后两题中的非差旅与小额差旅会误审；若只记“1,500 元要审”，1,200 元差旅又会漏审。严谨评测应在固定反馈口径下对比“开启记忆”与“清空记忆基线”，并切换到采用新阈值的新公司，测验系统“从错到对”的收敛步数是否显著缩短。本例为本文方法示意，非原题。

独立判断：把四次“打脸”翻译成技术与创业坐标

1. 上下文、外部笔记与参数更新，是三种不同的持续学习

单次超长上下文、外部可读写记忆笔记（memory notes）与在线参数更新（TTT/持续微调）在保存位置、更新代价、可删除性与跨任务泛化上差异极大。文本笔记可审计易回滚，却高度依赖底座摘要与检索精度，任务流拉长易引发笔记膨胀与规则冲突。评价系统时必问：经验存在哪、何时写入、坏经验如何覆盖、换新环境能否加速学懂。

2. “手”与“脑子”常在交界处互相纠缠

虽然“操作已泛化、认知成瓶颈”很贴切，但在复杂企业软件里，关键审批条件常藏在二级弹窗里，误点也会静默改写状态。诊断失败宜拆成交叉对照——“明文给全规则测跨界面操作”与“固定极简接口测隐性规则归纳”——避免把界面盲区误判为认知失败。

3. 研究型团队创业的难关是切换“验收裁判”

学术裁判是同行与基准，商业裁判是客户预算与错漏兜底成本。面对“灭火器 vs 砖头”的张力，应将长期技术北极星（通用持续学习）与短期切入点（一个高频、可人工兜底的具体工作流）解耦，先用真实业务流滚出反馈与数据，再反哺底层通用引擎。

4. 模型狂飙时代，应用层须守住“非模型替代资产”

花数月封装的操作技能被 Opus 5.5 一夜吸收，说明专门修补模型当前短板的工程层保质期极短；而沉淀在企业侧的权限边界、真实例外规则、合规审计日志与结果验收标准，模型再升级两代也不会凭空拥有。分清哪层做厚、哪层随时交由模型接管，才是应对“苦涩教训”的生存之道。
