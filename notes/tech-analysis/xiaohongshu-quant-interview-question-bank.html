小红书量化面试题库 3–54：52 道题的完整推导与面试方法

这是一套按日发布的量化面试题。题目从概率、随机过程和最优停止，扩展到矩阵、博弈、几何、组合、算法与比较下界。本文把当前公开的第 3–54 题全部重建，并把“答案”改写成可以复述、可以检查、也能指出假设边界的解法。

原文讲解：这套题库到底在考什么

题库来自小红书账号 alpha2026 的连续笔记。当前主页公开显示第 3–54 题，共52题；第1、2题在当前主页没有出现。每张卡片只给出一道短题，下一篇笔记通常在正文里给出上一题的简短答案，评论区有时会补充证明或指出题面歧义。

题目顺序不是严格难度排序，而是把不同类型的量化直觉交错放在一起：前半段常用对称性、指标变量、递推和几何不变量；中段加入随机矩阵、布朗运动、赌徒破产、最优停止和组合计数；后半段把这些工具放进夏普率、分枝过程、模运算、游戏策略、随机游走和比较复杂度。

原帖的写法适合当作面试触发器，却不总是完整证明。例如第19题只给出13次构造，没有说明为什么12次不够；第43题的13/27依赖信息如何产生；第31题如果误读球的搬运规则，会得到错误的确定性答案。下面的每题都把这些隐含前提显式写出。

先记住三条总原则

先判断模型

看到“平均”先想指标变量或尾和；看到“直到”先想停止时间；看到“随机排列”先想对称性、记录值和顺序统计。

先问条件

“已知红球先抽完”“一个孩子是周三男孩”“十局后有3元”都是条件概率，不是普通概率。

先找不变量

博弈、几何和矩阵题往往不需要枚举。模2奇偶、模3余数、行列式展开和势函数会直接锁定答案。

面试表达模板

“我先说明随机机制和停止条件；然后定义一个最小状态或指标变量；最后用对称性、递推或不变量得到数值。若题面没有说明信息披露机制，我会给出不同机制下的答案。”

详细解答一：第3–20题

第3题：圆排列相邻差之和为16

完整题面：将整数1～9随机排列在一个圆圈上，求所有相邻两个数的差的绝对值之和等于16的概率。

答案：1/315。

先识别模型

这是一个“总变差达到下界”的圆排列问题。闭合路径中的总上升量必须等于总下降量，而1和9的跨度给出不可突破的最低成本。

逐步推导

  1. 把顺时针相邻差分成上升和下降两类。因为绕一圈回到原点，两类绝对值总和相等。
  2. 从1到9至少要上升8，再从9回到1至少下降8，所以总和至少16。
  3. 若总和恰好16，不能有任何额外折返；从1到9的两个方向都必须严格递增。
  4. 固定1的位置后，2到8分别选择放在两条单调链上，共2⁷种；恢复1在9个位置，合格数为9×2⁷。
  5. 除以9!得到1/315。

易错点与面试表达

圆周旋转是否算同一排列要先说清。这里按题目“随机排列”把9个位置区分，因此分子分母都保留位置因子。

第4题：循环赔率是否有正期望下注

完整题面：三支球队A、B、C比赛，AB、BC、CA的赔率均为1.5:3。球队实力值为正、固定且未知；实力为a、b的两队比赛胜率分别为a/(a+b)、b/(a+b)。是否存在期望为正的下注策略？

答案：存在，下注每场赔率为3的一方。

先识别模型

先把赔率换成期望利润，再利用实力模型的传递性。赔率给出的强弱关系形成闭环，和单一实力参数不可能完全一致。

逐步推导

  1. 下注1元在赔率3的一方，赢时净赚2元，输时亏1元，所以单局期望利润是3p−1。
  2. 下注B、C、A三场，真实胜率之和为 S=b/(a+b)+c/(b+c)+a/(c+a)。
  3. 令u=b/a、v=c/b、w=a/c，则uvw=1；用柯西不等式或通分可证S大于1。
  4. 总期望利润为3(S−1)，严格大于0。

易错点与面试表达

“1.5:3”可能有不同赔率口径；本题采用十进制赔率3。若赔率定义改变，先改利润公式，再保留循环不相容的核心思路。

第5题：布朗运动在(1,2)内有无穷多个零点

完整题面：求一维标准布朗运动在时间区间(1,2)内有无穷多个零点的概率。

答案：1/2。

先识别模型

这是布朗运动的击中问题。先求未来一个单位时间内是否碰到0，再用布朗运动零点在击中时刻附近无限聚集的性质。

逐步推导

  1. 给定W₁=x，未来过程等价于从x出发、运行1个时间单位的布朗运动。
  2. 由反射原理，击中0的概率是2Φ(−|x|)。不能简单用W₁和W₂异号，因为路径可能先过0再回到同号。
  3. 对x服从标准正态分布积分；把积分写成二维独立正态的扇形概率，区域占全平面的1/4。
  4. 因此总概率是2×1/4=1/2。

易错点与面试表达

“有无穷个零点”不是另一个更难的事件；对布朗运动来说，一旦在开区间内击中0，零点几乎必然在附近无限累积。

第6题：10、22、33不能表示的最大整数

完整题面：不能写成若干个非负整数10、22、33之和的最大整数是多少？

答案：111。

先识别模型

先按奇偶性拆开，再把偶数部分化成互质的5和11。奇数部分只需保留一个33，因为多出的两个33等价于3个22。

逐步推导

  1. 偶数N写成10a+22b时，除以2得到5a+11b。
  2. 5和11的最大不可表示数是5×11−5−11=39，所以最大不可表示偶数是78。
  3. 奇数表示必须使用奇数个33；3×33=33+3×22，因此所有奇数只需检查33加上一个可表示偶数。
  4. 最大不可表示奇数为33+78=111，超过它的奇偶两类都会被覆盖。

易错点与面试表达

不要直接套三元Frobenius公式；这里的奇偶结构可以把问题降成两个互质数。

第7题：6个矩形最多分几块

完整题面：6个矩形最多能将平面划分为几个区域？

答案：122。

先识别模型

这是“每加入一条曲线，边界被切成多少段就增加多少区域”的分割递推。

逐步推导

  1. 两个矩形边界最多有8个交点。
  2. 第k个矩形与前面k−1个矩形最多产生8(k−1)个互异交点。
  3. 这些交点把新矩形边界切成8(k−1)段，每段穿过一个旧区域并把它一分为二。
  4. R₁=2，故R₆=2+8(1+2+3+4+5)=122。

易错点与面试表达

122需要一般位置：不能相切、不能三条边界共点，也不能让交点重合。

第8题：5×5网格中心蚂蚁到边界

完整题面：位于5×5网格中心的蚂蚁，每次等可能向上、下、左、右走一格，走到边界停止，平均走几格？

答案：4.5步。

先识别模型

有限网格上的吸收随机游走，最重要的技巧是按对称性压缩状态，而不是给25个位置逐个列方程。

逐步推导

  1. 设中心、轴向相邻、斜向相邻三类期望步数分别为x、y、z。
  2. 中心走一步必到轴向点：x=1+y。
  3. 轴向点四个方向通向边界、中心、两个斜向点：y=1+(x+2z)/4。
  4. 斜向点两个方向出界、两个方向到轴向点：z=1+y/2。
  5. 联立得x=9/2。

易错点与面试表达

“到边界”要明确是进入边界格就停；若把边界外一格才算停止，状态和答案都会改变。

第9题：每个新数都是当前最大或最小

完整题面：将1,2,…,8随机排列，要求每个数都大于它前面的所有数，或者小于它前面的所有数，满足条件的概率是多少？

答案：1/315。

先识别模型

每个新数都是前缀最大或最小，等价于每次加入一个新的左右端点记录。

逐步推导

  1. 从后往前看，最后一个数必须是全局最大值或全局最小值。
  2. 删掉最后一个数后，剩余排列仍满足同样条件。
  3. 因此有效排列数满足aₙ=2aₙ₋₁，a₁=1，得到a₈=2⁷。
  4. 总排列数为8!，概率为2⁷/8!=1/315。

易错点与面试表达

不要把“比前一个大/小”误读成局部相邻比较；题面是比前面所有数都大或都小。

第10题：均匀取数直到累计和超过1

完整题面：每次均匀随机取[0,1]中的一个数，累计和大于1时停止，求停止时累计和的期望。

答案：e/2。

先识别模型

这是更新过程与停止时间问题。关键是先求停止次数的尾概率，再用Wald恒等式把随机次数转成累计和。

逐步推导

  1. N是第一次使X₁+…+Xₙ大于1的次数。
  2. N大于k等价于k个均匀数的和不超过1，这个区域是单位立方体中的单纯形，体积为1/k!。
  3. 所以E[N]=Σₖ≥₀1/k!=e。
  4. 每个X的期望是1/2，故E[停止时累计和 ]=E[N]/2=e/2。

易错点与面试表达

Wald恒等式需要独立同分布和可积停止时间；本题满足，换成依赖抽样时不能直接套。

第11题：红球先抽完时剩余蓝球

完整题面：袋中有m个红球和n个蓝球，不放回随机抽取；如果红球先被抽完，求此时平均还剩几个蓝球？

答案：(m+n)/(m+1)。

先识别模型

这是条件顺序统计。先算末尾蓝球串长度的无条件期望，再除以“红球先耗尽”的概率。

逐步推导

  1. 把所有球随机排列，K表示最后一个红球之后连续蓝球的数量。
  2. 任意指定蓝球排在全部m个红球之后的概率是1/(m+1)，所以E[K]=n/(m+1)。
  3. 红球先抽完等价于最后一球是蓝球，概率为n/(m+n)。
  4. 因此E[K｜红球先抽完]=(n/(m+1))/(n/(m+n))=(m+n)/(m+1)。

易错点与面试表达

直接报n/(m+1)漏掉了条件，只得到无条件尾部长度。

第12题：73人的相同生日配对

完整题面：在某年365天出生的人中随机抽取73人，平均有几对人的生日相同？

答案：7.2。

先识别模型

题目问相同生日“配对数”的期望，不是至少出现一对的概率。

逐步推导

  1. 对每一对人定义指标Iᵢⱼ，生日相同则为1，否则为0。
  2. E[Iᵢⱼ]=1/365。
  3. 共有C(73,2)对，线性相加得到C(73,2)/365=7.2。

易错点与面试表达

配对事件之间不独立没关系；只有问“至少一对”时才需要容斥。

第13题：到达3前访问−2的次数

完整题面：从0开始的随机游走每次等可能加1或减1，求首次到达3之前访问−2的次数的期望。

答案：6。

先识别模型

把访问−2的次数拆成“是否先到−2”和“到达后会回来多少次”两个部分。

逐步推导

  1. 在−2和3之间做赌徒破产计算，从0先到−2的概率是3/5。
  2. 从−2离开后，向−3走会在到3前必然返回−2；向−1走则以4/5概率先回−2。
  3. 回返概率为1/2+(1/2)(4/5)=9/10。
  4. 包含第一次访问的几何期望为1/(1−9/10)=10。
  5. 总期望为3/5×10=6。

易错点与面试表达

不要把“到达−2一次”与“访问次数”混为一谈；访问后可以反复返回。

第14题：三根不均匀绳子测7分钟

完整题面：三条不均匀绳子，每条恰好燃烧8分钟，如何用它们计时7分钟？

答案：7分钟。

先识别模型

不均匀绳子不能靠长度计时，但从两端同时燃烧一定把剩余燃烧时间减半。

逐步推导

  1. 时刻0：第一根两端点燃，第二、三根各点一端。
  2. 第4分钟第一根烧完；点燃第二根另一端。
  3. 第二根此前还剩4分钟单端时间，改两端后2分钟烧完，即第6分钟。
  4. 第三根已单端烧过6分钟，只剩2分钟单端时间；第6分钟点另一端，再过1分钟烧完。

易错点与面试表达

不能假定绳子长度均匀；可靠的是“整根单端8分钟”和“剩余部分两端减半”。

第15题：圆心在自交四边形内部

完整题面：圆周上顺时针随机取4个点，依次记为A、B、C、D，求圆心位于自交四边形ACBD内部的概率。

答案：1/4。

先识别模型

自交四边形的“内部”容易引起歧义。先判断圆心是否在四点凸包内，再利用对称性判断它落在哪个三角形。

逐步推导

  1. 四个圆周点全落在某个半圆内的概率是1/2，因此圆心在普通凸四边形内的概率是1/2。
  2. 两条对角线把凸四边形分成四个三角形。
  3. 自交路径ACBD对应其中相对的两块；在凸包事件内，圆心落入这两块的概率由标签对称性为1/2。
  4. 总概率为1/2×1/2=1/4。

易错点与面试表达

若采用不同的自交多边形“内部”定义，必须先说明采用偶奇规则还是绕数规则；原题默认的是两瓣区域。

第16题：9枚对10枚硬币是否公平

完整题面：A、B分别投9枚、10枚硬币；如果B的正面数严格多于A则B赢，否则A赢。这个游戏公平吗？

答案：公平。

先识别模型

最后一枚硬币只在前9枚平局时有作用。把样本按前9枚的胜负分成三类即可。

逐步推导

  1. P(B前9多)=P(A前9多)，因为两组9枚硬币同分布。
  2. B前9少时，第10枚正面最多追平，仍由A赢。
  3. 前9枚平局时，第10枚正面B赢、反面A赢，各占一半。
  4. 所以两方总胜率相同，游戏公平。

易错点与面试表达

若规则改成“平局算和局”或“B多或相等都赢”，结论会变；这里是严格多于。

第17题：绳子对折n次后从中间剪

完整题面：一根绳子对折n次，从中间剪开，展开后有几段？

答案：2ⁿ+1段。

先识别模型

折叠把一刀复制到多个层，展开后数的是不同切点，段数再比切点多1。

逐步推导

  1. 对折n次后有2ⁿ层。
  2. 从中间剪开，相当于在原绳上产生2ⁿ个内部切点。
  3. k个互异内部切点把一根连通绳子分成k+1段。
  4. 答案为2ⁿ+1。

易错点与面试表达

若刀口正好落在折痕，多个切点可能重合；题目默认普通中间位置。

第18题：随机子集形成链

完整题面：在{1,2,3,4,5}的子集中有放回地随机取3个集合A、B、C，求A⊆B⊆C的概率。

答案：1/32。

先识别模型

把集合包含关系逐元素拆开，五元素问题变成五个独立的三比特状态问题。

逐步推导

  1. 一个元素在A、B、C中的状态共有8种。
  2. A⊆B⊆C只允许000、001、011、111四种单调状态。
  3. 单个元素满足条件的概率是4/8=1/2。
  4. 五个元素独立，概率为(1/2)⁵=1/32。

易错点与面试表达

A、B、C是随机子集，不是从集合里抽出的三个元素；这是本题最常见的读题错误。

第19题：只有“至少一位正确”的三位密码锁

完整题面：三位数字密码锁每次尝试后只能知道是否至少有一个数字与位置都正确，至少尝试多少次才能保证找到密码？

答案：最坏情况13次，而且12次不可能。

先识别模型

这是带“是否至少一位位置正确”反馈的自适应识别问题。先识别数字集合，再识别排列位置。

逐步推导

  1. 依次试000到999。试ddd时，反馈“是”恰好说明数字d出现在密码的某个对应位置，因此十次后知道密码使用了哪些不同数字。
  2. 三个不同数字a、b、c时，取未出现数字d，试abd、dab、bda，三位反馈可区分六种排列。
  3. 两个不同数字时，用aad、ada、daa区分六种重复位置。
  4. 为什么不能12次：连续6次全否定后，每个位置至少还有4个候选，共64个状态；剩余6次反馈若要完成识别，下一次必须把64精确分成32/32，但一次询问只能产生16、28或37个“是”状态。

易错点与面试表达

若反馈只说“数字出现过但位置不明”，或者密码允许前导零，策略需要重新定义；面试时先确认反馈语义。

第20题：抽到比上一个数大的数就停

完整题面：每次均匀随机取[0,1]中的一个数；如果它大于上一个数就停止，求最后一个数的期望。

答案：2−e/2≈0.64086。

先识别模型

当前状态只有“上一个数x”，所以可以写一维递推函数，而无需记住全部历史。

逐步推导

  1. 定义f(x)：已看到上一数x后，最终停止数的期望。
  2. 下一次u≤x则继续，贡献f(u)；u>x则停止，贡献u。
  3. 所以f(x)=∫₀ˣf(u)du+∫ₓ¹u du，求导得f′=f−x。
  4. 由f(0)=1/2解得f(x)=1+x−eˣ/2。
  5. 初始上一数X₁均匀，再积分得到2−e/2。

易错点与面试表达

第10题求的是最终累计和，第20题求的是最后一个增量；数值相同不代表随机变量相同。

详细解答二：第21–39题

第21题：随机±1矩阵行列式的方差

完整题面：A是n×n矩阵，矩阵元素独立地随机取+1或−1，求det(A)的方差。

答案：n!。

先识别模型

随机±1矩阵题用行列式排列展开，核心是独立均值为0的变量会让交叉项消失。

逐步推导

  1. det(A)=Σσ sgn(σ)Πᵢaᵢ,σ(i)，均值为0。
  2. 平方后出现排列σ、τ的交叉项。
  3. 若σ≠τ，至少有一个矩阵元素只出现一次，期望为0。
  4. 只有σ=τ时每个元素都平方为1，共n!项，因此方差为n!。

易错点与面试表达

若元素不独立、不是对称±1，交叉项未必全消失，不能照搬n!。

第22题：最大值加最小值大于1

完整题面：在[0,1]上均匀随机取n个数，求最大值与最小值之和大于1的概率。

答案：1/2。

先识别模型

利用Xi→1−Xi的分布对称性，不需要求最大值和最小值的联合密度。

逐步推导

  1. 令M=maxXi、m=minXi。
  2. 变换后最大值和最小值之和变成2−(M+m)。
  3. 原分布与变换后相同，所以P(M+m>1)=P(M+m<1)。
  4. 连续分布下等号概率为0，故答案1/2。

易错点与面试表达

离散分布会有M+m=1的正概率，此时不能直接说两边各一半。

第23题：十局后有3元且中途未破产

完整题面：有1元的赌徒，每局以相同概率赢1元或输1元。已知10局后有3元，求他中途没有破产的概率。

答案：3/7。

先识别模型

这是给定终点的随机游走路径计数，反射原理负责删除“曾经破产”的坏路径。

逐步推导

  1. 从1到3的净增量是2，十局中必须6胜4负，共C(10,4)=210条路径。
  2. 曾经到过0的路径，在第一次到0处反射，和从−1到3的路径一一对应。
  3. 从−1到3需7胜3负，坏路径数C(10,3)=120。
  4. 安全路径90条，条件概率90/210=3/7。

易错点与面试表达

分母是“十局后有3元”的条件路径数，不是全部2¹⁰条路径；若问联合概率，答案会是90/2¹⁰。

第24题：最多掷3次公平骰子的最优停止价格

完整题面：最多投3次公平骰子，可以随时停止并以最后一次点数为收益，求这个游戏的公平价格（最优期望收益）。

答案：14/3。

先识别模型

有限次数最优停止必须倒推，每一层都比较“现在拿”与“继续的期望”。

逐步推导

  1. 最后一次只能接受点数，价值3.5。
  2. 还剩两次时，1、2、3小于3.5，重掷；4、5、6停止，价值4.25。
  3. 还剩三次时，1到4重掷，5、6停止，价值(4×14/3+5+6)/6=14/3。

易错点与面试表达

不能把三次骰子的均值简单相加；允许停止意味着每一步都在做最大值比较。

第25题：布朗运动退出±1区间的条件时间

完整题面：Wₜ是一维标准布朗运动，τ=inf{t:Wₜ=1或Wₜ=−1}，求E[τ | Wτ=1]。

答案：1。

先识别模型

布朗运动退出区间的时间与向上/向下出口在对称性下同分布，也可以用边值问题直接算。

逐步推导

  1. 从0出发到+1和−1的概率各为1/2。
  2. 反射x→−x把向上出口路径映到向下出口路径，同时保持退出时间。
  3. 因此条件退出时间期望等于无条件Eτ。
  4. 鞅Wₜ²−t在τ处给出Eτ=E[Wτ²]=1。

易错点与面试表达

若起点不是0或边界不是对称的±1，条件退出时间一般不再相同。

第26题：三个变量相关系数下界

完整题面：X、Y、Z三个随机变量两两相关系数均为ρ，求ρ的最小值。

答案：−1/2。

先识别模型

三个相关系数能否同时存在，取决于相关矩阵是否半正定。

逐步推导

  1. 相关矩阵对角为1、非对角为ρ。
  2. 其特征值是1−ρ、1−ρ、1+2ρ。
  3. 半正定要求ρ≤1且ρ≥−1/2。
  4. 令X+Y+Z=0可构造ρ=−1/2，说明下界可达。

易错点与面试表达

只给特征值下界还不完整；最好同时给出达到下界的构造。

第27题：12枚硬币一枚异重

完整题面：12枚外观相同的硬币中只有1枚质量不同，用天平至少称几次才能保证找出这枚硬币？

答案：3次称重。

先识别模型

12枚异重硬币是经典三结果信息编码问题。三次称重有27种结果，足以覆盖24种“硬币编号×轻重”状态。

逐步推导

  1. 第一次把硬币分成4、4、4三组并称两组。
  2. 平衡说明异常在未称组；不平衡则知道异常在盘上两组且轻重方向受约束。
  3. 第二次重新安排候选硬币与已知正常硬币，使三种结果继续近似三分。
  4. 第三次在剩余候选中确认编号和轻重。

易错点与面试表达

信息容量27>24只是必要条件，不是策略本身；必须维护每个分支的候选状态。

第28题：n维单位球面两点弧长期望

完整题面：在n维单位球面上均匀随机取两个点，求两点之间较短大圆弧的期望长度。

答案：π/2。

先识别模型

球面弧长题只用到对跖反射对称，不需要知道高维球面的具体密度。

逐步推导

  1. 记两点较短大圆弧长为L，单位球面上L∈[0,π]。
  2. 把第二点反射到对跖点，弧长变为π−L，分布保持不变。
  3. 所以E[L]=E[π−L]=π/2。

易错点与面试表达

若问的是欧氏直线距离或指定非大圆路径，答案不是π/2；要先确认“弧长”的定义。

第29题：出现奇数前出现过所有偶数

完整题面：反复投掷公平骰子，求在第一次投出奇数之前已经投出过所有偶数面2、4、6的概率。

答案：1/20。

先识别模型

停止条件只依赖各面第一次出现的相对顺序，因此可以把无限投掷压成一次随机排列。

逐步推导

  1. 六个面的首次出现顺序等可能，共6!种。
  2. 在第一次奇数出现前见过2、4、6，等价于这三个偶数面占据首次出现顺序的前三位。
  3. 前三位内部有3!种，后三个奇数内部有3!种。
  4. 概率为3!×3!/6!=1/20。

易错点与面试表达

重复投掷次数不需要计算；只看第一次出现时间的排序即可。

第30题：100!的末位非零数字

完整题面：求100!的最后一位非零数字。

答案：4。

先识别模型

末位非零数字由2和5配对产生的尾零控制。

逐步推导

  1. 先统计100!中2和5的幂次，成对的2×5全部贡献尾零。
  2. 2的数量更多，去掉配对后还剩多余的2。
  3. 对剩余因子按模10循环相乘，得到末位非零数字4。

易错点与面试表达

直接对100!取模10会得到0，必须先剥离尾零。

第31题：盒中球随机搬运直到集中

完整题面：n个盒子中每个盒子初始有1颗球；每次随机选一个有球的盒子取出1颗球，再随机放到另一个盒子，直到所有球集中到一个盒子，求平均操作次数。

答案：n(n−1)/2。

先识别模型

这是一个用势函数求吸收时间的盒中球过程。势函数选成不同盒子之间的球对数，终止状态的势为0。

逐步推导

  1. 设第i个盒有xᵢ个球，定义S为所有i小于j的xᵢxⱼ之和。
  2. 初始每盒1球，S₀=C(n,2)；所有球集中后S=0。
  3. 一次搬运只改变源盒和目标盒相关的跨盒球对；按题目的随机源、随机目标规则，条件期望漂移为−1。
  4. 所以Sₜ+t是鞅，停止时E[T]=S₀=n(n−1)/2。

易错点与面试表达

如果把目标盒误读成“只能放到已有球的盒子”，漂移会改变，甚至会误以为每步都减少一个非空盒。

第32题：三个六面骰子和一个二十面骰子谁大

完整题面：分别投掷三个六面骰子并把点数相加，再投一个20面骰子比较大小。这个游戏公平吗？

答案：公平。

先识别模型

公平性用保持分布、交换胜负的反射映射证明，而不是比较两个骰子总期望。

逐步推导

  1. 三骰和X的范围是3到18，二十面骰Y的范围是1到20。
  2. 映射(X,Y)→(21−X,21−Y)保持联合分布。
  3. 它把X>Y映成X<Y，因此双方胜率相等。
  4. 平局概率为1/20，双方各胜19/40。

易错点与面试表达

“公平”只表示胜率相同；不代表没有平局，也不代表两个随机变量期望相同。

第33题：圆内两点与圆心构成钝角三角形

完整题面：在圆内均匀随机取两个点，与圆心组成三角形，求这个三角形为钝角三角形的概率。

答案：3/4。

先识别模型

三角形的钝角可能在圆心，也可能在两个随机点。必须把三种互斥事件都算上。

逐步推导

  1. 圆心角大于90°的概率是1/2。
  2. 圆心角小于90°时，设两点半径为r、s、夹角为θ；A处钝角条件为r小于s cosθ。
  3. 圆内均匀点的半径密度为2r，积分后A处钝角概率1/8，B处同样为1/8。
  4. 总概率1/2+1/8+1/8=3/4。

易错点与面试表达

若两点是在圆周上而非圆内均匀抽取，半径不再随机，答案会改变；必须按原题区分。

第34题：2ⁿ的首位是1的频率

完整题面：求2ⁿ的十进制首位是1的长期频率（原题写作“概率”）。

答案：lg2≈0.3010。

先识别模型

这是2的幂的首位数字问题，本质是无理数旋转的等分布。

逐步推导

  1. 2ⁿ的首位为1等价于n·lg2的小数部分落在[0,lg2)。
  2. lg2是无理数，序列n·lg2模1等分布。
  3. 长期频率等于目标区间长度lg2≈0.3010。

易错点与面试表达

这里的“概率”应理解为n取很大范围时的自然密度，不是每个n独立随机。

第35题：掷骰子直到出现3，期间大于3的点数期望

完整题面：反复投掷公平骰子，直到第一次投出3；求在此之前投出的点数中大于3的次数的期望。

答案：3。

先识别模型

把“等到3要多久”和“期间出现哪类点数”拆开。

逐步推导

  1. 出现3前的失败次数期望为(1−1/6)/(1/6)=5。
  2. 给定一次失败，点数在1、2、4、5、6中均匀。
  3. 其中大于3的有4、5、6三个，占3/5。
  4. 期望次数为5×3/5=3。

易错点与面试表达

如果把“重复出现的点数也记录”改成只统计不同点数，答案会不同；需确认计数口径。

第36题：n个椭圆最多分几块

完整题面：n个椭圆最多能将平面划分成几个区域？

答案：2n²−2n+2。

先识别模型

椭圆和矩形的递推相同，但两条椭圆最多只有4个交点。

逐步推导

  1. 第一个椭圆产生2个区域。
  2. 第k个椭圆最多与前面k−1个椭圆各交4次。
  3. 新增区域数为4(k−1)。
  4. 求和得到2+4(1+…+n−1)=2n²−2n+2。

易错点与面试表达

相切、三曲线共点会减少区域；题目问最大值，所以采用一般位置。

第37题：累计和超过1时最后一个数的期望

完整题面：每次均匀随机取[0,1]中的一个数，累计和大于1时停止，求停止时最后一个抽到的数的期望。

答案：2−e/2。

先识别模型

这是第10题的“最后增量”版本，状态仍然是当前累计和，但兑现的收益改成最后一次抽到的数。

逐步推导

  1. 上一累计和为x时，下一次u≤x继续，u>x就停止并得到u。
  2. 因此f(x)=∫₀ˣf(u)du+∫ₓ¹u du。
  3. 解微分方程得到f(x)=x+1−eˣ/2。
  4. 对初始均匀x平均，结果2−e/2。

易错点与面试表达

第10题的收益是停止时总和，第37题的收益是最后一个抽样值；两者数值相同是结构巧合。

第38题：1×2骨牌铺满2×n地板

完整题面：用n个1×2的砖铺满2×n的地板，有几种铺法？

答案：Fₙ₊₁。

先识别模型

这是最经典的局部递推：最左边只可能放一块竖砖或两块横砖。

逐步推导

  1. 竖放一块后剩2×(n−1)棋盘。
  2. 横放必须成对出现，剩2×(n−2)棋盘。
  3. 所以Tₙ=Tₙ₋₁+Tₙ₋₂。
  4. T₀=T₁=1，故Tₙ=Fₙ₊₁。

易错点与面试表达

不同教材对F₁、F₂的编号不同，答案最好同时写递推和初值。

第39题：记录偶数、1或3清空、5停止

完整题面：反复投公平骰子，只记录偶数；出现1或3时清空记录，出现5时停止，求停止时平均记录了几个偶数。

答案：1。

先识别模型

清空操作使过程重置到状态0，不能把它当作普通“直到5出现”的几何分布。

逐步推导

  1. 记录偶数的概率为1/2，清空概率为1/3，停止概率为1/6。
  2. 设当前记录k个偶数，写出F(k)=k/6+F(0)/3+F(k+1)/2。
  3. 求线性解得到F(0)=1。

易错点与面试表达

记录的偶数不是累计总数；出现1或3会清空此前记录。

第40题：公平骰子第一次出现重复

完整题面：反复投一个公平六面骰子，直到某个面已经出现过两次，平均要投多少次？

答案：1223/324≈3.7747。

先识别模型

第一次重复是生日碰撞问题，尾和公式最简洁。

逐步推导

  1. T大于k表示前k次骰子都互不相同。
  2. 概率依次为1、1、5/6、5·4/6²，直到前6次全不同。
  3. 把这些尾概率相加，得到1223/324≈3.7747。

易错点与面试表达

“某个指定面出现两次”和“任意面出现重复”是两个不同问题。

第41题：7球放5盒，非空盒子期望

完整题面：将7个球随机放入5个盒子，平均有多少个盒子非空？

答案：5[1−(4/5)⁷]≈3.9514。

先识别模型

盒子是否非空适合用指标变量；相关性不妨碍期望相加。

逐步推导

  1. 某个指定盒子为空的概率是(4/5)⁷。
  2. 它非空的期望指标是1−(4/5)⁷。
  3. 五个盒子相加，得到5[1−(4/5)⁷]≈3.9514。

易错点与面试表达

若问恰好r个非空盒子，则不能只用期望线性性，要用容斥或占位数。

第42题：累计和超过1就归零的最优停止

完整题面：每次均匀随机取[0,1]并累加；理性的人可以随时停止并以当前和为分数，但如果累计和超过1则得0分。求最优策略下的平均得分。

答案：(√2−1)e^(√2−1)≈0.62678。

先识别模型

这是连续抽样的最优停止。当前累计和高到某个阈值后停止，低于阈值则继续。

逐步推导

  1. 当前和为x时，停止价值是x，继续价值是∫ₓ¹V(t)dt。
  2. 设阈值a，临界点满足a=(1−a²)/2，得到a=√2−1。
  3. 阈值以下V′(x)=−V(x)，结合V(a)=a得到V(0)=a·eᵃ。
  4. 所以最优平均得分为(√2−1)e^(√2−1)≈0.62678。

易错点与面试表达

阈值a不是最终答案；a是“何时停”的界，V(0)才是初始平均得分。

第43题：周三出生的男孩

完整题面：老王有两个孩子，其中一个是星期三出生的男孩，求另一个孩子也是男孩的概率。

标准“至少一个周三男孩”模型答案：13/27。

先识别模型

这是信息机制版本的条件概率题。先明确是随机选家庭，还是随机指出某个孩子。

逐步推导

  1. 标准家庭模型中，每个孩子有14种性别×星期类型。
  2. 至少一个周三男孩的家庭数为14²−13²=27。
  3. 两个都是男孩且至少一个周三男孩的家庭数为7²−6²=13。
  4. 概率为13/27。

易错点与面试表达

若先随机指定一个孩子并知道他是周三男孩，另一个孩子性别仍独立，答案是1/2。

第44题：分状态夏普率都高，整体一定高吗

完整题面：策略A在高波动市场和低波动市场中的夏普率都高于策略B，A在全市场的夏普率一定高于B吗？

答案：不一定。

先识别模型

夏普率的分母是波动，不是均值；合并分组时还会增加“状态均值之间的波动”。

逐步推导

  1. 合并方差=组内方差的加权平均+组均值之间的方差。
  2. A可能在每个状态内夏普率都高于B，但A的两个状态均值相距更远。
  3. 合并后A的额外状态波动更大，整体夏普率可能反而更低。
  4. 因此分组排序不能直接推出全市场排序。

易错点与面试表达

回答时最好给出状态权重、条件均值和条件方差；只说“辛普森悖论”还不够。

第45题：细菌最终灭绝概率

完整题面：细菌每小时有25%概率死亡、25%概率保持1个、50%概率分裂成2个；初始1个细菌，求最终灭绝概率。

答案：1/2。

先识别模型

这是Galton–Watson分枝过程。灭绝概率是子代生成函数的最小不动点。

逐步推导

  1. 子代数为0、1、2的概率分别是1/4、1/4、1/2，生成函数f(s)=1/4+s/4+s²/2。
  2. 若一个细菌最终灭绝，则它的每个子代谱系都必须灭绝，所以q=f(q)。
  3. 解得q=1/2或1，取[0,1]内最小根，得到1/2。
  4. 平均子代数1.25>1只说明存在正概率永不灭绝。

易错点与面试表达

不要因为期望子代数大于1就断言灭绝概率为0；随机分枝仍可能一开始就死亡。

第46题：100次抛硬币最长连续正面

完整题面：连续投100次公平硬币，最长连续正面的期望长度大概是多少？

面试说约6；精确期望约5.99178。

先识别模型

最长连续正面是游程问题。log₂100只给数量级，精确期望要跟踪当前末尾连续长度。

逐步推导

  1. 固定阈值k，状态j表示目前末尾有j个连续正面且尚未达到k。
  2. 反面把状态置0，正面把j推进到j+1，达到k的路径丢弃。
  3. 得到P(L₁₀₀≥k)后，用E[L]=Σₖ≥1P(L₁₀₀≥k)。
  4. 精确结果约5.99178，面试可说约6并说明这是近似。

易错点与面试表达

不能直接把log₂100当成期望；连续段之间会重叠，且尾部有明显概率质量。

第47题：两个2和八个1的随机删减

完整题面：有2个数字2和8个数字1；每次等可能选一个当前数字，选到2就把它减为1，选到1就删除。平均多少次后刚好没有2？

答案：47/6。

先识别模型

这是有限状态马尔可夫递推，关键是区分“2被选中变1”和“1被选中被删”。

逐步推导

  1. 状态(a,b)表示有a个2、b个1。
  2. 抽到1以b/(a+b)进入(a,b−1)。
  3. 抽到2以a/(a+b)进入(a−1,b+1)。
  4. 边界E(0,b)=0；解得E(2,b)=5/2+2b/3。
  5. 代入b=8得47/6≈7.8333。

易错点与面试表达

如果把2选中后直接删除，或者停止条件改成所有数字都消失，都是另一道题。

第48题：1到2ⁿ−1的二进制1总数

完整题面：将1到2ⁿ−1的所有整数写成二进制，一共出现多少个“1”？

答案：n·2ⁿ⁻¹。

先识别模型

按二进制位计数，不要逐个整数展开。

逐步推导

  1. 0到2ⁿ−1正好是全部n位二进制串。
  2. 固定任意一位，恰有2ⁿ⁻¹个串在该位为1。
  3. 共有n位，总数n·2ⁿ⁻¹。
  4. 去掉全零串不会改变“1”的总数。

易错点与面试表达

若区间不是完整的2次幂边界，就不能直接使用每一位一半的对称性。

第49题：100个骰子点数和被7整除

完整题面：投100个公平六面骰子，求点数总和被7整除的概率。

答案：1/7+1/(7·6⁹⁹)。

先识别模型

模7递推只需维护“当前和模7为0”的概率，不必维护全部7个状态。

逐步推导

  1. 设pₙ为n个骰子和模7为0的概率。
  2. 若上一轮余数非0，六个点数中恰有一个能补成0，所以pₙ₊₁=(1−pₙ)/6。
  3. 初值p₁=0，解递推得pₙ=1/7+(−1)ⁿ/(7·6ⁿ⁻¹)。
  4. n=100时为1/7+1/(7·6⁹⁹)，几乎等于1/7。

易错点与面试表达

“几乎是1/7”是数值近似，严格答案还带一个指数小修正。

第50题：随机排列后删除下降项

完整题面：将n个互不相同的数随机打乱排成一列，从前往后依次删除小于自己前一个数的元素，平均剩下几个数？

答案：Hₙ=1+1/2+…+1/n。

先识别模型

删除小于前一个数的元素后留下的是前缀最大值，也叫记录值。

逐步推导

  1. 第k个位置不被删，当且仅当它大于前面k−1个数。
  2. 随机排列中，前k个数的最大值等可能出现在这k个位置中的任意一个，所以概率1/k。
  3. 定义保留指标并相加，期望为Hₙ=1+1/2+…+1/n。
  4. Hₙ约为log n+γ，说明保留数量增长很慢。

易错点与面试表达

若删除后重新把剩余元素紧缩再比较，过程定义会变；这里按原排列的前缀规则理解。

第51题：100根火柴的非对称取法博弈

完整题面：有100根火柴，先手每次可以取1根或7根，后手每次可以取2根或3根，取到最后一根的人获胜，谁必胜？

答案：后手必胜。

先识别模型

这是一个带不同取数集合的组合博弈，后手维护模3不变量。

逐步推导

  1. 先手第一次取1或7后，后手取3，使剩余变成96或90，都是3的倍数。
  2. 之后先手取1或7，在模3下都等价于取1。
  3. 后手取2，把剩余数恢复成3的倍数。
  4. 不断重复，最终先手面对3、6、9等倍数，后手拿到最后一根。

易错点与面试表达

要说明取不出7时的末局规则；在通常“只能取剩余数量以内”的规则下，后手仍可用取2完成末局。

第52题：四枚硬币能否变成边长2正方形

完整题面：有4枚硬币，初始放在单位正方形四个顶点。每一步任选两枚，把其中一枚关于另一枚作中心对称移动。能否经过有限次操作让4枚硬币成为边长2正方形的四个顶点？

答案：不能。

先识别模型

中心对称移动保持每枚硬币的坐标奇偶类，这是一个模2不变量。

逐步推导

  1. 初始单位正方形顶点分别属于(0,0)、(1,0)、(1,1)、(0,1)四种奇偶类。
  2. P关于Q中心对称后P′=2Q−P，模2下P′与P相同。
  3. 所以四枚硬币始终各占一个奇偶类。
  4. 整数坐标的边长2正方形四顶点属于同一奇偶类，和初始状态矛盾。

易错点与面试表达

不变量是逐枚硬币保持的，不是只看四枚硬币整体的质心；目标正方形默认顶点仍在整数格点上。

第53题：环上随机游走走完所有n个点

完整题面：圆周上有n个点，从一个点出发，每次等可能移动到相邻点，平均多少步能走遍所有点？

答案：n(n−1)/2。

先识别模型

环上随机游走的已访问集合始终是连续弧段，可以逐次计算“扩张一个新点”的等待时间。

逐步推导

  1. 刚访问到k个连续点且位于端点时，把两侧未访问邻点看成吸收边界−1和k。
  2. 从端点对应的0出发，简单随机游走到任一边界的期望时间是(0+1)(k−0)=k。
  3. 从1个点扩张到2个点耗时1，从2到3耗时2，依此类推。
  4. 总期望为1+2+…+(n−1)=n(n−1)/2。

易错点与面试表达

这不是独立地等待每个点首次出现；已访问区域的连续性才是可以递推的原因。

第54题：2n个数找最大值和最小值

完整题面：给定一个包含2n个数的数组，能否用少于3n次比较找出最大值和最小值？

答案：可以，3n−2次比较，且最优。

先识别模型

同时找最大值和最小值时，先让一次比较同时产生一个局部大者和一个局部小者。

逐步推导

  1. 2n个数两两比较，n次比较得到n个局部大者和n个局部小者。
  2. 全局最大值只可能在局部大者中，再比较n−1次。
  3. 全局最小值只可能在局部小者中，再比较n−1次。
  4. 总计n+(n−1)+(n−1)=3n−2次。

易错点与面试表达

若只问“少于3n”，给出构造即可；若问最优性，再说明每个非极值元素都需要留下胜负证据。

术语和方法速查

指标变量把事件写成0/1变量，用期望线性性避开复杂联合分布。
尾和公式非负整数随机变量满足E[T]=Σₖ≥₀P(T>k)，适合首次重复和停止时间。
反射原理把越界路径与镜像路径对应，用来算破产概率和条件路径数。
鞅/势函数找一个单步条件期望不变的量，再用终点势函数反推停止时间。
最优停止每一步比较立即收益与继续的期望收益，通常形成阈值策略。
等分布无理数旋转的nα小数部分均匀铺开，首位数题依赖这一点。
信息机制条件概率中“事实如何被观察到”与事实本身同样重要。

边界、歧义与校正

需要特别注意

第31题的盒子转移规则、第43题的信息披露机制、第51题取不出规定数量时的规则，都应在面试中先澄清。规则未定义时，给条件化答案比背唯一数字更可靠。

  • 第20、37题原帖公式有简写，但最终答案2−e/2正确。
  • 第42题阈值是√2−1，初始最优价值才是(√2−1)e^(√2−1)。
  • 第46题“约6”是口头近似，精确期望约5.99178。
  • 第50题Hₙ依赖“按原排列前缀比较”的删除规则。
  • 第54题3n−2是2n个元素同时找极值的经典最优比较数。

把题库变成可迁移能力

压缩到局部状态

盒子球、随机游走、最长游程和博弈题都先把历史压成当前状态；状态足够才可以递推。

寻找可控势函数

非空盒子、生日配对、记录最大值用指标变量；球盒过程、随机游走和称重题用势函数。

把统计数字连回机制

周三男孩、夏普率和赔率循环说明，抽样协议、分层权重和信息生成机制决定数字能否比较。

上界之外还要下界

密码锁和比较问题不仅要说明怎么做到，还要说明为什么不能更少。
