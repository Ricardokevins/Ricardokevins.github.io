苏煜谈Agent技术演进、OpenClaw现象与未来发展

本期背景与内容导览

本期是张小珺对俄亥俄州立大学计算机系教授、NeoCognition创始人苏煜的技术访谈。节目以苏煜自己的研究路径为线索，回顾Agent从逻辑系统、深度强化学习与语义解析，到大语言模型驱动的Language Agent的演进，再讨论OpenClaw现象、专业化智能、创业和社会影响。以下内容以节目转录与shownotes为依据；历史评价、行业判断和未来预测均保留为嘉宾观点，未作外部事实核验。 苏煜用“记忆”和“自主性”贯穿这条技术史。早期专家系统把专家知识写成逻辑规则，再由推理引擎回答问题，受到知识获取成本和逻辑表达能力的限制。2000年以后，一条路线用神经网络和深度强化学习，在游戏等边界清晰、可反复试验的环境中学习感知到动作的映射；另一条语义解析路线把人说的话转成数据库、知识图谱或网站能够执行的形式化表示。前者仍受任务范围、样本效率和固定计算方式限制，后者则为后来用语言操纵数字世界提供了研究积累。2020年以后，大语言模型提供了跨任务的先验；苏煜所说的“语言脚手架”，是用语言及代码等符号表示承载理解、推理、计划和行动，而不只是增加一个聊天界面。 对近三年工作的回顾明显带有苏煜的个人研究视角：他明确说自己会更熟悉Computer Use Agent，也不可能穷尽所有工作。对话从Chain of Thought、ReAct、工具使用、网页与桌面环境，谈到视觉感知和像素级操作，再转入Coding为何可能打通不同数字界面。他把OpenClaw的走红解释为交互方式、持续在线形态和权限开放共同促成的范式传播，并将其与ChatGPT时刻类比；这是他对行业进程的解释，不是“底层毫无技术进步”或“开放权限没有风险”的客观定论。 后半场将技术判断连接到NeoCognition的创业方向。苏煜认为，通用模型能够给出看似合理的答案，却还不能像人类专家一样，在真实岗位中持续学会组织规则、软件操作、工作流、行动后果和人际关系。他把这套关于具体“小世界”的内部表征称为广义世界模型，把学习目标、学习过程与预期结果串成：持续学习构建世界模型，专业化智能成为结果，可靠性、速度和成本效益是期望改善的指标。公司中短期关注Specialized Intelligence，但目标不是预先写好HR、财务等单个角色，而是研究跨环境的通用学习方法。访谈没有披露可复现的训练算法或效果数据，因此这是一条研究主张，而非已经验证的产品能力。 节目还保留了苏煜从语义解析转向Agent、从微软到高校再到创业的个人解释，以及4000万美元种子轮、融资节奏和投资环境的自述。最后，他预测持续学习将在未来几年取得解决性进展，同时把更现实的社会风险落在岗位替代与收益分配，而非只讨论存在性风险。所有这些判断均应与节目中的亲历、引述和审读者的独立分析分开阅读。

00:03:30–00:12:38Agent技术史第一阶段：基于逻辑的Agent及其局限

  • 整个AI agent的一个历史，它是怎么一步步发展到现在的？它又是一个过去多少年的，一个时间轴呀？

主持人请苏煜从头梳理Agent的技术史。苏煜给出的工作定义包含三个条件：它是有边界的实体，在某种环境中活动，并为达成目标采取有目的的行动。动物和人也满足这个宽定义，因此Agent并不是大模型时代才出现的概念。

他把1950年代至1990年代的主线称为Logical Agent。以专家系统为例，工程师先采访领域专家，把知识写成一阶谓词逻辑等形式化规则；新问题到来后，推理引擎在规则库中推演答案。苏煜用两个广义能力解释它的局限。Memory包括知识的表示、获取、更新和遗忘，可再分为语义知识、情景记忆和“怎样骑车”这类程序性记忆；Autonomy则包括感知、推理、决策和行动。逻辑系统的记忆受逻辑语言可表达范围约束，自主性又往往只有“输入问题—逻辑推理—输出答案”，所以很难适应复杂现实。更直接的工程瓶颈是知识获取：把专家经验逐条采访、翻译成规则，成本高且覆盖有限。苏煜将这一时期未能兑现承诺与80至90年代AI寒冬联系起来，这是他宏观历史叙述中的因果判断。

他最后提到Stuart Russell与Peter Norvig的《Artificial Intelligence: A Modern Approach》。据苏煜自述，Russell曾向他强调这本书本质上也是一本Agent的书，因为开篇就在讨论intelligent agent。这段既补充技术史，也保留嘉宾与作者交流的亲历归属。

Logical Agent (基于逻辑的智能体)指1950-1990年代以“专家系统”为代表的早期AI。输入是问题，输出是答案。其核心机制是：将人类专家的知识编码成形式化的逻辑规则，然后使用一个“推理引擎”（Inference Engine）在这些规则上进行逻辑推演。因知识获取困难和表达能力弱而失败。

00:12:38–00:21:23Agent技术史第二阶段：Neural Agent与Semantic Parsing并行发展

  • 它的通用性有提高吗？相对于logical agent。
  • 为什么这个时候，大家会把游戏当作，一个训练agent的一个环境，或者说一个boundary？

苏煜把2000年后、尤其2010年后的发展分成两条并行线索，而不是一个路线完全替代另一个路线。

第一条是Neural Agent。深度强化学习中的Agent接收游戏画面和少量历史，经神经网络计算后输出动作，环境变化，再进入下一步。AlphaGo、Atari、Dota和星际等是它的代表语境。与逻辑系统相比，神经网络能从数据中学习更丰富的感知和策略，同一网络或同一方法也可覆盖多个游戏；但每个模型的知识与行动仍围绕有限任务。苏煜特别强调，简单前馈策略在一次forward pass中完成感知到动作的映射，复杂推理隐含在网络内部，而且不同难度局面消耗的串行计算量基本相同。它也不等于人到陌生环境后少量尝试就能学会的泛化：他举例说，当时的深度强化学习可能要玩几百万盘才能学会一个简单游戏。

主持人问为何游戏成为训练环境。苏煜先声明自己没有直接做那类Agent，再把回答标为猜测：DeepMind负责人Demis的游戏兴趣可能有影响；更实际的原因是游戏可重置、可重复，能廉价产生大量交互，且输入输出相对清晰，正好适配样本效率低、环境建模能力有限的技术条件。

第二条是Semantic Parsing（语义解析）。输入是一句自然语言，输出是特定知识图谱、数据库或网站可执行的形式化语义表示；例如把查询要求变成数据库查询，或把操作要求变成机器指令。它扩展了Agent可理解和可执行的范围。苏煜自己的博士研究就在这里，并指出多位后来从事语言模型和Agent研究的学者也有语义解析背景。个别人名和模型名在转录中失真，未确认的拼写不在正文猜改。

Neural Agent (神经网络智能体)嘉宾用来概括2000年后尤其深度强化学习中的游戏Agent：输入画面与历史，输出环境动作，策略主要从交互数据学习。简单前馈版本的推理隐式且计算方式固定，但循环网络、搜索和规划等变体不能都被这一句覆盖。
Semantic Parsing (语义解析)NLP中把自然语言转换成特定环境可理解、可执行的形式化语义表示，例如数据库查询。它依赖目标环境的schema和执行接口；本期用它与大模型提供的跨环境先验作对照，不等于它已被Language Agent淘汰。

话题推进：在分别介绍了Neural Agent和Semantic Parsing之后，苏煜将话题引向2020年以后，由大语言模型驱动的全新阶段——Language Agent。

00:21:23–00:29:27Agent技术史第三阶段：语言作为脚手架的Language Agent

  • 它是一个拐杖或者是一个工具手段。
  • 我有一个问题啊，就是语义解析和 Language Agent，它们本质区别是什么呀？因为 Language 它就是已经，存续很久的一个媒介。为什么之前大家没有想到，要把它应用在 AI 的训练里呢，或者 Agent 的训练里呢？

苏煜把2020年后、尤其2022年ChatGPT之后的形态称为Language Agent，他提到自己与同事在 EMNLP 2024 办过语言智能体教程。教程的合作者是 Diyi Yang、姚顺雨（Shunyu Yao，当时署名普林斯顿大学）和 Tao Yu。这里的“语言”不是只指最终说给用户听的话，而是组织智能体能力的符号脚手架。

在感知和交互上，自然语言让人可以用比固定表单、特定命令更灵活的方式描述目标。在推理上，模型可以先生成中间步骤，再继续回答；已生成的token进入后续上下文，使后续计算能够利用前面的分解、观察或计划。与只执行一次前馈映射相比，生成更多token会增加串行模型调用所消耗的计算，因此苏煜称之为adaptive computing。这个机制说明“计算量可以变化”，并不保证模型会自动选择恰当长度，也不保证更长的文本就是更正确的推理。在行动上，自然语言、编程语言和机器可读指令可以描述工具调用与环境操作，语言因而成为数字世界中的行动媒介。

从Memory看，苏煜把大模型训练解释为从大量语言中压缩出对世界的表示。他认为这种表示给Agent提供了先验，使其进入一个训练时未专门适配的新环境时，也可能先给出合理行为；这与早期语义解析每次面向特定数据库或网站训练形成对照。“ reasonably”是能力起点的描述，不是任何环境都可靠的承诺。他由此回应“随机鹦鹉”的看法，但这是嘉宾对语言模型内部表征的解释，节目没有给出单独实验证明。

他进一步把语言类比为人类文明演化的加速剂：书面符号能跨时间保存与传递知识，AI也可能借助语言进入新的发展阶段。主持人追问“语言早就存在，为什么现在才不同”，苏煜纠正了问题前提：NLP一直在使用语言，真正变化是大模型提供了更强的通用foundation/prior，而非过去没人想到用语言表达智能。

00:29:27–00:43:13近三年Language Agent关键工作演进及边界消弭

主持人请苏煜回顾过去三年。苏煜先限定范围：重要工作太多，自己会更偏向熟悉的Computer Use Agent，因此这是一份个人视角的时间线，不是完整文献综述。

他把2022年的Chain of Thought视为让语言承载中间推理、使计算量随生成过程变化的代表。ReAct则把这一思路放入外部环境：Agent观察环境状态，生成思考，选择行动，行动改变环境，再读取新的观察，形成“观察—推理—行动”的循环。苏煜认为其想法看似简单，但在合适时点识别出关键结构并做出来并不容易。同年，他所在团队开始从语义解析转向Agent，做LM Planner和Mind2Web；前者探索用语言模型做机器人规划，后者面向跨网站任务。转录还提到一项名为“Socratic”的Google机器人规划工作，完整名称未确认。

2023年的主线包括工具使用、开源Agent热和多模态。苏煜将Toolformer作为语言模型学习调用工具的代表，并自述当时在微软兼职，看到Satya在公司内传阅该论文；他由此解释，能够调用现成工具对企业软件尤其重要。Auto-GPT把模型包进Agent外壳，在GitHub迅速走红，但苏煜同时强调它实际能完成的任务很少，不能把star数当作能力证据。多模态模型出现后，团队从文本网页Agent转向视觉网页Agent，并在缺少官方API时自行包装网页接口来做实验。Mind2Web强调在真实、多样网站上做通用任务；WebArena则搭建若干网站副本，减少真实网站变化和法律问题，以便复现评测。两者是任务覆盖面与受控可复现性的不同选择。

2024年的场景从网页扩展到桌面和移动端。OS-World提供操作系统环境；苏煜团队一项转录为“U-Ground”的工作主张“像人一样用电脑”：每一步输入当前屏幕图像，经推理后输出点击坐标或键入内容等像素级动作。这与读取HTML等文本表示不同，输入输出界面被明确为“屏幕视觉—位置/键鼠动作”。SWE-bench代表另一条Coding Agent评测线，但苏煜坦承自己没有紧密追踪其时间线。

他随后回忆2025年Coding Agent在硅谷的迅速扩散，以及OpenClaw在年底出现、次年进一步走红。涉及具体模型版本、产品和公司的多处转录名称不清，正文不把“Ollama 4.5”等猜成另一个确定型号。

主持人问为什么Coding Agent的感知最强、Web/Computer Use/Coding的边界是否还存在。苏煜的回答是，这些分类是按环境和接口作出的临时划分，最终目标是能在数字世界完成各种任务的Universal Digital Agent。GUI是图形界面，CLI是文本命令接口，API是程序之间调用的接口，Coding则是生成程序或脚本。苏煜认为代码能描述和连接这些操作，因此可能推动边界融合；这是一种趋势判断，不等于所有界面已统一，也不否定后文对GUI长期价值的讨论。

语言脚手架：中间表示如何进入推理与行动

【嘉宾机制解释的展开】脚手架指语言/符号为智能过程提供可保存、可组合、可执行的中间结构，而不是只负责最后回答。

怎样的结果会改变判断：如果带API任务上GUI持续更优，或长尾GUI任务上代码迁移仍普遍更便宜，就需要修改当前的接口判断；若混合方式按环境条件稳定占优，则更支持按任务路由。

待解问题：真实部署能否成为NeoCognition所期待的学习信号，并构成专业化智能的可持续优势？

核心判断：通用智能变便宜之后，稀缺的是“专家化的世界模型”

这场访谈最重要的转折发生在“通用数字 Agent”之后。苏煜并不把 Universal Digital Agent 当作终点：数字世界由数百万个职业、公司、软件、网站和流程组成，每个都是一个有自己规则、权限、隐性组织图和失败代价的 microworld。一个通用模型可以在陌生环境里做到六七成，但要成为可靠、快速、便宜的专家，必须通过持续学习把这个小世界建模出来。

边界

Agent 是一个有主体边界的实体，不是无限发散的聊天窗口；边界决定权限、责任和可观察状态。

环境

Agent 必须在可感知、可行动的环境中工作；没有环境，就没有真正的反馈闭环。

目标

行动必须服务于 goal-directed activity；“会说话”本身不是 Agent 的充分条件。

进一步推演：从访谈中提炼的七条 Insight

  1. Agent 的最小单位是闭环，不是模型。 把模型、工具、记忆和权限拼在一起并不会自动产生智能；闭环必须能观察结果、更新状态并承担行动后果。
  2. 语言的真正价值是接口压缩。 它把知识、意图、推理和行动映射到可组合符号，但压缩必然丢失细节；专业化就是把被丢失的工作上下文重新接回系统。
  3. “通用”与“专家”不是一条能力轴。 通用先验负责跨环境启动，专家世界模型负责可靠、快速、便宜地运行；二者必须协同，而不是互相替代。
  4. OpenClaw 类产品的核心创新是权限经济。 用户何时愿意授予长期、广域、可执行权限，比增加一个新 prompt 技巧更能改变扩散曲线；权限越大，审计与撤销越重要。
  5. 研究问题会从“如何训练”转向“在哪个世界里学习”。 环境、任务规格、失败样本和部署反馈决定训练信号质量；没有这些，继续堆参数只是把未知问题推迟。
  6. 研究—生产一体化是一种反馈结构，不是一种公司口号。 只有部署能真实改变下一轮数据、评估和策略，创业才提供学术环境缺失的学习信号；否则“AI-native”只是包装。
  7. 技术民主化必须同时回答分配问题。 让每个人都能构建自己的 Agent 可能释放创造力，也可能把收益集中到模型、算力和平台所有者；访问权、收益分配与责任制度要一起设计。

如何证伪这套判断

  • 在同等模型、工具和 token 预算下，若长期记忆、专业化训练对真实任务完成率没有增益，“工作世界模型”被高估。
  • 若开放式 Agent 只靠通用基模就能稳定完成不同公司、软件和组织的长程任务，specialized intelligence 的必要性会下降。
  • 若 OpenClaw 类权限放开后，事故率、误操作成本和用户流失都不显著上升，本文对权限经济的担忧需要修正。
  • 若公开数据显示部署反馈不能改善模型/Agent，研究—生产不可分的判断就不成立。
  • 若所谓“全民 Agent”主要表现为一次性装机、转发和投机，而不是持续完成高价值任务，技术民主化叙事应被收缩。
