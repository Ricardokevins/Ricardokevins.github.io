访谈脉络：用视频 Agent 把动画做成普通人的表达容器

嘉宾画像闹闹（人称「闹爷」），视频 Agent 产品 OiiOii 创始人兼 CEO；中山大学毕业，INTJ、狮子座，笑称自己「还在一个能打的年龄」。
公司现状2026 年初录制时成立约 4 个月、内测上线约 1 个月（仍需邀请码），全职团队 18—19 人，Pre-A 轮融资接近收尾，尚无收入与利润。一句话定位：用 AI 做动画。
职业履历最早在腾讯微信事业群负责 QQ 邮箱移动端；离职后 gap 半年系统学习插画与 3D 动画软件 Maya；2014 年起创业做极限运动内容社区历时 6 年；后加入字节跳动，先负责抖音/TikTok 特效，后出任剪映整体负责人；因热爱动画赴 B 站负责动画业务并做过 To C 项目「离谱」；2025 年下半年正式创立 OiiOii。

开场与快问快答：十年动画心愿，以及「安静的力量」

节目一开场，Koji 分享即刻网友对 OiiOii 的高评价——「近半年没遇到什么惊喜的新产品，直到遇到 OiiOii」，他自己也用 OiiOii 给女儿做了一首圣诞歌曲 MV，女儿爱不释手地循环播放。闹闹随即补充，内测中涌现出许多意想不到的使用者，比如每天给孩子做动画小视频的家长，以及用动画给学生做科普短片的老师。

快问快答环节里，被问「如果不创业此刻会在做什么」，闹闹答道「去一个没太多人的地方隐居，养几只小动物，生活着就行了」。她坦言过去自己是完全闲不住的「外拓」状态，总觉得必须不停做事才算构建出意义；如今反而非常闲得住，把独处和安静当作充电——懂得了安静本身的意义，才能释放出更圆满的安静力量。

谈及为什么对动画如此执念，闹闹回溯了从腾讯离职后长达半年的 gap 经历。大学时她就梦想做动画，离职后先报插画班学角色设计，又去学专业三维动画软件 Maya，结果被极高的操作门槛劝退——「它太难用了」，做过产品经理的人对难用工具有天然抵触。加上彼时动画行业薪资微薄、近乎「为爱发电」，她最终没有贸然转行，而是开启了 6 年极限运动社区创业。但她始终忘不掉当时参观一家建模特效公司的一幕：整间屋子昏暗无空调，工作 5 年的建模总监月薪只有 1 万元，谈起自己做的作品时眼睛里却闪着极强的光。这份纯粹一直留在她心里。

真正把「AI + 动画」的念头点亮，是在 2022 年在字节看到图像生成模型 DALL·E 2 之际，她第一反应就是「这可以做动画」。此后去 B 站做动画业务、推进「离谱」项目，都在不断摸清动画产业、寻找切入口。到了 2025 年上半年，一方面原有环境已难继续施展，另一方面多模态视频模型突然像早年大语言模型那样开始高速内卷，加上 Agent（智能体）形态成熟，主客观时机交汇，团队在 7 月规划、8 月动手，正式做出 OiiOii。

从首尾帧到 All in Sora 2：AI 视频的两大帮派与架构转向

Koji 问她为什么认准 Agent 形态。闹闹给出三点理由：其一，Agent 天然擅长编排调用多种底层模型；其二，动画本就是剧本、角色、分镜、画面、配音多工种接力的流式工业流水线，与多 Agent 协作高度契合；其三，传统 GUI（图形用户界面）创作软件只会越叠越臃肿，而自然语言驱动的 Agent 能把复杂性藏在底层，给创作者极高自由度。

她把当时 AI 视频生成赛道拆成两大「宗门」：一是国内视频模型普遍擅长的「首尾帧」流派，给定起始帧与结束帧图像让模型推演中间过程，单镜头画面稳定性高；二是「参考图 + 文本」流派，依靠文字描述加多张元素参考图直接生成。

2025 年 8 月起步时，OiiOii 第一版采用的就是首尾帧路线：比如生成 8 个镜头，先画出 9 张首尾相接的关键帧图片，再分段生成视频拼接。团队当时的核心创新是引入一个 Task Agent（任务调度智能体），熟悉各个底层模型的长短板，按镜头内容自动路由——打斗镜头派给动作见长的海螺，人物微表情与细腻情感派给擅长情绪表达的模型，大片特效感（CG 感）则调用对应的影视风格模型。

做了大约一个月，首尾帧链路刚见雏形、正准备补齐 TTS（语音合成）、配乐和音效时，Sora 2 横空出世。闹闹在推特上刷到 Sora 2 生成的动画，震撼到「完全看不出任何 AI 痕迹」，镜头间的蒙太奇切镜极其自然。研发接入 Sora 2 后生成的第一个测试视频，是一只小螃蟹和一颗小海星打篮球——成片完整到让闹闹不敢相信「不会真的让我们做成了吧？」。虽然 Sora 2 文本权重很高，跨镜头角色与场景一致性不如首尾帧稳妥，但表现力与电影镜头语言优势巨大（她猜测其训练数据融入了大量高质量电影素材，做二创时甚至能隐约看出某部经典电影的影调）。团队短暂并行两条链路后，很快做出果断取舍：「老链路先不做了，全部切到 Sora 2。」

「超市与餐馆」理论：为什么模型变强不会消灭视频 Agent？

面对最尖锐的灵魂拷问——「如果未来进化到 Sora 4、Sora 5，端到端能力极强，OiiOii 会不会被吃掉？」——闹闹给出一个广为流传的比喻：基础大模型是大型超市或菜市场，提供食材；视频 Agent 是开在小吃街上的川菜馆、粤菜馆、火锅店，针对特定人群的口味烹饪成品。

在闹闹看来，即便未来模型迭代，底层视频模型也极难「大一统」：先天上各家的数据采集与标注标准天差地别，人眼对视觉细微差异极其敏感；后天上各家战略侧重不同（例如可灵、海螺各有侧重影视大片或动作）。消费者当然可以去超市买菜自己做，但永远有人愿意直接下馆子。即便是超市（像物美、盒马）自己开始卖熟食，也取代不了深耕细分口味的专业餐馆——专业性本身无法穷尽。

她透露，团队大约 60% 到 70% 的功夫花在用户界面根本看不见的「后厨调味」 上，并用三个具体实例拆解了什么叫「用同一份食材炒出不一样的味道」：

  • 垂类创作知识库（以二次元 MV 为例）：同一句 Prompt（如「让他们几个跳一段 K-pop 做个 MV」）和相同参考图直接扔进 Sora 2，效果远不及 OiiOii。团队系统拆解市面上优秀的二次元 MV，提炼出节奏、运镜、转场和音效规律沉淀为知识库，在用户给出简短意图后自动扩写专业指令并编排视听语言。
  • 刻意拿捏的「分镜断点感」：有用户反馈部分剧情分镜之间存在轻微跳跃，其实这是团队有意调节的结果——如果每个镜头无缝衔接得过于平滑，整段剧情反而平淡无起伏，必须像厨师控火候一样把连贯性与戏剧转折调到黄金平衡点。
  • 「放辣椒过头」的场景一致性调试：早期只用文本描述场景、只喂局部小元素，跨镜头背景容易飘移；听完用户反馈后团队加入完整场景参考图，结果背景虽然牢牢锁死，却限制了模型的空间想象力，画面变得死板、人物像生硬贴在背景板上的「贴片」——就像客人嫌川菜不够辣，厨师猛加一勺辣椒反而辣得吃不下。这件事也让团队深刻意识到：底层模型纹丝不动，仅仅微调输入条件就能彻底改变成片观感。

目标用户演化：为什么不做漫剧和 UGC，以及意外涌现的「社交关系动画」

聊到商业切口，闹闹清晰复盘了两次「主动放弃」：

  • 暂不切漫剧（漫画风格短剧）：第一，漫剧极度考验剧本功底，这既非当前模型长板也非团队优势；第二，漫剧高度依赖买量投流；第三，漫剧是在既有成熟流水线上拼人工精修效率，而团队不想做重人力生意。
  • 暂不做类似「离谱」的泛 UGC 内容社区：一方面，当下用户的单次内容信息消费阈值很高，浅层 UGC 很难撑起大型独立 App 的留存；另一方面，大型社区对用户体量与视频推理算力的资金消耗极高，时机未到。

团队最终锚定了中间层——一人或两三人规模的小型自媒体动画工作室，细分为三类：①围绕固定原创 IP 连续更新的动画自媒体（过去两三人小团队一周更 1 集，借助 OiiOii 的固定 IP 角色连续生成功能，粗算一天能出 10 集，精挑细选日更 1—2 集毫无压力）；②ACG 圈层的 MV 创作者；③讲历史、做科普的非动画自媒体，内容极适合动画表达，只是过去成本高不可攀。

但内测一个月后，市场给出了三类完全出乎意料的惊喜用户：①漫剧创作者还是找上门来了——虽然 OiiOii 还没做剧本上传等专属功能，他们发现根本不需要一键成片，只要快速生成高可用分镜下载回去自己剪，效率就已大幅跃升；②零视频经验、不愿真人出镜的普通 C 端用户，把动画当成表达内在精神世界的面具；③并非为了公共流量的「私人社交关系」创作者——家长给孩子做、学生给老师做、情侣互做、成年人给父母做、主人给自家宠物做。面对多元需求，闹闹表示终极目标并不是一刀切做减法，而是借鉴当年抖音深耕垂类的打法：排好优先级，逐一研究每个垂类的内容结构、沉淀专属知识库，一个一个啃下来。

两个月四次架构重构、与剪映的互补，以及把「孤独」翻译成镜头

Koji 抛出视频 Agent 最难啃的工程问题：传统剪辑软件和固定工作流（Workflow）高度可控，自然语言 Agent 则极其灵活却容易失控，OiiOii 怎么做到「既要又要」？闹闹坦言，为了兼顾「流水线的稳定性」与「随时和流水线上每个 Agent 自由对话修改」，团队在短短两个月里做了四次架构重构：

重构阶段 核心架构思路 实际暴露的痛点
第一版 纯靠 System Prompt 定义多个 Agent，全权交由大语言模型自主决定流程与交接 自由度过高、极不可控，模型经常「不听话」，该交棒给下一个 Agent 时不交棒。
第二版 切换为严格锁死的固定 Workflow 流水线 稳定性提升，但彻底牺牲了用户中途插话修改与探索的自由度。
第三版 在固定流水线中引入退出/返回「信号」：检测到修改需求时跳出主干，改完再发信号回流 状态跳转极易出错，用户常遇到系统跳出去就忘了回来，或者没正确退出而僵硬地继续往下跑。
第四版 在第三版基础上允许跨分支流程跳转，进一步平衡可控与灵活 录制时仍处于密集调试阶段，持续提升边界状态下的稳定性。

在产品交互上，OiiOii 采用「导演带队」的群聊隐喻：剧本、角色设计等表面可见的 7 个具名 Agent 像拉群协作一样彼此召唤，而界面之下还隐藏着负责调度与辅助的隐形双层 Agent，处理跨角色上下文记忆颇具挑战。不过闹闹认为，相比 Photoshop → Sketch → Figma 或 Premiere → Final Cut → 剪映这种不断堆功能再被简化工具颠覆的循环，Agent 允许用户主动探索边界，甚至做出连研发团队都惊呼「这是用我们产品做的吗？」的高阶作品。

作为前剪映负责人，闹闹也直面了「OiiOii 会不会吃掉剪映」以及「Cursor for 视频编辑」的话题。她把剪映拆成两层：底层通用的剪辑轨道，以及嫁接抖音内容生态的模板体系（后者具备极强护城河）。OiiOii 切中的是更靠前的内容生成增量市场：随着 Sora 2 这类模型把镜头切换与复杂特效内化到生成环节，过去极其繁琐的重度特效和转场反而最容易被模型替代；而「把片尾删掉 0.1 秒」、调顺序、最后统一合入配音（避免多模型音色不统一）这类极轻量的精准微调，直接上手拖动轨道远比用自然语言发指令高效。因此两者是叠加增效的关系——以前在剪映里耗时 3 小时，今后在 OiiOii 生成再进剪映精修可能只需 30 分钟。

谈到如何帮不懂镜头语言的普通人做出「有感觉」的片子，闹闹举了一个动人的设计细节：用户说不出推拉摇移，却能说出「孤独」「悲伤」「欢乐」「治愈」等情绪词。团队把影视视听语言拆解映射进系统——比如选择「孤独」，背后会组合长长的走廊、灰白色调等理性构图元素来传达感性氛围，恰如朱自清《背影》里铁轨旁拎着橘子的父亲。此外用户还可以调用大师导演风格，只是目前融入个人原创细节的自由度还不够高，团队仍在持续打磨。

微信的右脑、字节的左脑，与好产品经理的三条底座

作为少有的横跨腾讯微信事业群与字节跳动核心产品线的老兵，闹闹用「右脑与左脑」复盘了两段修行。她先严谨纠正：自己在腾讯并非微信核心负责人，而是早期做 QQ 邮箱移动端，但深受张小龙（「龙神」）的产品价值观浸润——哪怕一个版本更新语（例如微信曾配迈克尔·杰克逊照片写「我所说的都是错的」，以及冷不丁推出让人上瘾的小游戏「跳箱子/跳一跳」），背后都藏着极深的人性洞察。当时团队每天都要读大量用户反馈（记不清是一百多条还是上千条）并亲自回复，训练「泡在用户里识别真伪需求」的肌肉直觉，绝不坐在会议室里空口争论。

刚到字节做抖音特效时，她一度抵触纯粹的数据指标驱动——把按钮无限放大肯定涨点击，体验未必更好。直到深耕「策略产品」才恍然大悟：通过用户浏览特效视频、点开转盘、点收藏等真实行为，测算出谁是大概率会跟风拍特效的人群，先把趋势「造」给他们引爆模仿，数据其实比口头反馈更诚实。两家巨头看似一感性一理性，本质共同点却惊人一致：把各自基因里的长板发挥到极致（微信把人性洞察做到极致，张小龙的拍板建立在开放倾听与更深思考之上；字节把推荐引擎与科学决策做到极致）。而 AI 时代数据量尚未形成规模，恰恰需要「微信的体验直觉」叠加「字节式的模型搭配策略」。

被问做一个好产品经理最重要的品质，闹闹干脆给出三条：

  1. 移情能力：瞬间从「经验老到的专家」抽身切换成「一窍不通的小白」，做自己和用户的旁观者（Koji 联想到马化腾说的「一秒变小白用户」）。
  2. 50% 的自信 + 50% 的自省：如阴阳平衡，只自信易变自负、只自省易生自卑，用冷静自省看清盲区，反而能筑牢真正的自信；一旦自我感过强，就会彻底丧失移情能力。
  3. 对技术敏感：不必亲自写代码（闹闹自己也不会写代码），但必须深刻理解技术边界与规律，才能把前沿能力翻译成用户产品。她自幼对视听敏感又酷爱物理规律，如今做多模态动画产品，回望过去每一段看似弯路的经历，竟像乔布斯说的「把所有点连成一线」，感到格外幸运。

「OiiOii」的小蜗牛、冲突是做事的力量、与 2026 反共识预言

聊到公司取名，闹闹笑道原本几轮头脑风暴都没定下来，一位技术同事提议二次元打招呼常说「oi」，叠成两声 OiiOii 既亲切顺口，字形上两个 O 加两个 i 又酷似两只小蜗牛，寓意踏实慢慢爬又足够可爱。

Koji 翻出她朋友圈的两句金句深聊。第一句是「将隐形的愿力显化到产品上是秘籍，掌握者寥寥无几，要更精纯」。闹闹回忆离开「离谱」时的不舍：前一个项目里夹杂了太多自己无法掌控的外部杂质，如今独立创业，终于可以把更精纯的团队愿力灌注进产品。第二句是「要允许冲突，甚至制造冲突，因为冲突是做事的力量，是筛选做事的人的方式」。爱好打篮球的她相信良性竞争能激发对手潜能：在字节做特效时曾与多个团队抢业务打得不可开交，打完仗发现彼此都「以事为先」，反倒成了背靠背的战友；第一次创业时，她亲手开掉的第一位员工竟是自己的好朋友，当时被骂得狗血淋头、对方离职还挖走了人，但一年后对方自己带队踩过同样的坑，主动加回微信说「我终于理解你了」。只要初心不是害人，时间会证明一切。

如今显得极其平和（Peaceful）的她，中学时代竟然组过摇滚乐队、玩过极限运动，浑身反骨。经历过上一段创业起伏与家庭变故后，她悟出一个反差极大的自由观：年轻时以为向外呐喊、反抗就是自由，结果反倒在不断索求中给自己造了牢笼；向内审视才发现，安静并不是软弱，而是一种无需过度用力的广阔能量——「闹」与「静」其实是追寻自由的一体两面。

谈及自己最推崇的企业家——皮克斯联合创始人（艾德·卡特穆尔），Koji 问她为什么不像偶像那样直接去拍动画片。闹闹答得通透：皮克斯创始人自幼热爱动画却既画不好画也不会讲故事，靠热爱的计算机与物理用分形图形学做出史上第一只电脑生成的手（1 分钟短片），一步步进工业光魔最终开启 3D 动画电影时代。这启发了她：自己既非顶级画师也非编剧，最擅长的是用产品连接技术与创意，因此选择用 OiiOii 进入这个商业世界里「少数愿意奖励纯粹与热爱」的行业（她以迪士尼、皮克斯以及中国的王微与追光动画、饺子为例）。

展望 2026 年的 AI 视频演进，闹闹给出一个冷静的反共识判断：未来模型画质、可编辑性与实时互动性都会提升，但更高的编辑自由度与实时互动，反而可能让受众变窄、变小众——因为大众已被短视频规训成习惯被动消费（唯一动作就是上下滑），多加一步主动交互就会筛掉大量普通人；反倒是像 Sora 2 那样只把切镜和叙事体验做得更自然顺滑，就能瞬间引爆大众市场。另外，视频模型短期内不会大一统，而 OiiOii 未来也可能逐步开放模型自选。

尾声两个快答极具个人色彩：如果拿到 300 万美元分投 3 位天使创业者，她第二反应是「投给自己」——因为天使投资首要投给最了解、最信任的人。而在压轴的 10 个「我是」彩蛋中，因修习佛法正刻意放下身份执念，她请求豁免，只留下两句分量极重的话：第一，「我是一个正在尽量减少『我是某某』的人」；第二，「我是一个容器」——借用李安那句「不是我更有才华，只是电影之神刚好选中了我，我是一个容器」，她希望自己和 OiiOii 都成为「动画之神」的通道，不替用户决定要讲什么，而是让所有想讲故事的人借这个容器把故事讲出来。

机制拆解：用户中途改剧本时，多 Agent 流水线究竟卡在哪里？

闹闹提到两个月四次架构重构、系统「跳出去修改后忘了回来」，点中了多 Agent 视频工作流最核心的状态管理难题。假设用户生成一段三镜头动画：①小猫推门走出家门，②在街角遇见朋友，③一起散步回家。系统按顺序已生成前两个镜头，此时用户突然打断说：「把朋友改成一只橘色小狗」。

一个既灵活又可控的流水线必须完成四步显式状态控制，而不是只把指令塞进聊天记录：

  1. 挂起与快照（Checkpoint）：暂停后续镜头 3 的渲染队列，记录当前全局版本号与各节点产出状态。
  2. 上游资产改写与脏标记（Dirty Propagation）：只更新「朋友」的角色设定档案与参考图，并沿着依赖图自动标脏——镜头 1 未出现朋友可以保留，镜头 2 已渲染但依赖该角色必须重绘，镜头 3 尚未渲染则自动绑定新角色设定。
  3. 最小范围重算（Partial Re-execution）：仅重跑受影响节点，避免从头全量重绘浪费算力与等待时间，也避免沿用缓存里的旧参考图导致「改了设定却画出旧人」。
  4. 确定性回流（Deterministic Resume）：校验修改验收通过后，显式触发状态机回到主干节点继续完成镜头 3 及配音合成。

纯靠大模型自由提示词调度时，模型极易遗漏依赖关系或丢失恢复指针；纯靠死板固定流水线则无法响应中途插话。这正是 OiiOii 第三、四版架构反复调试「退出与返回信号」的底层原因（以上三镜头依赖图为解释性机制示例，不代表 OiiOii 内部具体实现代码）。

独立判断：「超市里的熟食」与「专业餐馆」之间，壁垒究竟在哪里？

模型进化既给餐馆送好食材，也在不断吞噬浅层「调味」

「超市与餐馆」的比喻精准说明了垂类创作编排的价值，却不能自动保证每家餐馆都安全。如果模型厂商只提供底层 API，应用层靠知识库、镜头美学与多模型路由确实能做出明显差距；但如果模型厂商像盒马做熟食一样，亲自把 MV、漫剧分镜、角色一致性与内置剪辑做成低价一站式应用，浅层 Prompt 扩写壁垒就会被迅速抹平。衡量一家视频 Agent 是否真正站稳，要落到同批真实任务上的硬对比：端到端成片可用率、局部返工修改成本、单分钟推理费用，以及用户做完第一支爆款尝鲜视频后的长期复购留存。

「一致性」与「镜头表现力」天生张力十足，应做成可调旋钮

闹闹分享的「加场景图反而像贴片」是一条极有价值的实操洞察：不同视频品类对一致性和想象力的权重截然不同——连续剧漫剧和固定 IP 动画容不得角色脸盲与背景跳变，而情绪短片或音乐 MV 恰恰需要大胆的蒙太奇跳切与画面隐喻。产品侧不必把「越一致越好」奉为单一指标，而应按内容模板或创作者分级暴露可控梯度（例如仅锁主角形象 vs 同时锁场景机位），让高阶创作者保有介入空间。

「私人社交关系动画」与「自媒体生产工具」指向两套完全不同的产品指标

内测意外跑出的两类核心需求其实逻辑迥异：给孩子做圣诞 MV、给伴侣和宠物做动画看重的是零门槛、情绪戳中与即做即分享，用户并不追求日更十集，却极度看重第一次打开时的惊喜感；而自媒体工作室与漫剧团队算的是单位时长成本、可控修改效率与平台完播率。后续逐个啃垂类时，团队需要为「个人情感纪念」和「专业流量生产」分别建立留存与付费口径，避免用单一活跃指标混淆两类人群的真实价值。
