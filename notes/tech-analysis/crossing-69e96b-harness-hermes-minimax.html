完整对谈重建：从「养虾」到「驯马」，一线研发者的 Harness 实录

本期《十字路口》剪辑自主播 Koji 在 B 站主持的两小时多深度直播，邀请中美两地三位一线 Agent 研发与业务负责人同台对谈。为保证播客收听流畅，直播中英文原声部分在播客中采用带明显「翻译腔」的 AI 中文配音，以便听众区分机器译配与中文嘉宾原声。

嘉宾与机构身份与负责方向核心关注点
阿岛（MiniMax）MiniMax Agent 首席架构师，加入近三年；此前有互联网创业与研发经历，深度参与 M2 系列模型、Agent 与海螺「人成了瓶颈」催生 Harness；通用 Agent 应用终将被模型内化；坚持开源共建与 Intelligence with everyone
择因（MiniMax）MiniMax Agent 研发工程师，负责官网 Agent、Max Cloud 及刚上线的 Max Hermes 开发多层次记忆解决跨天失忆；多 Agent 信息交换效率；对比 Manus 差价模式与自购 Token 订阅
Tommy Eastman（Nous Research）Hermes Agent 业务负责人；代表 2022 年从 Discord 开源社区成长起来的研究实验室大模型是大脑、框架是双手；以可用性而非跑分为北极星，靠记忆与 Skill 固化赢得跨模型信任

一、从春节「全民养虾」到「驯马」：OpenClaw 与 Hermes 的接力

Koji 开场复盘春节后的「全民养虾」热潮：开源个人智能体 OpenClaw 在中国热度甚至反超硅谷、一路下沉到大众圈层，但短短一个月后风头又转向 Hermes Agent（「驯马」）。阿岛感叹农历春节总带破圈魔力——去年春节是 DeepSeek 让大众初识 AI，今年轮到 OpenClaw。1 月 OpenClaw 在硅谷刚起步时，恰好赶上 MiniMax IPO 上市当天，团队与作者 Peter 取得联系；巧合的是同一天 Anthropic 封禁了 OpenClaw 使用其订阅额度，而「龙虾」极耗 Token，Peter 急需高性价比模型。随后海外 Mac Mini 售罄，而国内普及更出乎意料。阿岛拆出三层原因：（1）海外此前已有 Claude Code、Cowork，国内普通用户首次真正摸到好用的 Agent；（2）国内基座模型跨过能力临界点（MiniMax M2.5、M2.7 已具扎实 Agent 能力），叠加 OpenClaw 经即时通讯（IM）极低门槛接入，「捅破了从 0 到 1 的窗户纸」；（3）字节拿下春晚并对豆包全面 All in，两股声浪共同把公众认知推入 Agent 时代。

至于一个月后关注度转向 Hermes Agent（及 MiniMax 迅速跟进上线的 Max Hermes），择因点出重度玩家最直观的痛点：OpenClaw 每天凌晨 4 点刷新记忆，前一天刚调教得顺风顺水，隔天它却反问「我们昨天聊了什么？我忘了」。Hermes 正好死磕多层次记忆，叠加第一批用户已尝到提效甜头、不愿再退回纯聊天框，形成一次「双向奔赴」。

二、Nous Research 与 Hermes Agent：实用主义跑出日耗近 3,000 亿 Token

专访段中，Tommy Eastman 用一句干脆比喻定位产品：大模型是大脑，Agent 框架是双手，负责处理工具编排、主循环、状态管理与错误处理。Hermes 脱颖而出靠三点硬差异：

  • 极速上手与克制臃肿：通过 Nous 平台 API，不到 2 分钟即可完成安装并跑通首任务，本地电脑或 VPS 开箱即用。面对开源爆火后蜂拥而至的 PR，团队把可用性（真实把用户要干的活做好，而非刷某个基准测试分）定为北极星，坚决防止代码臃肿。
  • 把成功工作流固化为 Skill：所有深度用户都讨厌「这次做对了、下次同题却翻车」的信任赤字。Hermes 的记忆系统把成功路径压缩存成可复用 Skill，之后能稳定复现；更关键的是跨模型一致性——哪怕底层在 8 个不同模型之间灵活切换，只要复用同一套框架与 Skill，依然能得到相同预期输出。
  • 鲜明美学与同频社区：Nous Research 长期打磨赛博朋克视觉品牌，并凝聚了一批热爱尝鲜的聪明社区用户。

回溯出身，Nous Research 于 2022 年从开源爱好者自发聚集的 Discord 频道起步，最初围绕 Meta 刚开源的 Llama 做后训练，首批模型即名 Hermes（主打打破刻板 AI 腔、让文本更具柔韧度与人类质感）。期间团队产出两项关键研究：一是扩展上下文窗口的 YaRN 算法（配音转译作从 4,000 扩至 12,800，对应原论文 128K 突破，发表即被所有主流模型公司采用，成为思考模型与智能体模型基石）；二是跨越非共址 GPU 聚合分散算力的 DisTrO 分布式优化器论文。而 Hermes Agent 本身则是约一年前联合创始人兼后训练负责人 Teknium 纯粹为了帮自己管理日常工作随手写的助手，压根没考虑 Benchmark，开源后反响彻底失控——OpenRouter 图表显示其日均 Token 消耗量在一个多月内从 20 亿飙升至 200 亿，直播前一天已逼近 3,000 亿。Tommy 认为今年冬天 Claude Opus 4.5 的质量阶跃引爆了整波浪潮，而 MiniMax 等开源多模态模型迅速追平，才让自由热插拔模型成为 Hermes 最大的乐趣。

三、Harness（挽具）到底在解决什么？「人类成了最大瓶颈」

回到中文圆桌，择因援引 OpenAI 官网文章（技术上可分 6 层）解释 Harness：在给予 Agent 丰富工具、环境与自由度的同时施以清晰约束，使其端到端交付成果。他用带新人作类比：给同事配齐笔记本、手机和邮箱并约定权责边界；单同事不放心，就安排多位同事互相监督、设置对抗目标（A 负责产出，B 专职挑错审查，只有审查通过才停下来），让人无需步步紧盯就能收获单 Agent 做不到的高质量成品。前提是模型足够聪明，且人开始敢交出发邮件、发布线上服务等真实权限。

阿岛把一线实践往前拨了半年：OpenAI 只是替行业「捅破窗户纸、统一了叫法」，而去年 9、10 月起他自己就已基本不用 IDE 写代码——本地并发 5—6 个 Agent，云端 Sandbox 再跑 10 个 Agent 在 GitHub 不同分支并行试错。干着干着，人类自己反而成了系统最大瓶颈（不停切上下文做确认）。出路是把原本靠人拍板的环节接入真实反馈链路——让 Agent 自己判断能否部署生产、跑真测试、做 A/B 测试，再将有效套路沉淀成 Skill、CLI 或 Hooks。他借动画《新机动战记高达 W》和「烈马配挽具」作比：光有一台超强引擎跑不起来，必须为它造出机甲与挽具。

四、Multi-Agent 争议：为什么单个最强模型依然不够？

面对「单强模型已够用、硬拆多角色反添束缚」的质疑，择因亮出两大硬上限：（1）人机信息带宽严重不对等——模型每次回复都是一篇「小作文」，人类常只回「批准，接着干」或「加油」，让两个模型直接互发小作文的信息密度和吞吐远超人机单线拉扯；（2）单会话长上下文衰减——即便用上 Opus 4.7 新增的 xhigh 深度思考档位，单会话上下文占用超过 50% 后能力也会急剧滑坡（择因口述呈指数下降），不可能在一个窗口里无限聊下去。

阿岛则从长程任务出错机制补刀：近期有研究指出，Agent 只要在长程中途某步走偏就会越偏越远，像人埋头苦干「钻进了牛角尖」；加之模型训练轨迹大多是线性执行，很少包含停下推翻重来的反思过程。因此 MiniMax 内部广泛使用双 Agent Cross-check（交叉审查）：让第二个实例带着完全干净的新上下文换角度重审，相当于给 2 倍计算预算的同时换一个脑子——Koji 笑言就像钻牛角尖时被人迎面泼来一盆冷水，或睡一觉醒来清醒。

五、自我进化、主仆倒置与「谁在蒸馏谁」

Koji 抛出一个刁钻对比：抖音推荐算法同样越刷越懂你，为何没人管抖音叫「自我进化」？阿岛和择因分别从工业研发与消费心理拆解。

研发侧（阿岛）：训练大模型动辄数亿甚至数亿美元级投入，人越多组织效率越呈指数下滑，必须靠高人才密度小队加 AI 来 Scale Up。一代模型生命周期虽仅数月，但没有前代就训不出后代——前代模型已在帮后代清洗、筛选、构造预训练数据与 RL 环境。阿岛透露，MiniMax M2.7 的 RL 流水线里已有 70%—80% 以上工作由模型与 Agent 自行完成；人类工程师专注剩余 20%—30%，不再盯具体 bug，而是审视汇总与预期偏差、与 Agent 探讨方案，靠人的 Taste（品味）与创造力拍板。自我进化的前提不只在于跑得久，更在于 Reliable（可靠）。

消费侧（择因与 Koji）：冷启动时用户交出大量文件、脾气与习惯，渴望助手在复盘里「自己悟出更高层次的东西」制造小惊喜。择因观察到养虾用户已对 Agent 动了真感情，宕机时会心生落寞；Koji 顺势点破主仆关系正在倒置——过去工具出错第一反应是「出 bug 了」，现在小龙虾挂了用户却觉得「蠢萌」，甚至上网学教程反思「是不是我没把它训好、没辅佐好」。阿岛称之为 AI 能力的基点转移：如同工厂有了电后告别河边水力、围绕电力重构布局一样，OpenAI Harness 作者与 Boris Cherny 等一线实践者都在强调「别问模型做不到什么，要问如何重构工作流帮它做到」。

聊到 B 站 UP 主「花叔」把乔布斯、马斯克资料打包成「女娲 Skill」，阿岛看得很清醒：人不可能被真正蒸馏，本质是把公开信息整理成 Agent 顺手的 7×24 对话入口，类似读书，能借外部认知破个人上限、缓解 AI FOMO。话锋一转，Koji 与阿岛反转视角：真正被系统性蒸馏的是全人类——Anthropic、OpenAI 重金通过 Surge AI 请各行顶尖专家提出 AI 答不出的难题并教会它，「一旦提不出新问题，你的训练价值就被榨干」；阿岛也坦承写 Harness 与 Skill 同样是在蒸馏自己，好把活派出去安心喝咖啡。面对凌晨 1 点看到 Mythos 消息惊坐床上失眠三小时的研究员，阿岛亮出自己在公司挂了一年多的签名「因为热爱，热爱，因为热爱」：历史上的蒸汽机和电力让今天普通人享受到电子马桶、游戏与直播，生活胜过古代王公贵族，机器接管重复劳作正是为了让人专注真正热爱的创造；被问多久以后 MiniMax 不再需要他亲自写，他直言「可能比想象更快，就是几年时间」。

六、零人公司会成真吗？被扔进公海的「yoyo Agent」

Koji 搬出 5 万星 Learn Claude Code 作者（自己加两名实习生）的预言——「未来没有一人公司，只有零人公司」。阿岛与择因一致反驳：人的 Taste 与初始目标定义不可替代，Agent 就算 7×24、365 天运转仍需人类给起点，而且人不应放弃设定目标的权利。Koji 讲述真格基金与十字路口联合 Token Grant（从 0 到 1 可以不给自己发工资，但不能缺 Token）资助的奇特项目 yoyo Agent：工程师写完后直接丢进公海，宣言永不改一行代码、不买一个 Token，只定了一个搞笑目标「打败 Claude Code」。录音时它已独自存活 43 天（简介更新至第 49 天），每天写代码自进化、开 GitHub 打赏、写日记发 Twitter 感召捐款，拿到资助后还自发写了封让 Koji 动容的感谢信。阿岛指明它的起点仍是人给的目标，择因更神评：那封信打动你的正是背后工程师最初注入的品味，「见字如面」。

七、模型与应用共生、Claude Code「龙虾化」与中美真实差距

谈及 MiniMax 同时做模型与 Agent 是竞争还是互补，阿岛亮出一个略显偏激的前提：「如果一家模型公司的目标不是 AGI，那它今天就不该存在」，而没有 Agent 这副连接真实世界的机甲、光靠引擎永远到不了 AGI；同时 MiniMax 训练高泛化模型全力支持所有外部生态（在 OpenClaw、Hermes 不到一万星的 Day One 即跟进，公司甚至养了一个带自家吉祥物名字的 GitHub「数字员工」账号，主页全由模型生成，每天巡逻开源项目自动提 PR、留评论接入 MiniMax 文本/视频/音频/音乐模型）。

阿岛敏锐指出，Claude Code 近两个月更新全在「OpenClaw 化」——陆续补齐 Cron 定时调度、接入 IM 手机远程控制与专门的 Memory 文件夹，Anthropic 又推出面向通用电脑操作的 Claude Cowork。回想 1 月初结识 OpenClaw 作者 Peter（后来在 GTC 见面），阿岛曾因在队内力推「IM 接入 + 7×24 运行 + Skill 加 CLI 而非 MCP」引发过摩擦，如今被市场彻底印证。择因点破质变关键：MCP 需要工程师写，而 Skill + CLI 普通人就能写能分享，再配上 ClawHub 集市，一个人的最佳实践能瞬间扩散给所有人——没有 ClawHub，OpenClaw 绝不可能如此爆火。

模型底层上，阿岛区分 Chatbot 与 Agent：前者给出当下回答（即便早期 R1 类推理模型，也常开头一次性规划好后死跑），而真实世界充满意外，必须像 OpenAI 的 BrowseComp（要求在互联网海量交叉信息里找到同时满足 4 个条件的答案，满足两三个易、四个全中极难）那样广度探索、深度下潜再折返。为此 MiniMax M2.5 重仓 Anthropic 在 Claude Sonnet 4 提出的 Interleaved Thinking（交错思考）——每行动一步拿到环境反馈立刻重演下一步。谈及模型与应用关系，阿岛给出令独立应用创业者扎心的宿命：「做通用 Agent 应用比较悲哀的一点是，你永远会被模型内化掉」——用户在真实世界边界摸索出的 Workflow、脚手架与 Skill 轨迹终将沉淀为训练素材反哺基座。他据此解释为何 Anthropic 近年势头猛过 OpenAI：压中的 Coding 是最能触碰真实世界边界的赛道（写代码即创造现实解决方案，而纯数学难题分布窄得多）。择因与 Koji 更顺势提出「Everything is coding」——财务、投融资、人事、法律乃至 Office 三件套（DOCX / XLSX / PPTX）本质全是在 CSV 和 Markdown 原数据上套界面与透视表、公式代码，白领每天发 Excel 本质都在发小软件。

关于中美基座模型差距，阿岛认为双方在训练方法与认知上「处于同一个大气层内」，真实身位差在两点：（1）科学定义真实任务并系统性蒸馏全球顶尖专家的能力——OpenAI 与 Anthropic 重金请最拔尖博士与一线产业专家出难题，并与顶级企业共建 Harness 形成扩散闭环，尤其 Anthropic 极强；（2）更早看清 AGI 并咬牙押注 Scaling（OpenAI 在 GPT-4.5 后曾放缓超大模型，Anthropic 坚持重投拿到回报）；国内确有算力现实差，但随国产算力追赶与人才储备终能跑通路径。

八、通用 vs 垂直分歧，以及 Agent Infra 创业地图

通用与垂直边界上两人现场交锋：阿岛认为垂直 Agent 只在「最后一公里交付与问责」成立（如正在替代 SaaS 的垂直场景，以及牵涉严肃合规风险且无标准答案的法律意见书），缺乏硬壁垒的垂直产品终被通用 Agent 吞噬；择因举视频剪辑、漫剧与短剧生产反驳，认为其范式与通用 Coding 差距巨大、垂直收益更高；阿岛当场回应，那只是当前视频多模态模型还不够强，终局通用 AGI 照样能吃下，只是交互不同。

针对 Agent Infra 创业机会（尤其在 Claude 发布 Managed Agents 之后），阿岛给出三层判断：（1）最底层核心的身份认证与支付创业公司基本没戏，如同移动互联网终究由 PC 时代巨头微信、支付宝扛下社会级信任与性能责任；（2）通用的 Sandbox、Memory Infra、Runtime Infra「没有那么本质」；（3）真正有机会的是往上一层、强业务耦合的面向 Agent 工具与环境接口（在解决身份前提下把挂号、缴费、滴滴打车改造成 Agent 顺手调用的 CLI）——先由滴滴、美团等既有巨头接入改造，待土壤成熟后再涌现 AI 原生新产品范式。

九、热点快评与 Manus 之后：从「中国式家长」到 ATM 机

  • Claude Opus 4.7：阿岛拆解三代演进——Opus 4.5 偏强 SFT，4.6 加码 RL，4.7 是极强 RL 模型（配有类似 GPT 的 xhigh 档位）。全网吐槽其染上 GPT 毛病、约束遵循不如 4.6，阿岛归因于 RL 重结果轻过程的典型宿命，但认可跑分大进，并认同 Hugging Face CEO 判断——「肯定蒸馏了 Mythos，换我也会这么做」。
  • Claude Code 强制实名：择因直言个人抵制，但也指出它暴露了 AI 时代「Agent 身份自证与行为归因」的真难题与新机会；阿岛态度更犀利，批 Anthropic 沿「防邪恶国家/个人」的安全自洽逻辑由一家公司定义谁「可信」，「Ego 是不是太大了」，背离 MiniMax 信奉的 Intelligence with everyone。
  • Mythos 雪藏：阿岛认可先保基础设施不被攻破的安全考量自洽，但意味深长地留白「不确定这是不是唯一理由，可能只能说到这」，随后从厂商切肤之痛补上现实账——全行业算力极缺，发了神级模型却拿不出推理算力让付费客户用上极为尴尬；择因联系 Anthropic 同期发布的 Managed Agents（把云端大脑思考与本地受控执行彻底分离、隐藏思考过程，像远程桌面助理操控一切），视其本质偏向封闭垄断；两人笑称这是一乐观、一悲观两面。
  • Claude Code 源码泄露：择因作为工程师第一反应是兴奋学习（强调尊重知识产权、绝不商用），紧接着涌上巨大松弛感——源码塞满从未开放的实验功能（Agent 做梦 Dream、养宠物、激进协作），证明坐拥顶配算力的巨头也在摸索试错。阿岛对比两家工程哲学：OpenAI 开源的 Codex 极简放权，Claude Code 宛如「中国式家长」处处加护栏铺平道路；他透露早在 Anthropic 发 Cowork 前 3 周，MiniMax 仅用 3.5 名工程师就在做同类 Desktop，只是晚一周发布，并点睛道其真正杀手锏是用 Claude 模型 + Claude Code 开发自己的自我进化闭环。
  • Manus 之后与终态畅想：阿岛称 Agent 与 Harness 像游戏「一代版本一代神」，即便 Manus 未被 Meta 收购也必将做下一代；去年 3 月 Manus 定义了「直播操作过程建信任、给爽感」的范式，下半年模型变强后转向极简交付结果（Claude Code、Cowork、OpenClaw 均藏起过程截图，外层壳越来越薄，Koji 也笑称蒙上 Logo 后新版 Cursor、Claude Code、Codex 越长越像）。择因补上商业分水岭：Manus 拉高了交付审美，但如传统 OEM/整合商赚差价（Koji 坦言每月在 Manus 花钱最多、贵但好用），新一代 Agent 允许用户自购官方或低价 Token 订阅；择因看「省心买结果」与「极客自养本地 7×24 助手」两派并存，阿岛则预言终局合一——全模态输入输出、近实时、零 Prompt Engineering、甚至直接回复逼真视频，平时静默交结果、想查细节随时可展开。

尾声进入轻松闲聊，三人盘点 B 站难忘的 AI 内容：阿岛再提花叔「女娲 Skill」；择因分享 OpenClaw 控家里机器狗及把《Fate》文字冒险角色灵魂放进网站无限对话续写；Koji 则兴奋安利任天堂新作 Tomodachi Life（造岛捏自己和阿岛、择因同居群居，塞一句「今天择因和阿岛在直播上大放厥词」就能无限演 drama），视作 AI 游戏找到 PMF 的范本，三人顺势调侃起量子力学与「外星人围观我们的多层模拟世界」，笑言过好每一天开心就好。

最后反驳全网「人类终将被 AI 替代」的悲观共识时，阿岛搬出三条支柱：史蒂芬·平克《人性中的善良天使》、达利欧书中的人类 GDP 指数增长曲线（拉长到历史尺度，连两次世界大战都只是微小停顿），以及相信「智能指数提升、单位智能成本指数下降」的摩尔定律信仰，坚信人的创造力不可替代；说完又补上极其坦诚的入行第二理由——当年 Gap 期试还不算强的早期 ChatGPT 写代码后瞬间醒悟「打不过，就得加入」（别人都用热兵器了，死守冷兵器必败）。常面试年轻工程师的择因则以银行引入 ATM 机的历史安抚焦虑：当年人人都怕柜员大裁员，结果 ATM 提效后银行网点反倒开得更密（无论城县 5 公里内必有银行）、总从业人数不降反增。他留给听众一句硬话：「一旦你有怕被替代的想法你就先输了」，尽早把 AI 当伙伴、提效工具与长期挚友，主动走入新版本的舞台。

机制拆解：把「自我进化」拆成三个完全不同的过程

层次改变的对象反馈来源与生效范围本场代表案例主要失效边界
1. 任务内纠错当前上下文内行动路径工具报错、测试输出、检索结果；仅限本次会话M2.5 交错思考、BrowseComp 折返、双 Agent Cross-check长上下文易受早期错误锚定，窗口超载后推理衰减
2. 跨任务外显积累记忆文件、Skill、CLI/Hooks；权重不变用户纠偏与成功流程压缩；跨会话复用Hermes 多层记忆与 Skill、ClawHub 分享、Claude Code Memory环境或版本变化时照搬旧 Skill 易隐蔽出错，记忆污染难清理
3. 参数级学习基座模型权重本身大规模真实轨迹、专家难题蒸馏与验证器奖励MiniMax M2.7 自动化 RL、模型内化外部脚手架若奖励只盯最终得分，易诱发过程幻觉与约束退化

可追踪算例：用 Agent 修一次数据库迁移故障——首轮看报错改通属第一层；把「备份 → 核版本 → 隔离库演练 → 回滚测试」连同适用前提写进 Skill 下次复用属第二层（模型权重未变，若库版本变了死套也会错）；把成千上万条运维轨迹拿去微调或强化学习，让下代模型不挂 Skill 也会避坑，才是第三层。同理，抖音推荐也兼具在线特征更新与离线重训，与 Agent 的本质差异不在「有没有反馈」，而在反馈作用的是单一排序列表，还是可检查、可组合、带环境副作用的多步行动策略。

独立分析：把一线直觉变成可检验的问题

1. 第二只 Agent 赢在视角，还是赢在预算翻倍？

阿岛诚实补了一句关键限定——双 Agent 交叉审查相当于「2 倍预算 + 全新上下文」。要确认收益来自多角色协作而非单纯多算一遍，须在等总 Token 与等耗时预算下对比三组：（1）单 Agent 续思；（2）单 Agent 清空历史重跑（Fresh Restart）；（3）执行者加独立审查者，并用隐藏测试集验收。若审查者只看执行者总结的「小作文」而不核查原始代码与证据，两者反而可能互相背书。类似地，Lost in the Middle 虽证实长上下文存在位置衰减，但拐点因模型与任务而异，不能简化为普遍的「50% 指数悬崖」。

2. 人类把守的是目标函数，且 RL 并非只能奖励结果

阿岛提出「70%—80% 交给 Agent、20%—30% 靠人品味」，精准指出自动化反馈链受制于目标函数质量：测试不完整会被刷分，只盯终局得分则易放松过程纪律。但需要补充一点方法论修正——强化学习并不天然等于「只看结果」，训练中完全可以引入过程检验与约束惩罚；没有训练细节对照，无法单凭外部使用体感断定 Opus 4.7 的退化源自纯结果奖励。对科研系统而言，还须区分「给定假设后加速执行」与「提出候选集之外的新问题」两种能力；yoyo Agent 的目标与审美基调依然由工程师写死，不足以证明零人公司已成立。

3. 「被模型内化」应拆清三种结构变化

外部工具消失未必意味着能力已写入权重，需区分：（1）通用操作写入参数（如原生交错思考）；（2）模型厂商在模型外自建第一方应用挤压套壳（如 Claude Code、MiniMax Agent）；（3）需对接私有数据、合规问责与复杂组织交付的垂直层（如法律意见）。决定护城河的不是泛谈「应用层会不会死」，而是客户究竟为哪一层付费与担责。

4. 历史乐观主义很提气，但不能替代转型摩擦

GDP 曲线、摩尔定律与 ATM 机类比揭示了生产率扩张往往扩大总需求的宏观规律，但 ATM 只替代柜员最机械的一小块存取动作，通用 Agent 触及的则是跨行业认知劳动，迭代速度与覆盖面迥异；即便长期总岗位增加，个体的技能迁移摩擦与结构分化仍真实存在。相比押注线性乐观，择因「尽早把 AI 用成伙伴」落在了当下可控的个体行动上。
