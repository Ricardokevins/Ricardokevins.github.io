苏庭灏的入门学习路径如下：

1. 入门课程：他首先在Bilibili上学习了斯坦福大学吴恩达（Andrew Ng）的机器学习课程，这为他打下了基础。

3. 论文挑战：为了克服困惑、深入理解，他给自己设定了一个为期30天的挑战——每天阅读一篇机器学习论文并做笔记。通过阅读《Lottery Ticket Hypothesis》、《AdamW》等经典论文，他逐渐培养了研究品味（research a taste），能分辨论文的优劣，并对一篇关于象棋和机器学习的论文产生了“自己可以写出更好”的想法。

在学习了Andrej Karpathy的视频后，苏庭灏最初的宏大目标是“自己训练一个世界上最好的大模型”，即便是在1B、0.5B这样的小尺寸模型中做到最好。但他经过计算发现，即使是训练一个小模型，成本也高达数十万甚至上百万元，于是放弃了这个想法。

他转而将学习到的先进论文中的思想，如转写不清的模型或方法名、Value Residual Learning（按转录读法，正式方法名待核）等，在自己编写的Transformer代码上进行实现和改进。经过约200次不同的尝试后，他幸运地取得了一些成果，便决定投稿到自己听闻过的三大AI顶会（NeurIPS, ICLR, ICML）之一——当时正在开放投稿的ICML。他表示，审稿人提供了专业的建议，最终论文获得了很好的评价和分数。

苏庭灏提到，做预训练非常“烧钱”，他很感谢父母的支持。他的论文研究总共花费了约3万元。在实验后期，为了让论文能被顶会接收，他需要将模型从0.5B的规模扩大（scale up），计算后发现这需要花费约6000元。他为此非常紧张，担心即使花了钱，论文也可能因运气不好被拒。最终在家人支持下，他迈出了这一步，并且scale up取得了成功。

在实验过程中，他也犯过代价昂贵的错误。有一次，他因为参数没调好，忘记设置检查点（checkpoint）来保存训练好的模型，导致同时训练的三个模型全部作废，白白损失了1500元。他为此伤心到哭，母亲则安慰他“吃一堑，长一智”。

当被问及数据准备时，苏庭灏表示他用的数据集不算大，最大的是一个20B的公开免费数据集FineWeb-EDU。他承认自己用于训练的代码写得比较混乱（messy），存在效率低下的问题，只有他自己会用。

关于论文方向，主持人提问为何选择Attention机制。苏庭灏解释这并非刻意为之，而是“机缘巧合”。他实验最多的方向是Value Residual Learning（按转录读法，正式方法名待核），这本身就是对Attention中Value部分的改进，最终在这个方向上取得了进展。他的论文《Attention Projection Mixing with Exogenous Anchors》核心思路源于Value Residual Learning（按转录读法，正式方法名待核），即把第一层Attention的Value通过残差连接加到后续层。他的创新点在于：

1. 发现可以在这些残差上使用RMSNorm，并把这种方法从Value扩展到Key和Query上。

2. 他意识到第一层的Attention Projection需要同时服务于当前层和后续的残差连接，于是他将该Projection的宽度乘以二，切成两半，一半用于当前层，另一半用于残差，从而分离了两个功能，提升了效果。

主持人将他的工作与嘉宾所提到的另一项研究提出的“注意力残差”进行对比。苏庭灏明确指出两者思路完全不同：嘉宾转述对方做的是用Attention机制来实现对隐状态（hidden state）的残差连接，而他做的是对Attention内部的projection（Q, K, V）进行残差连接。他坦诚地认为嘉宾所提另一思路更有效（work），因为已经在大规模模型上得到了验证。

对于为何不像陈光宇一样加入前沿实验室（Frontier Lab），苏庭灏表示当时自己只是在摸索，对论文能否被接收并没抱太大期望，所以没想那么多。但他表示如果现在有Lab邀请，他“当然”非常欢迎。

最后，主持人请他分享对AI学习的感受。苏庭灏认为，理解当前主流的Transformer框架，数学上只需要高中水平的矩阵乘法。但更关键的是培养对Transformer和GPT的“直觉”。他将这种直觉描述为一种“灵光一现”的理解，有时很快领悟，有时则需要几十天。他提到自己接触神经网络已有两三年，是一步步从强化学习过渡到Transformer的。Andrej Karpathy的教学视频，他初看时完全不理解，只是照着敲代码，但这些知识在他脑中“沉淀”了半年到一年后，才突然有了“aha moment”。一个具体的例子是，他通过将Q（Query）、K（Key）、V（Value）类比为“我想寻找什么”、“我是什么”、“如果你觉得我有趣，可以从我这里获取什么信息”，才真正理解了QKV机制。

嘉宾先说明，选择 Attention 并非预先规划的唯一方向，而是因为他在 Value Residual Learning 上实验最多；这种方法修改 Attention 内的 Value。他也尝试过 Residual、位置嵌入等，最终是在这个方向上取得进展。节目列出的论文题名是《Attention Projection Mixing with Exogenous Anchors》。

他先复述基础思路：将第一层 Attention 的 Value 加到后续若干层，形成残差路径。随后介绍自己的两个改动。第一，可以在这些残差上使用 RMSNorm，并把相关思路从 Value 延展到 Key、Query；第二，第一层 Value 既要在本层使用，又要传给后续层，他把第一层 Attention Projection 的宽度乘二，再切成两半，一半服务本层，另一半服务后续残差。这里的变化对象是 Attention Projection 的输出和跨层传递，不是把整层 hidden state 与注意力输出笼统相加。

主持人随即问与另一‘注意力残差’工作的区别。嘉宾明确说两者完全不同：对方是用 Attention 处理 hidden-state residuals，他是残差 Attention Projection，名字相似但作用对象不同。谈话没有清楚交代另一项工作的作者与机构。

当主持人问哪个思路更 work，嘉宾指向对方，称‘scale up 已经被 2.5T 那个被证明了’。两套 ASR 均出现 2.5T 音写，但没有单位语义或实验配置。审读只记录为‘嘉宾提到 2.5T 作为对方大规模验证的依据，具体含义待核’，不能解释为 2.5T 参数、Token、训练数据或模型规模，更不能拿它证明嘉宾自己的方法同样在大规模上有效。

嘉宾把 Q 理解为‘我想寻找什么’，K 理解为‘我是什么，别人可用它寻找我’，V 则是‘如果你觉得我有趣，我具体向你提供什么信息’。Q、K 相互作用后得到每个 head 上两个 token 有多大连接的数字；V 则承接被连接后要读取的信息。这是嘉宾用于建立直觉的类比，不是完整的注意力公式。为了不把比喻误写成算法，审读保留其语义分工，不据此增加 softmax、维度缩放或多头拼接的未讲步骤。

展开补充算例与独立延伸分析（已去除与正文重复的旧版对话复述）

本文补充解释：同一份投影服务两种用途，冲突怎样发生？

简化算例，不是嘉宾实验或论文原式

这里只把“同一份表示受到两个用途约束”缩成可手算的优化问题。实际语言模型的目标来自后续网络和文本预测，不是下面人为设定的两个数。

先分清对象：Q 是查询，决定当前位置想找什么；K 是键，提供被匹配的线索；V 是值，提供匹配后取出的内容。三者原本通常有各自的投影权重。#151 的“两种用途”首先发生在同一份 V 既供本层使用、又传给后层，并不是 Q、K、V 三者共用一个矩阵。类似分工能否推广到 Q、K，要另做实验。

本例输入与参数输入只有一个数，记为 \(x=1\)；投影权重为 \(w\)，所以输出 \(v=wx=w\)。本层与后层都直接读取这个输出。
两个教学目标人为设本层希望输出接近 0，后层希望输出接近 2；用平方误差衡量偏离。目标取值只为展示相反约束。

本层损失是 \(L_{\mathrm{local}}=w^2\)，后层是 \(L_{\mathrm{later}}=(w-2)^2\)。等权相加，逐项展开：

\[\begin{aligned}L(w)&=w^2+(w-2)^2\\&=w^2+w^2-4w+4\\&=2(w-1)^2+2.\end{aligned}\]

平方项最小是零，故最佳共享权重是 \(w=1\)，但总误差仍为 2：本层得到 1，离目标 0 差 1；后层也得到 1，离目标 2 差 1。再看更新方向，在 \(w=1\) 处，本层梯度 \(2w=2\) 想把权重往下推；后层梯度 \(2(w-2)=-2\) 想往上推，合起来为零。停住并不是两个用途都满意，而是相反要求抵消。

把投影拓成两个输出，并专门分配用途：

\[\begin{bmatrix}v_{\mathrm{local}}\\v_{\mathrm{later}}\end{bmatrix}=\begin{bmatrix}w_{\mathrm{local}}\\w_{\mathrm{later}}\end{bmatrix}x,\qquad L=w_{\mathrm{local}}^2+(w_{\mathrm{later}}-2)^2.\]

取 \(w_{\mathrm{local}}=0\)、\(w_{\mathrm{later}}=2\)，代入得到 \(L=0^2+(2-2)^2=0\)。本例消除了共享参数约束，同时也增加了参数。因而“拆开后更好”本身分不清是容量变多，还是用途分配更合适；如果两个目标本来都希望得到 2，共享 \(w=2\) 已能零误差，更谈不上拆分必胜。

可将四组实验设为下表。输入宽度为 \(h\)，每个用途输出宽度为 \(d\)；参数数只计投影主项，其他新增权重必须另算。

组别投影和路由要检查的差异
A 原连接一份 \(h\to d\) 投影，两用途共享，约 \(hd\) 参数。基线。
B 只拓宽一份 \(h\to2d\) 投影，两用途都读取完整表示，再用预先规定的固定映射回到 \(d\)，约 \(2hd\) 参数。B−A 检查增加宽度是否足够；同时报告固定映射的影响。
C 拆用途同样 \(h\to2d\)，两半分别供本层和后层，每路 \(d\)，约 \(2hd\) 参数。C−B 在投影参数相同时检查路由分工；读取宽度仍不同，须承认该取舍。
D 加归一化在 C 的后层复用路径加入预先规定的 RMS 归一化。D−C 单独检查尺度控制；若有可学习缩放，计入参数与预算。

这四组是本文建议，不是源论文已有消融。B 的固定读出也可能压掉新增信息，故 C−B 不是绝对纯净的“只拆分”归因；应预先规定读出方式，并另查可学习读出的结果。固定数据、训练 token、优化器和评测，再报告实际参数与计算量；等参数不等于等计算。还可在共享基线上测两用途对同一权重的梯度夹角：频繁相反支持冲突假设，基本同向则削弱它。B 已达到 C 的表现，或收益仅随预算增加，都不足以归因于拆分。
