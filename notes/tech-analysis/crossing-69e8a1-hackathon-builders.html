黑客松里的七组创造者：从 48 小时原型到真实需求

一场比赛如何让想法、原型、陌生人的合作和个人经历交汇？又有哪些问题需要在离开赛场后继续回答？

七组作品与故事 · 从想法到检验 · 独立判断 · 资料与边界

先把现场讲清楚

Koji 采访小红书黑客巅峰赛负责人散兵及七位参赛者。比赛围绕 48 小时创造原型展开，受访者介绍的不只是获奖作品，也包括失败的演示、现场互助和他们各自想解决的问题。组织者说，技术热点变化很快，与其只追逐下一个流行词，更希望认识那些持续动手创造的人；他说现场有两百多位参与者。

1. 小鹅：把手机放进「面包机」

设计专业研究生王心怡，大家叫她小鹅，和团队围绕注意力做了一个专注装置：把手机放入像面包机一样的设备中锁住，通过对话和打印提供物理反馈；另一个摄像装置尝试记录使用过程并生成专注报告。她的出发点是：当手机不断吸引注意力，单靠口头提醒自己「专心」可能不够，改变身边的物理环境也许能帮助人停下来。

她说现场组队像一场不断换队的游戏，设计能力成了被团队争取的资源。她还记得一个无法轻易搬动的水母灯原型：工作人员守了一夜，选手们也帮助别组保护和完成作品。赛后她感觉创造的兴奋仍在持续。节目没有展示专注装置是否长期有效，也没有说明摄像数据如何保存。

2. 动漫大头：让 Agent 想象自己的外形

头壳团队带来了可穿戴的动漫大头，并尝试让 Agent 根据描述生成角色五官、纹理和三维资产。Koji 问是否真的有人下单，团队明确回答：现场有人尝试，但没有接入真实订单系统；完整生产、交易和交付比演示复杂得多。

现场有人把大头放到会移动的机器人上，吸引了围观。团队把它视为有趣的需求线索：面容可能影响人与机器的互动。他也分享个人体验，戴上角色头套后，自己得到的外界反馈和日常身份很不一样。这能说明现场引发了兴趣，不能单凭围观推断真实购买意愿或长期陪伴效果。

3. Pocket Guitar：先让不会弹的人感到自己能演奏

全场大奖得主叶博文介绍一款便携式类吉他设备。用户选定一组和弦，用摇杆切换，再触摸琴弦发声；团队预先组织了相容的音，降低初学者上手时出现不协调声音的概率。Koji 在现场试弹，感受到「自己也能做出音乐氛围」。这里的核心不是声称任何演奏都会成为好作品，而是把前期乐理门槛藏进了交互设计。

组队时，博文先向别人介绍想法；他承认自己不精通合成器，后来找到有音乐技术背景的成员一起做。路演对他还有个人意义：童年一次上台失误后，他一直紧张，这次虽然仍在发抖，却开始享受舞台。他借鉴发布会从口袋取出产品的呈现方式；获奖后希望未来做成品牌，但采访时产品尚未正式发售。原型的现场掌声和未来量产是两个不同阶段。

4. Edward：网页能否随人的注意力变化

设计师 Edward 的团队提出动态网页界面：减少当前不相关的内容，把可能需要的按钮移到鼠标附近，并尝试把对用户意图的推测变成可选操作。他认为目标不一定是节省每一分钟，而是让注意力落到更值得处理的内容上。官方简介将项目写作 Attune，现有转写有另一种拼法，本文沿用官方写法。

团队开赛时并没有达成共同想法，争论了十多个小时；他们后来决定各做一个可体验的小 Demo，再让队友试用和选择。最后 Edward 的方案被选中，团队用剩余时间继续实现。这个过程说明，快速原型可以让抽象分歧变得可讨论，但哪个界面真正帮助不同用户完成任务，还需要赛后测试。

5. 陈锦初：用夸张装置讨论自律，也谈公开创作

连续创业者陈锦初展示的「赛博紧箍咒」尝试用摄像头识别预设的不自律行为，再触发佩戴装置的刺激。他把它描述为一个带有玩笑性质的原型。概念引人注意，并不说明刺激方案安全、识别可靠或适合作为行为干预产品。

他还观察到越来越多非编程背景的人参加活动，作品也更贴近日常。他主张公开展示制作过程：尽早获得讨论和用户反应，再判断是否继续投入。这里提到的 PMF 是产品与市场需求的匹配，Traction 是实际获得用户或业务进展；曝光和点赞可提供线索，却不能单独证明用户会持续使用或付费。

6. Queenie：把比赛变成更多人可参加的活动

投资人 Queenie 希望让任何人都能发起线上创作比赛：设置主题、人数、时间和可能的奖金，参与者边制作边展示，观众可以体验、提建议并投票。她把喜欢的 Vibe Coding 与黑客松结合，希望降低参与门槛。官方简介称作品为 Vibethon 赛码场，转写中的英文名称有多种写法，故以官方简介为准。她说团队计划继续完善并上线；节目中的计划不等于已经上线或形成稳定社区。

她还喜欢一个面向公共场所使用 AI 的降噪口罩概念：人在说话时希望既能和系统沟通，也尽量不打扰旁人。这个例子把 AI 交互从屏幕扩展到真实场所，也提出收音、舒适度和周围人体验等后续问题。

7. 李鹏程：想在康复过程中先被听见

李鹏程从事听障人士言语康复，和手语翻译一起参加访谈。他说团队想做一个类似《名侦探柯南》变声器的设备：将较难辨认的发音转换成更容易理解的表达。他自己的经历是，训练口语可能需要很长时间；他不希望必须等到康复完成，才能与别人顺利交流，因此希望在训练过程中就增加表达方式。

团队的硬件在现场烧坏，最终没有获奖；3D 打印遇到困难时，其他参赛者帮忙完成模型。他希望以后继续开发，让自己能借助产品上台演讲。现场原型并未证明对不同使用者的识别准确率、表达忠实度或实际可用性，但问题来自具体生活经验，失败也没有抹去它的价值。

比赛之后：关系、年龄和创造的持续性

散兵说，主办方既营造轻松、互助的环境，也用倒计时和有限资源制造压力。Koji 把黑客松比作一个能遇见同行者的地方：除了作品和奖项，陌生人可能在合作中形成以后继续交流的关系。关于外界过度强调选手年龄的质疑，散兵回答，更看重的是对新技术的兴趣、接触时间和行动，而不是年龄本身。

这些感受解释了比赛为什么对参与者有吸引力，但不能据此要求每个人都通宵或把高压当成创造的必要条件。不同的人需要不同的工作节奏和支持。

从一个想法到可检验的产品

七组作品分别卡在不同问题上。口袋吉他的首要体验是「第一次拿起来能否发出自己喜欢的声音」；专注面包机需要知道用户是否愿意把手机交给设备；辅助表达设备则要看输出是否忠实于使用者真正想说的话。它们虽然都能现场演示，成功标准却完全不同。

本文自拟的验证方式：如果要继续做口袋吉他，可以邀请不会弹琴的人，先不解释操作，让他们用几分钟尝试；记录能否理解和弦切换、是否愿意再次使用，再与其他简单乐器比较。对辅助表达设备，应与听障使用者共同设定场景，让使用者核对系统输出、方便纠正或拒绝表达，并观察不同口音、噪声和交流对象下的表现。两者都需要长期体验，不能只用观众掌声代替。

Edward 团队用多个小 Demo 代替长时间口头争论，是另一种低成本试验：每个人先做出可以点击的东西，团队更容易讨论具体差异。但选中哪个 Demo 仍受团队成员偏好影响，之后要把它交给真正的目标用户。

独立判断：原型、需求和机会之间还有什么

快速做出来，帮助发现问题；不会自动证明问题重要

有人围观机器人头套，说明它能吸引注意；有人询问口袋吉他在哪里买，是比围观更进一步的信号。要判断商业需求，还需看到有多少人愿意在明确价格、等待时间和产品限制后购买，是否持续使用，以及生产和售后能否支撑。对无障碍工具，购买意愿之外，正确表达、尊严和适配不同用户同样重要。

公开创作既能找用户，也能找到合作者

访谈里小鹅获得其他团队帮助，博文找到音乐技术成员，Edward 的团队通过互相体验原型达成选择。这些故事说明，公开作品可以暴露自己在解决什么问题，进而吸引不同能力的人参与。对一个研究者或产品探索者，一个可行的第一步可以是带着真实问题和一个小原型参加活动，观察别人理解哪里、提出什么反例；这能带来信息，但是否继续投入仍要结合时间、资源和自己的目标。

创造力并不只属于特定年龄和职业

本期参赛者包括设计师、开发者、投资人和来自真实使用场景的团队；他们贡献的分别是问题、体验、实现和组织能力。低门槛工具可以让更多人参与，但硬件稳定、隐私保护、领域知识和长期交付仍需要积累。作品来自不同经历，这比用年龄或单次奖项判断一个人的潜力更有信息量。

证据边界与资料索引

依据节目官方简介与可取得的第三方机器转写整理，未逐字听审或观看现场演示。转写与简介对部分姓名、英文项目名存在差异，采用简介名称并尽量避免推断未确认的身份。作品状态和获奖情况以访谈时为准；本文没有独立测试这些产品，验证方案为本文提出。
