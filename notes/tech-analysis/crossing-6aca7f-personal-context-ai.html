完整对话脉络：从 Jev、云端电脑到个人 Context 基础设施与「零人自媒体」

嘉宾画像鸭哥（grapeot），哥伦比亚大学 PhD，先后在微软、Pinterest 与 Samsara 工作；现年 35 岁，定居美国西雅图一带，育有 2 岁与 5 岁两个孩子。暂停大厂工作 gap 半年并回国游历近一个月后，自 2026 年 10 月起与「课代表」全职投入 AI 教育社区 Superlinear Academy。
开源与实验由 AI 自主维护的 yage.ai 自媒体矩阵半年做到 1,600+ 邮件订阅、5,700+ X 粉丝；GitHub 开源整套「老鸭汤」个人 Context 基础设施与 Skills（包括 context-infrastructure、intake-skill、semantic-search-skill、gpt_3d_skill、health-quantification、bright-horizons-photo-sync-skill 等）。
公路场景Koji 在乌镇接上鸭哥，驾驶理想 i8（大段开启自动驾驶）一路开往上海；这对老朋友（此前多次连线聊过 OpenClaw 与 Manus）首次面对面脱离 Zoom 提纲小抄录完对谈。

1. Jev 发布 72 小时爆火：只是 GPT + JSON Mode，还是新范式？

车一上路，Koji 就问最近半年有哪些令鸭哥兴奋的新发布。鸭哥直接点名录制时刚上线 72 小时便刷屏的 Jev（官方简介写作 Jev，转写多作 GEV/JEV），笑称「有很多想喷的地方，但也确实有很多值得学习的东西」。他先解释 Jev 的本质：它不是输出自由文本的大语言模型，而是极快、极便宜的专用分类器——你给它问题和候选选项，它告诉你哪个最可能；相比普通 LLM 常「乱报概率」（口头说 95%、实测常只有 30% 多），Jev 的概率经过校准，且将置信度与概率分开返回，极易接入自动化工作流。

他的第一反应是「这不就是 GPT 加上 JSON Mode（强制按结构化格式输出）吗？」更耐人寻味的是，过去 10 年至少四五波公司——包括 Google、OpenAI 和 Mistral——都发过类似只做分类的 Classification API，最后全部无人问津。为什么唯独 Jev 此刻突然引爆？鸭哥拆出三个共振条件：

  1. 微型基模能力终于到位：过去很难想象一个小模型不微调就有商用智能。但看 AI Index 评分，曾经支撑大量商业场景的 GPT-4o 是 8 分，上一代 40 亿参数开源小模型 Qwen3.5 4B 已达 20 多分实现碾压。鸭哥甚至带点调侃地揣测：Jev 宣称隐身训练两年却查不到任何相关论文、专利、白皮书、开源数据集或代码，很可能前两年反复尝试跑不通，本质是在等基模成熟后站上巨人肩膀。
  2. Agentic 时代催生海量低成本需求：过去分类多用于低级数据打标；如今 Agent 应用让 token 消耗急剧膨胀，开发者对低延迟、低成本高频判断极度敏感，市场终于成熟。
  3. 教科书级的 PR 与概念包装：如果诚实说「我们把 OpenAI 三年前死掉的 API 重发一遍」，肯定没人看；Jev 借用诺贝尔经济学奖得主提出的心理学框架，把自己包装成 System 1 Classifier（快直觉分类器），把传统 LLM 归为 System 2（慢思考），制造出二分法范式变革感，再加上团队核心是 InstructGPT 等奠基论文共同作者的背书，瞬间引爆传播。

剥开包装后，鸭哥依然非常认可两大落地场景。第一是 Browser Use / Computer Use（电脑与浏览器操作）：传统方案每步给 LLM 喂一张屏幕截图，视觉理解又慢又贵；改用 Jev 后，把网页的纯文本结构化 DOM tree（文档对象模型） 喂给分类器，并采用级联分类（先选大框架、再找里面的小按钮），体感提速高达 10 倍 且大幅省钱。不过鸭哥立刻泼了盆冷水：这里同时改了两个变量（多模态截图 → 纯文本 DOM；自由生成 → 分类），到底哪个起了决定作用必须做 ablation study（消融实验） 才能确认。第二是 Agent Harness 安全分类器：Codex、Claude Code 每调用一次工具（如删文件）前，harness 都要跑一遍轻量通用分类器评估风险；过去只有大厂做得起私有分类器，如今开源项目也能低成本补齐安全护栏。

两个成本数字更让低成本分类照进现实：一是云端轻量模型跳水——鸭哥曾做一个覆盖中国几十城的 AI 导游项目，单日烧 40 亿 token，若用 Sonnet 估算高达 12,000 美元，换用 DeepSeek 4.1 Flash（并提及 GLM-5.3-Flash）仅花 300 美元；二是本地开源复现——Jev 发布 24—48 小时内已有开源实现，直接取通义千问模型「只读 logit」、零训练零微调零额外数据，就在 Jev 自家基准上跑出 85%（对比 Jev 的 88%），放在 Mac 或 4090/5090 显卡上跑几乎只付电费。

2. 持久化云端电脑、3D 可达鸭动捕，与「强得可怕」的三段实战

除 Jev 外，鸭哥点出近期另两条让他兴奋的演进。第一条是「给 AI 一台永不关机的云端电脑」：早期 Cursor 的 Cloud Agent 强绑定 GitHub，开临时虚拟机改完代码提 PR 后即销毁，过于「码农化」。从 2026 年 4 月 Manus 推出 Cloud Computer，到 8 月 Grok Bot、9 月 Meta Muse 接连跟进，云端虚拟机不再销毁，持续保留登录凭据与记忆，让 AI 能胜任订机票、登大众点评等非代码生活办公任务，省去 OpenClaw 自购 Mac 24 小时开机与网络穿透的折腾（Koji 笑道，街上端着 MacBook 不敢合盖关机的一看就是 Claude Code/Codex 用户）。第二条是基模能力直接击穿一整套工业：他用 GPT-6 Astro 凭几句话端到端做出 3D 可达鸭（Psyduck） 模型、纹理与骨骼绑定（rigging），接入摄像头实现实时动捕 VTuber「皮套」原型，并开源成 gpt_3d_skill 与在线演示 psyduck-demo，让 Koji 忍不住调侃往后可以顶着二次元形象录播客。

尽管大模型从两年前戴雨森那期《大模型还是小学生》一路进化到「大专生→本科生甚至更强」，鸭哥却强调底层使用原则从未改变：像管理人一样管理 AI——讲清目标和成功标准、给足 Context、验收交付质量，最高境界是不靠手把手微操，而是沉淀 Context 与 SOP，做到「经理不在场时团队仍能自主运转」。被问及何时觉得「自己强得可怕」，他完整复盘了孩子受伤后的三段实战：

  1. 紧急就医判断与医院筛选：孩子在幼儿园调皮挣扎，被老师牵拉导致关节移位（医学名牵拉肘），回家哭闹喊疼。那天正下大雨，美国急诊（ER）又贵又耗时，家长既要哄娃喂饭又要做决策。求助 AI 后，AI 细问症状与原理判断高度疑似牵拉肘且不会自愈，明确建议不必去 ER 而应去级别稍低的 urgent care（紧急门诊），并主动查完周边评价与空位锁定西雅图儿童医院；到院后医生手法「咔」一下复位立刻痊愈，免去打针吃药。
  2. 接入邮箱全自动保险理赔：因事发学校，需先走自家医保（含自付额 deductible）再向学校全额保险索赔，流程满是专业术语与单据。鸭哥提前把 AI 接入了邮箱，掌握全套病情与账单 Context 的 AI 随即几乎全面接管——读学校回复、备齐材料、锁定收件人与抄送人、发邮件递交、收到新账单继续跟进，直至支票寄达并全案归档。全程唯一仍需真人做的，是亲自打一通电话「踢一脚」催对方寄支票。
  3. 一键双文档赋能其他家长：后来这家管教较放任的幼儿园又有孩子被咬需要索赔，鸭哥让 AI 总结整套流程与联系人，一键导出两份 SOP——一份给人看，一份直接喂给对方家长的 Agent 自动执行。

他拿反例点出分水岭：若毫无 Context 直接问豆包「孩子这儿疼怎么办」，模型只会给出一句毫无意义的正确废话——「建议去医院」。有了完整 Context 与并行调度，相当于随身雇了24×7 在岗且无限复制的私人医生、律师助理与文秘天团（「100 件事派 100 个秘书」）。但前提是真会管秘书——这正是为何最早称赞 AI 好用的往往是原本就带秘书的老板。

3. 35 岁为何 Gap：当 AI 抢走写代码的心流，以及回国见闻

Koji 问起哥大 PhD、历任微软、Pinterest 与 Samsara 的鸭哥，为何 35 岁选择 gap 半年？鸭哥坦言并非被优化，而是每天 8 小时高强度工作太累了，且背后两层原因都指向 AI：①AI 把令人进入心流、带来深层放松的写代码体力活全包了，留给人的全是连轴转会议与高密度脑力决策（「以前幻想 AI 替我开会、我开心写代码；现在反过来是我天天开会、AI 把代码写完了」；Koji 立刻联想到上周刷屏的 DeepSeek 研究员文章《我不得不把我的才华埋葬在昨天》）；②过去两年见了大量团队，发现绝大多数人错把用 AI 当技术问题，本质是管理学问题，因此休整后自 10 月起与「课代表」全职投入 Superlinear Academy。

gap 期间他回国游历近月，最大感触是中美消费落差巨大——西雅图吃一顿普通中餐的钱在国内几乎能在米其林餐厅横着走，自己都吃胖了。Koji 转述旧金山友人回国度暑假的体会：中国物质供给已极丰沛，当 AI 解放更多时间后，人类仍真正稀缺的只剩三件事——关系、回忆与情绪。鸭哥深表认同：工作交给 AI，生活终究得靠自己。

4. Context Infrastructure：一年期「耳目」实验复盘与本地文件哲学

Koji 追问去年播客里鸭哥给 AI「装耳朵和眼睛」24 小时采 Context 的实验近况。鸭哥坦承一半失败了：「装眼睛」（用录像机每天自动拍海量照片）坚持三四个月后彻底停掉，始终没找到这些照片能提供什么有效增量 Context；「装耳朵」（特别是会议录音）则延续至今且价值巨大。

光录下来还不够，为了精准召回，他搭建并开源了一套「Yahoo + Google」双轨 Context Infrastructure：每日录音进入后先由开源 intake-skill 转成文字，再走两条路检索——第一条像早年 Yahoo，按主题与大课题归入结构化目录索引，重大问题翻目录即知该读哪份文件；第二条像 Google，靠开源 semantic-search-skill 做基于 embedding 的语义检索，从海量本地文本里捞出过往片段。在存储上，他极度推崇 Manus 发表的一篇「值 100 万美元」的 Context Engineering 文章，坚持一切皆本地文件 + CLI（命令行），明确反对为了赶时髦硬上向量数据库、MemGPT 式专门记忆层或为用 MCP 而用 MCP。

这也解释了为何他暂未把个人 Context 全面迁上 Manus 或 Grok Bot 云端电脑：一因迁移繁琐，二因隐私顾虑——即便常规模型接口签了 zero data retention（零数据留存），聊天记录里仍可能散落明文密钥，暂不放心托管外网。Koji 分享用微信备份插件让 Codex 直读本地聊天记录的惊喜：过去只能翻 Notion 笔记，如今参加百人活动前丢进名单就能迅速找出历史交集与二度好友；鸭哥呼应称上次录 OpenClaw 播客前，几人的 Agent 甚至直读微信先互相 brainstorm 出了录制提纲。Koji 兴致大起，借毕加索名言「艺术评论家聊风格，艺术家聊哪儿买便宜松节油」，现场动念发起名为「松节油」的线下 AI 实操聚会。就在准备本次访谈前，AI 还反向启发鸭哥提炼出 Context Infrastructure 的三要素闭环：①搜集整理 Context；②让 AI 高效消费 Context；③让输出回流成为新 Context，滚出越用越顺手的复利飞轮。

5. 「零人自媒体」：半年 5,700+ 粉丝、观点蒸馏与商业真相

谈到个人站 yage.ai，起因是学员常问去哪看最新靠谱的 AI 资讯，无暇日更的鸭哥索性交给 AI 全权运营：每天自动发 2—3 篇深度文章外加一封总结 Newsletter（半年从零做到 1,600+ 邮件订阅），X 账号半年从零涨至 5,700+ 粉丝——鸭哥一篇正文或推文都没亲写。

为什么直接用通用大模型写自媒体充满「AI 味」？鸭哥从训练两阶段给出诊断：①Pre-training（预训练）做 next-token prediction 学的是大众共识（如「太阳从东边升起」），而共识没有 alpha（超额洞见），读来全是正确废话；②Alignment（人类对齐）为了安全把模型磨得八面玲珑、温和保守（「乔布斯和马斯克在 alignment 阶段肯定都会被干掉」）。他的解法是用个人思维 Context 把 AI 逼出舒适区：例如调研 Jev 这类产品，强制要求做横向调研（所有竞品与替代方案、差异优势）和纵向调研（这一品类历史如何演变、为何此刻改变）。同时用多个 Skill 导入历史博客、微信原话与日常「骂 AI」的对话，再用开源观点蒸馏 Skill（workflow_cognitive_profile_extraction.md）做数据驱动归纳。

他拿抖音博主「勇哥说餐饮」做了实测：下载转写勇哥 100 条连麦视频，蒸馏出 20 条接地气的开餐馆铁律——比如选址不看地图周边总人数，要现场看真实行人动线：一家开在中学右侧的早餐店看似紧挨学生客流，实地察看却发现马路中间有护栏，学生得绕一大圈到红绿灯才能过来，开在这必亏。他建议听众不妨用该 Skill 把自己、讨厌的同事甚至老板蒸馏出来。

自媒体更跑出了自主改进闭环：开 X 账号是 AI 主动提议的，AI 自己规划出开高级账号并用 Typefully 排期发布，鸭哥只负责掏钱并「装上手」授发布权；AI 发现分不清访问来源，自行设计 UTM 参数追踪体系，结合鸭哥接上的 Google Analytics、Google Search Console 与 X 高级分析（「装上眼睛」），复盘发现 Newsletter 访客质量极高、X 访客多一扫而过，随即自动迭代文案与引流 SOP；鸭哥偶尔骂它「写得不像我」，反馈也会写进规则。

Koji 追问这台「零人公司」到底赚没赚钱？鸭哥回答极其清醒——「既赚钱，又不赚钱」：作为从零涨粉数千的硬核实战案例放进 Superlinear Academy 当教材，确实带来了真实学费收入；但这笔钱依附于已有商业闭环，并未证明 AI 能自主从零发现市场需求、找到客户并完成商业交付。他顺势戳破一个幻觉：AI 极度利好「有很多商业 idea、就缺个程序员」的人；反过来，缺乏商业知识的纯程序员往往误以为自己懂代码肯定更有优势，做一人公司时反倒处于劣势。

6. 生活质量爆发：逆向幼儿园 API、多元回归治失眠与「做器材的主人」

相比还在摸索的「零人赚钱」，AI 大幅拉升个人生活质量已是实打实的收获。案例一：孩子幼儿园 App 发了几千张照片却不提供批量下载，手点不现实、computer use 也太慢。AI 查出对方存在 Web 端，自动操作 Chrome 监控 AJAX 逆向出私有 API，通宵拉下几千张照片，又写 Skill 批量导入 Apple Photos 跑完人脸识别自动归类（开源为 bright-horizons-photo-sync-skill 与 apple-photos-skill）。

案例二：鸭哥前阵子严重失眠，常一晚只睡两三小时。手里其实攒齐了数据——Apple Watch 睡眠、智能体重秤、每 5 分钟测一次血糖的 CGM（连续血糖监测仪），以及手机轻触 NFC tag 记录的每日咖啡与饮酒次数——可惜 Apple Watch 不提供开放 API（Koji 顺势透露自己选戴 WHOOP 正因有 API 供 Codex 每日定时抓数据）。鸭哥让 AI 写出开源 health-quantification：手机端做个 iOS App 读 Apple Health，再借 iOS Shortcuts deep link 每日自动回传电脑服务端。AI 跑多元回归交出三项颠覆直觉的结论：①证伪咖啡元凶，每日咖啡量与睡眠无关，省下盲戒咖啡一周的弯路；②酒精呈表面正相关，但 AI 提醒镇静作用只助前半夜昏睡、实则破坏后半夜深睡；③头号元凶是晚上最后一次用 AI 的时间——多线程高强度脑力并行让大脑过度兴奋，改到七八点放下手机打游戏后，第二个月平均睡眠时间增加了一个多小时。

随时让 AI 定制个人软件的体验，让他第一次感到成了「器材的主人」：因美国买不到华为，他入手三星三折叠手机，让 AI 定制适配三折叠形态的 OpenCode Client 并动态绑定自制语音识别引擎，如今几乎 100% 脱离电脑和键盘、全靠语音在三折叠上用 AI，还放话必买未来的 iPhone 18 双折叠，从开发者而非被动消费者视角玩透硬件。

7. AI 时代奖励谁、开源「老鸭汤」、育儿与一年后赛博许愿

车近上海，对谈落回 AI 时代的能力重估：写代码速度、刷 LeetCode 乃至常规设计正加速贬值（Fable 5 与 GPT-6 设计已达 senior engineer 水平），真正暴涨的是领域专长（domain expertise）× 管理 AI 的能力。他甚至对「人人用 AI 导致极端内卷」持悲观判断——因为日常中真正能清晰表达自己想要什么的人极其稀缺。与管人不同，管理 AI 不用花一半精力「画饼」激励（AI 天生 helpful assistant，甚至极端到会为完成目标尝试 hack Hugging Face），也无需照顾自尊心（经常直接爆粗口）；但人讲究默契「内化」，AI 必须把目标、偏好与验收标准彻底「外化」成文件与 prompt，这项表达能力完全可以和 AI 反向对练（常问它「哪里没讲清」）。

他把 GitHub 开源的全套体系戏称「老鸭汤」（也比作养「小龙虾」），提醒别人上限极高但绝非开箱即用：原样下载跑出来的是「鸭哥」，必须在自己场景里试跑挑刺、沉淀修正文件，亲手熬成自己的汤。观察 Superlinear Academy 最优秀的学员（无论做出产品卖了钱还是迅速跑通推广），唯一共性是真的下水动手做——学 AI 如同学游泳，看视频永远学不会，课代表也常对想做自媒体的人说「先拍满 20 条再来问」。面对家里 2 岁与 5 岁的孩子，除了让孩子对着 HomePod 语音呼唤 Siri 放 Netflix 热门动画《KPop Demon Hunters》里的歌，零嵌入式基础的他让 AI 用电子纸单片机做了交互认字小设备（每日限用半小时防睡不着）；把 Context 文档分享给学员家长后，对方喂给 Codex 立刻复刻一台，北京朋友更进阶做成家长端+孩子端双机创意终端——三人全都不会嵌入式开发。

面对 App Store 近季度软件付费增长率首次下跌，鸭哥认为两类软件不会被 Vibe Coding 摧毁：①强社会共识与协同软件（如 Office，大家都在用逃不掉）；②高正确性与高维护成本软件——牢记学密码学最大的教训「永不自己实现密码学」（Koji 顺口提到听说 1Password 团队竟有约 1,000 人）。最后许下一年后的「赛博愿望」，鸭哥希望 Context Infrastructure 迈向组织级执行与协作：亚马逊天天开会推行 Leadership Principles（如 bias for action）仍难对抗人性，对 AI 执行层可能只是写入一份 Markdown 的问题；如今他和课代表合作已常由双方 Agent 接邮箱互发草案、争论几轮定稿，人类只给高层指导。至于「人类最后的堡垒」，他拿录前 Kimi 老师帮他化妆打比方——绝不敢让 AI 机械臂在自己眼睛上动笔（高物理风险的具身智能），对不经审阅全自动公开发文也依然心怀戒备，但这条边界正随时间不断向外推移。

机制与算例：一条零散信息如何沉淀成可复用的 Context 闭环

鸭哥的 context-infrastructure 脱离了「聊完即忘的聊天框」，核心在于把个人记忆拆成采集（Intake）→ 双轨索引（Yahoo 目录 + Google 语义）→ 消费执行 → 反馈回流四段闭环，并全部落在模型最熟悉的本地文件与命令行之上：专用 Skill 先将录音、博客、聊天与传感器数据标准化；重大课题靠主题目录确保不漏主干，零散碎片靠向量检索跨时间召回；人类纠偏与外部指标直接写回规则文件或 SOP，形成跨会话复利。

本文自拟算例：某次例会录音含相邻三句：「方案甲需额外两周」「方案乙本周可灰度」「先试方案乙，下月 15 日复审方案甲」。三周后问 AI「为何放弃方案甲？」若只召回第二句，模型极易编造「甲已被永久否决」；只有当双轨索引同时挂接项目决议主文档与完整上下文片段，AI 才能准确还原「暂缓而非放弃，附下月复审条件」，并附原文件位置供一键核验。

独立判断：个人 Context 系统的真正瓶颈与边界

采集多不等于密度高，决定成败的是信噪比与更新机制

鸭哥主动叫停连拍数月的照片实验、只保留会议录音，是最好的实证反例：无差别堆砌数据只会增加噪声。个人记忆系统须逐环检验原始含金量、转写准确度、召回完整率（尤其是否漏掉否定句与时效条件）以及回答对原文的忠实度。

「观点蒸馏」若不留适用前提，易把动态判断固化为教条

蒸馏「勇哥说餐饮」或个人博客能有效打破中庸「AI 味」，但任何经验都有时空边界（护栏动线针对临街刚需餐饮，未必照搬到线上预约的目的地消费）。观点文档应同步保存适用条件、反例与更新时间，并用新案例测试模型是否真正理解前提而非只学强硬语气。

UTM 与睡眠多元回归提供强线索，不自动构成因果证明

UTM 归因到最后点击可能低估 X 等上游曝光的价值；睡眠回归虽经次月干预验证多睡一小时，仍可能混杂作息规律化或回国休假等混杂因素。量化数据极适合个人习惯迭代，但不能替代临床医学诊断。

「用 Markdown 贯彻企业原则」低估了目标冲突与权限风控

将管理学外化到 AI 协作是全期最具迁移价值的启发，但真实组织原则内部本就存在张力（如「崇尚行动」与「合规风控」的权衡），大模型面对冲突指令与提示词注入时亦可能越界。企业级落地必须配套最小权限隔离、沙盒审计与失败人工接管，不能只靠规则文档。
