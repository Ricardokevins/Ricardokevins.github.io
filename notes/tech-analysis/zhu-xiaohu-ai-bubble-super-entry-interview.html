朱啸虎：从超级入口、算力泡沫到垂直应用的生存策略

本期背景与内容导览

这是张小珺在2025年末对朱啸虎的第三次年度AI访谈。对话从OpenAI谈起：朱啸虎把浏览器、群聊等动作解释为从AGI叙事转向日活和超级入口，但他并未因此断言OpenAI已经建立护城河。是否能把群聊变成社交关系、组织能否适应消费产品运营，仍是他的保留条件。 泡沫讨论中，他以旧GPU仍在使用、Token消耗增长和数据中心／电力瓶颈反驳产能过剩，并把2000年的暗光纤作为对照。这套论证说明当期算力紧张，却没有独立证明Token均产生可持续收入，也不能直接决定公司估值。节目里同时保留了GPU飞轮、负毛利和商业化未兑现等反方线索。 创业部分的主线是“离开大厂三条马路”和“错开共识15度”：纯工具与通用API可能被模型厂、操作系统或大厂吸收，垂直优化、私有化部署、销售和线下交付则留下不同的工作。水下洗船、按摩机器人、AI陪伴玩具和垂直企业应用都是嘉宾自述的投资案例，出货量、增长和头部地位没有独立材料验证。 后半段进入投资组织：十分钟会面、创始人诚实、反宏大叙事、Club Deal导致的持股稀释，以及规模与退出标准。朱啸虎还复盘过早进入新能源车造成亏损、真正周期到来时反而不敢投的经历。这是他校准共识判断的反例，并未被写成“非主流必然正确”。 最后，他认为中国开源生态和能源基础设施将支撑长期机会，预测五到十年中国AI整体领先美国。该判断高度依赖算力仍是约束、算法追赶较易和地缘环境等前提；它是嘉宾的宏观预测，不是当前已经发生的事实。本文的独立分析进一步把入口、使用、收入和估值四层证据拆开。

00:01:48–00:08:24OpenAI从AGI叙事转向日活：群聊提供社交可能，但护城河尚未成立

  • 张小珺：从年初到2025年末，你对AI产业的判断有什么根本变化？
  • 张小珺：OpenAI会上成为新的超级入口吗？此时上市是否太早，商业模式怎么看？
  • 张小珺：ChatGPT类产品会垄断吗？中国的OpenAI是谁，Google、字节、阿里、腾讯怎样竞争？
  • 张小珺：AI入口会替代传统社交网络吗？Ilya关于研究时代的说法是否意味着Scaling Law撞墙？

片头先摘录朱啸虎“三年内看不到泡沫”、二级市场回调和Sam Altman“做应用端”的判断，正式访谈则从年度变化开始。他认为行业“越来越现实”，把OpenAI上线浏览器、群聊等功能视为从追求AGI转向应用端的证据。这里的AGI是通用人工智能的愿景，周活／日活是每周／每天使用的频率指标；日活提高不等于用户一定付费，更不等于形成社交壁垒。

他把搜索和单次AI对话归为较难防守的周活场景，把信息流、浏览器和群聊看作提高使用时长的入口动作。他尤其欣赏群聊：一方面可总结团队过去讨论，另一方面可能从人机对话转向人与人、人与AI共同参与的社交关系。机器稿中的“搜索map”无法确认是否指社交图谱，本文保留这个疑点，不替嘉宾确定术语。朱啸虎也明确说，AI入口能否反向切入社交网络“还很早期”。

对竞争格局，他判断不会一家垄断，可能集中到两三家。Google有技术积累和搜索转型，OpenAI以群聊打Google不擅长的社交侧；国内则称豆包领先，千问和蚂蚁灵光有亮点但较晚，腾讯延续后发策略。他还把阿里在即时零售和AI上的两线投入视作资源聚焦的考验。这些是对当时竞争态势的个人评价，并非用户份额数据。

主持人问OpenAI是否该上市，他回答一级市场融资仍容易、3000亿美元估值时超额认购，因而未必需要急于上市；在谈到海外C端时则认可付费意愿与粘性。两者并不矛盾：融资顺利和公司值得长期持有是不同判断。

话题随后转向技术瓶颈。主持人转述Ilya Sutskever关于预训练数据与研究时代的观点，朱啸虎同意当前Transformer上继续扩大投入成本高、边际提升有限。这是投资人的技术趋势判断，不是对架构、预训练、后训练全部路径的科学证明。他以Token消耗增长十几倍说明现有模型已足以支撑许多应用，将“前沿能力提升放缓”和“现有能力可大规模应用”同时保留。

日活与留存日活是每天使用产品的用户数，留存是一段时间后仍继续使用的比例；两者衡量使用习惯，不等于付费、毛利或社交关系。

00:08:24–00:16:43算力紧张能否反驳泡沫：旧GPU、Token、能源与商业化是四层不同证据

  • 张小珺：AI泡沫的悲观情绪从哪里来，未来会用什么指标识别？
  • 张小珺：GPU飞轮、英伟达回调、OpenAI和Anthropic是否值得投资？
  • 张小珺：AI收入来自哪里，DeepSeek和国内六小龙怎样商业化？

在 2025 年末录制这期节目时，朱啸虎判断之后至少三年难见他所说的产业泡沫，论据首先是使用端和供给端：五六年甚至七八年的GPU仍在使用，Token消耗迅速增长，数据中心和电力建设跟不上。他把2000年互联网泡沫时大量暗光纤闲置作为反例，强调现在的卡与数据中心是不够用。旧卡仍在服役可以说明存在可利用的计算需求，却不能单独证明利用效率、服务毛利或资本回报；同样，Token是输入输出的文本计量单位，消耗量增长并不自动等于终端用户创造的价值。

他补充国内调用的成本结构：输入Token多、输出少，输入更便宜；若大厂认为场景有战略价值，还会降价甚至近似免费。原话是某个使用规模每天约两毛钱成本、广告可赚回约一毛钱，不是一个Token两毛钱，也不是应用已经整体盈利。原转录中“100万”缺少单位，本文不猜它是用户、请求还是收入。嘉宾稍后也承认Token指标有水分，输入约占七八成；因此全文不能一面采用他的Token论据，一面删掉这一限定。

主持人追问GPU飞轮和互相交易，他承认与互联网泡沫有相似处，并把部分安排理解为表外化的会计技巧，但坚持核心仍是实际使用和供需。关于泡沫情绪来自二级市场投资人故意引导，只是他的猜测，没有证据链。中美AI公司估值相差百倍、必有一端错误，也是他提出的背离现象；究竟是收入不可持续还是中国收入被低估，他说尚未看清。

投资选择上，如果五亿美元求稳，他偏向Google、微软、苹果，而非OpenAI。OpenAI在3000亿美元融资中超募是一回事，能否守住C端入口是另一回事；持续训练基础模型的资本开支又使公司盈利拐点更难判断。他不喜欢Anthropic式纯API生意，理由是用户会切换到更便宜、更好的模型。这个判断说明纯接口的切换风险，但并不能覆盖有合规、延迟、企业合同或深度集成的API服务。

收入从哪里来？他的回答是替代原本要招聘的岗位，且要看毛利；他提到一些编程产品仍负毛利，相当于补贴程序员。原转录中的Office用户规模和单人成本不清，本文不据此计算市场总量。对DeepSeek，他高度评价开源对生态的影响，同时认为团队仍专注往前走，商业化甚至生态都未成为优先事项。国内模型创业公司的训练能力仍稀缺，但大厂云服务以低价和好模型压缩商业化空间，上市本身不解决这一问题。

Scaling Law这里指增加模型、数据或算力时性能如何变化的经验规律。嘉宾判断当前Transformer扩大投入的边际收益降低，不能由此推出所有训练方法已失效。
Token消耗模型处理输入和生成输出的文本计量。输入和输出价格可能不同，长上下文、重复请求和补贴都会影响Token量，因此必须和真实任务、留存、收入一起看。

00:16:43–00:28:30从通用工具转向垂直交付：水下机器人、陪伴玩具与私有化部署

  • 张小珺：这一轮与PC、移动互联网有哪些相似和不同，2026年会怎样？
  • 张小珺：今年投了哪些公司，为什么不投人形机器人，Token消耗能否衡量价值？
  • 张小珺：为什么对手电筒、优化大师等纯工具谨慎，Agent生态能否构成壁垒？
  • 张小珺：什么叫离开大厂三条马路，垂直公司为什么还有空间？

朱啸虎认为周期仍沿芯片、平台到应用展开，但速度更快；他用PC互联网六倍、移动互联网三倍作经验性比喻。2025年被概括为从AGI梦想转向现实应用，2026年应用爆发是他当时的预测。这个预测的另一面是基础设施能否跟上，以及中国开源小模型能否承接更多私有部署。

他今年自述投了十几家公司，以AI应用为主，也有做具体工作的机器人。水下洗船需要面对海水腐蚀、海浪和浑浊环境中的识别与清洗；按摩机器人除操作外还能询问体验、推销充值。两类案例说明他把价值放在具体任务与交付，而不把人形这一外形当投资前提。所谓便宜、高性价比和草根创始人有多年研究，都是他的投资口径，未披露估值、合同或经营数字。

AI陪伴玩具则是他主动选择的较红海项目：自称聊十几二十分钟即决定，半年不到在出货、活跃和Token指标上超出预期。他把壁垒归于把用户体验做到极致，并用游戏公司说明不同产品可并存。这里没有证明数据飞轮：原话后半段转录不清，不应把Token高直接写成模型效果提升或不可替代的壁垒。

在中国硬件创业与供应链部分，他以深圳及二十公里内竞争者说明中国创业者彼此竞争，又用越南被投服装企业难以延伸做电动剃须刀的例子，解释体系化零部件与制造协作的重要性。该电动产品名在转录中不清，本文不据此断言是某一型号；具体仍待回听。智能穿戴方面，他投的是向第三方提供方案的公司，判断眼镜、耳机、指环、手表都会AI化，同时承认赛道很卷。

对纯工具的警惕来自移动互联网：手电筒、万年历、邮箱、安卓优化大师曾满足真需求，但后来被OS或大厂集成。他明确纠正主持人的“伪需求”归纳：问题不在需求是假的，而在独立产品守不住。对设计师生态型产品则保留其生态可能形成壁垒。

“离开大厂三条马路”指离通用平台更远，做垂直优化、私有化部署和销售交付。他以千问30B开源模型私有部署为例，称被投垂直公司从上年数千万元到今年一亿多、明年预计两三亿元；明年数字是预测，且币种按后文语境理解为人民币，未独立核验。他总结上一周期的两条路径：滴滴、美团、Uber、Airbnb含线下苦活，抖音、快手、小红书利用了巨头战略空隙；现在大小公司都能补位，不能押注巨头持续犯错。这处举例能辨认出 Uber 和 Airbnb，第三家公司未能确认。

SOTA与30BSOTA指某评测当前领先结果；30B指约300亿参数。任务适配、推理成本和端到端准确性才决定业务选择，排名或参数量各自都不充分。
私有化部署在客户控制的环境中部署模型及应用，涉及适配、运维、权限、销售与服务，不只是把开源模型文件交给客户。

00:28:30–00:37:44十分钟决策与反宏大叙事：回报、退出、Club Deal和创始人筛选

  • 张小珺：应用公司的北极星指标是什么，小市场会不会降低投资兴奋度？
  • 张小珺：怎样决定见创业者，十分钟如何判断，今年为什么加速？
  • 张小珺：什么公司适合拿VC钱，港股IPO和一二级市场策略怎么看？
  • 张小珺：为何偏好诚实、不迎合、不讲大故事的创始人，Club Deal怎样改变回报？

朱啸虎预测大厂会更大，甚至三年内出现十万亿美元市值公司；对国内创业公司能否出现千亿美元机会则保留问号。大平台更大和新公司是否还有空间是两个问题。他回忆饿了么、滴滴、小红书早期不被看好、分出一半额度也没人愿意接，用以说明小机会可能长大；这是成功经历的回溯，不证明每个冷门项目都有同样上限。

尚未解决的问题与可检验的下一步

待解问题：OpenAI群聊能否从有用功能变成关系网络？

下一步信息或小实验：跟踪群创建后的四周／十二周留存、真实人际互动比例、跨群关系沉淀和迁移成本，比较只有AI总结与有持续群协作的用户。

怎样的结果会改变判断：若高频群协作带来长期留存和用户邀请，社交路径增强；若只有短期试用、关系仍在其他平台，则入口判断需转向工作流或其他高频场景。

待解问题：Token增长中有多少能在补贴退坡后形成正向单位经济？

下一步信息或小实验：按应用拆分输入／输出Token、免费补贴、广告或订阅收入、推理总成本、留存和毛利，做同一队列的价格变化压力测试。

怎样的结果会改变判断：价格恢复后仍有高留存和正毛利支持嘉宾的应用乐观；若消耗与收入同步坍塌，则不能把先前增长当作无泡沫证据。

待解问题：垂直私有部署究竟形成可复用产品还是高成本服务？

下一步信息或小实验：对同类客户记录部署时间、定制代码比例、交付人日、续约、毛利和模型替换成本，比较新客与老客。

怎样的结果会改变判断：交付成本随规模下降、续约稳定且可替换底层模型，支持垂直壁垒；定制与人力成本同步增长则削弱VC回报逻辑。

待解问题：错开共识的组合能否在实际回报上优于集中投资？

下一步信息或小实验：保留同一时期两类项目的进入估值、持股、稀释、后续融资、毛利、退出和失败，不以少数成功案例替代全组合。

怎样的结果会改变判断：若偏离策略提高风险调整后的基金回报则得到支持；若大量项目市场过小或无法退出，则需重新评估15度策略。

待解问题：能源与数据中心优势会怎样转化为中国模型和应用领先？

下一步信息或小实验：对比同口径算力成本、电力建设周期、模型能力、开源采用、应用收入与人才供给，分离基建与其他变量。

怎样的结果会改变判断：基建改善若持续伴随模型与应用份额提升，因果链更可信；若仅供给增加而能力、采用和商业回报停滞，应下调长期预测。

延伸分析与可证伪框架

展开早期专题留存的 5 节延伸分析与可证伪检验（已去除重复的旧版原文讲解与旧证据区）

总判断：泡沫不是一个二元标签，而是“供给、入口、回报”的错位

朱啸虎的核心判断可以压缩为：只要 GPU、数据中心、电力和 token 消耗仍然处于紧张或快速扩张状态，就不能仅凭估值很高宣布“AI 泡沫已经破裂”；但 token 增长也不等于投资回报，真正的风险在于基础设施投入能否通过产品和现金流回收。这个区分让他既能说“三年内看不到典型泡沫”，又承认估值、融资和个别公司的订单承诺可能出现剧烈回调。

本文的独立抽象“泡沫”至少有三层：使用层看需求是否真实，生产层看算力/能源/数据中心是否稀缺，资本层看未来现金流是否已经被提前定价。三层不必同时转向，因此一条 token 曲线不能代替完整的单位经济。

入口

OpenAI 的关键不只是模型能力，而是能否从 WAU 走向 DAU、时长和群聊关系，形成新的社交图谱。

应用

30B 级别模型在许多场景已够用；产品应按 DAU、留存、成本和任务结果判断，而不是追逐 SOTA 排名。

投资

避开高度拥挤的 club deal；与共识错开“15 度”，不等于反对一切共识，而是寻找价格与胜率不匹配的地方。

这期最容易被误读的是“token 消耗量持续上涨，所以估值没有泡沫”。朱啸虎自己也在后半段承认，usage 与 return 不是同一个变量。互联网历史上可以存在用量上升但商业回报不佳的产品，因此 token 更像需求强度和成本结构的观测量，不是现金流的替代变量。

深度分析：他的判断在哪些地方成立，在哪些地方不够

成立之处：把“技术真实”与“资本便宜”拆开

很多泡沫争论把技术是否有效和资产是否值得当前价格混为一谈。朱啸虎的框架更稳健：AI 可以是真的，产品可以有用户，基础设施也可以紧张，但投资仍可能因为增长被过度透支而回报不佳。这一拆分也让 #122 与后续 #124 戴雨森的“Year of R”形成有意义的对照：前者更关注需求和供给是否已过剩，后者更关注 return、research 和 memory 是否能撑起预期。

不足之处：供不应求并不自动推出高回报

GPU 或数据中心被使用，只能说明当前存在需求；它不能回答需求由谁付费、价格是否覆盖折旧、客户是否会迁移、推理成本是否随价格下降而扩大，以及供应扩张后利润会落在哪一层。要把“还在使用”变成投资结论，至少还需要客户留存、毛利、资本强度、合同兑现和替代风险。

最有启发的部分：把创业机会放在“共识的边缘”

“15 度”不是寻找完全没人相信的故事，而是寻找共识方向里的二阶问题：模型已经够用但工作流没有重做，某个行业有数据但没有产品，或大厂能力外溢后仍有低成本、强反馈的小切口。它和 #123 王冠谈的产品内生数据、#124 戴雨森谈的 context 与工具形成互证：真正的边缘机会往往不是再训练一个模型，而是拥有别人没有的任务状态和反馈。

把判断变成研究表：四个不能混在一起的指标

如果要把这期访谈转成季度跟踪表，第一列应是需求，而不是估值。需求要看真实任务数、重复使用率、用户是否把工作交给系统，以及使用是否来自少数重度用户的补贴。第二列是生产能力：GPU/数据中心的利用率、推理延迟、每个任务的 token、能源和折旧成本。第三列是产品结果：完成率、返工率、用户留存、跨模型迁移和企业愿意支付的金额。第四列才是资本价格：融资倍数、现金消耗、合同兑现和退出预期。这样可以区分“大家都在用”“公司能交付”“公司能赚钱”和“资产很贵”四个不同问题。

超级入口的三种失败方式

第一种失败是高频但无关系：用户每天打开 ChatGPT，却没有形成跨用户的关系、共同任务或可迁移的社交图谱，产品仍只是强工具。第二种失败是关系有了但不可变现：群聊和社交行为增长，却无法承载搜索、交易、服务或订阅，入口的商业价值低于想象。第三种失败是入口被平台替代：大厂把模型、手机、浏览器、支付和社交同时掌握，独立产品的上下文和分发无法留住用户。只有当入口同时形成频率、关系、结果和切换成本，社交图谱才可能从叙事变成护城河。

“15 度偏差”也有边界

偏离共识必须建立在更好的信息或更清晰的机制上，而不是把反向观点本身当作洞察。一个可复用的检查方式是：先写出共识为什么成立，再指出哪一个前提可能被高估，最后给出能够在三到六个月内观察的信号。若不能说明信号，所谓非共识可能只是延迟验证的故事；若信号出现却没有行动窗口，差异化也无法转成收益。把偏差写成假设、价格和验证日期，才能避免投资人事后重写自己的判断。

给创业者的现实翻译

对创业者而言，本期最实用的建议不是“不要做大模型”，而是选择一个能在小规模上产生密集反馈的切口：用户愿意反复使用，结果容易判断，成本能被控制，且大厂的通用能力还没有覆盖全部流程。然后保留可逆性：模型可以替换，数据和评价不能丢；入口可以变化，用户任务和结果记录要留下；融资可以快，也要知道没有下一轮时还能活多久。这样，15 度偏差才不是口号，而是一种带有止损线的产品策略。

因此，朱啸虎的观点更适合被当作一个“观察顺序”而不是一句结论：先观察真实需求，再观察生产约束，再观察产品结果，最后才讨论资本价格。这个顺序不能消除不确定性，却能减少把热度、供给紧张或融资金额误认为回报的错误。

后续如何证伪或修正

  • 若 token 消耗持续增长，但推理价格下降、客户付费和基础设施回报长期不改善，说明 usage 不是 return 的可靠先行指标。
  • 若 OpenAI 或其他超级入口形成稳定社交图谱、跨用户关系和高频留存，超级入口假说得到加强；若群聊只产生短期尝试而没有关系沉淀，入口叙事应收缩。
  • 若小模型在成本、延迟和真实任务完成率上长期优于大模型，应用选择小模型的判断成立；若模型能力快速商品化且上下文无法形成壁垒，应用公司仍会承压。
  • 若 club deal 项目的退出收益显著高于非共识项目，且高价格确实换来更高胜率，“15 度偏差”就不应被当作通用投资原则。
