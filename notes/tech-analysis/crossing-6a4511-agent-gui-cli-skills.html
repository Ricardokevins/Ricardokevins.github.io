完整对谈重建：Agent 元年第 500 天，六大关键词串起消失与诞生

本期是真格基金《此话当真》与《十字路口》的串台对谈。主播 Koji 邀请真格基金投资总监钟天杰（Jack）与 AI 开发者、内容创作者归藏，站在“Agent 元年”走过约 500 天的时间刻度上复盘整个行业的剧变。从第 100 天 Manus 借 Claude 3.5 Sonnet 爆火，到第 300 天 Claude Code 刷屏，再到第 400 天 OpenClaw 破圈，直至第 500 天新概念持续井喷，三人借 Headless、CLI、Skill、Agentic Economy、OpenClaw、Token Grant 六个热词，串起软件形态、大厂开放博弈、个人工作流与未来 500 天的押注。

嘉宾身份与一线实践背景（据节目介绍与访谈口述）本场核心立场
钟天杰（Jack）真格基金投资总监；刷屏文章《我们或许不应该再投资 GUI 思维的软件》作者，真格 Token Grant 推动者之一模型超预期、产品化远不及预期；一切回到上下文管理；普通用户终局认的是品牌 Agent 而非底层 Skill
归藏AI 开发者与内容创作者；开源本地 Agent 项目 CodePilot（GitHub 6,000 star）及热门 PPT skill 作者效率与能力拓展远超预期；CLI 把复杂性交还 AI，但结果预览仍需好 GUI；Skill 生态藏着巨大商业价值

一、五百天复盘：截然相反的预期体感，与一句话总结

开场话题直接从钟天杰三个月前引发热议的文章切入，Koji 追问两人：Agent 元年走到第 500 天，现实进展究竟超过还是低于预期？两人给出了恰好相反的第一反应。

钟天杰认为“模型能力超预期，但产品化远低于预期”：环顾市面上各类产品尤其是信息消费应用，依然停留在“人是唯一操作者、必须源源不断把注意力灌进去”的旧交互里，至今没有一款让他真正满意的产品出现。

归藏则觉得“整体远超预期”：两项亲身变化彻底打破了他的想象边界。其一，原本只懂基础前端的他，从 Manus 爆发一路走到今天，竟然独立维护起一个几十万行代码的代码库并对外提供服务；其二，他的工作流自动化程度远超想象，甚至放弃了过去“坚决不用 AI 写内容”的媒体人执念。如今除线下与人当面交流外，他几乎所有自媒体与内容生产都已高度自动化。面对普遍对公众号“AI 味儿”的吐槽，他划出清晰分界：公众号、新闻和观点表达的本质是高效率、低摩擦地传递信息，AI 有时写得比他本人还好；而小说等高审美文学创作 AI 仍够不到（他顺带提及最近读到最没“AI 味儿”的作品是《置身事内》）。

用一句话浓缩这 500 天里不变的内核时，两人视角各具锋芒：钟天杰锁定“上下文管理（Context）”——无论模型自身上下文还是 Agent 系统的上下文编排，所有新发明绕了一圈终究回到上下文；归藏则总结为“唯一不变的是万物皆变，以及新概念不断被祛魅”——他援引科技圈老笑话：凡是还没被驾驭、用不稳的都叫 AI，一旦稳定高效落入日常工作流，大家便轻描淡写地说“那不过是软件而已”。但不变的是，模型底座仍在持续突破，不断解锁意想不到的技术奇观。

二、关键词一 Headless：GUI 是人类认知缺陷的补丁，但并未死去

第一个关键词是 Headless（无头软件）——剥离图形界面、只留数据库与执行工具的软件形态。距离《我们或许不应该再投资 GUI 思维的软件》刷屏已过去三个月，钟天杰首先澄清最易被误读的“思维”二字：传统效率软件默认“人来操作按钮”，当 Agent 执行力超越人类后，图形界面（GUI）反成工作流负担；但面向人的入口 GUI 从未退潮，早期 AutoGPT 等命令行框架门槛过高，出圈的 Manus 与 OpenClaw 恰靠友好 GUI 封装才赢得大众。因此核心界定是：只要人用，GUI 就很重要；一旦任务交由 AI 端到端完成，GUI 就不再重要。

展开“GUI 是人类认知缺陷的补丁”这句金句时，钟天杰解释：人类短时记忆最多并行记住约 7 个单词，到第 8、9 个认知负荷陡增。Notion、Figma、Slack 都围绕人类聚焦习惯打磨；一旦流程不再需要人全程盯着，自然不必继续为人类的认知缺陷打补丁。

归藏的一线 Headless 实践：他日常重度使用 FFmpeg 等 CLI——录制前一天刚给自己的 Skill 加上 3:4 Live Photo 排版轮播，AI 自动调 FFmpeg 裁切缩放素材。他直言许多传统 GUI 实属“反人类”，用户只关心结果（下周会议、近五篇文章隐含关系），不想在层层按钮与文件夹中翻找。如今连肯德基、瑞幸等线下消费品牌都推出了 CLI，AI 可绕开小程序代点单，背后商业算盘是借 AI 建立自有渠道、摆脱旧平台抽成与控制。

反面教材（Notion）与正面样板（Gmail + Codex）：归藏点评 Notion——CEO 是顶级设计师，为硬塞 AI 竟连改 5 次侧边栏，属典型 UI 思维。若由他操盘，会将老用户与 AI 用户分流：复杂 To B 软件的老入口保持稳定，新路径另做 Headless。自称近 10 年重度用户（印象笔记 → Quip → Notion）的 Koji 感叹 block 组织已达 GUI 巅峰；钟天杰直言往极致旧 GUI 里强塞 Agent 只会破坏老用户价值网络、让两拨人都难受，真正颠覆它的应是全新产品。

正面例子则是钟天杰亲身跑通的 Gmail + Codex：他订阅数百个海外信源导致收件箱崩溃，两年前每周花 3 小时清理、设关键词和 skip the inbox 规则，一次手滑配错过滤器把所有邮件归进随机标签，“维护形式压过消费信息本身”。如今通过 Codex 授权 Gmail，每日早晨定时通读过去 24 小时邮件并按需摘要——某种意义上 Gmail 的 GUI “死了”，把核心能力献祭给 Codex。旧软件若转型失败会退化成底层数据库，若整合到位也能成默认执行底座。但归藏立刻拿 Codex 为好 GUI 正名：它圈粉靠的恰是三个界面细节——对话流内嵌视频播放器当场预览 FFmpeg 成品、图文混排信息流、把本地文件夹路径做成一键直达链接。

谈及写作诱因，钟天杰说年初看到 Sentry、Supabase、MongoDB 乃至飞书、Gmail、Google Suite 密集推出 MCP 和 CLI，确认拐点已至。面对“刷抖音已在手机极致优化、文章太极端”的质疑，他强调产品经理核心是定义问题，别去重解上个时代已解完的题。两人同时吐槽不少创业者把“轻 GUI”错当成放弃打磨门面：近期收到的许多 BP 全是 Claude Code 粗造，生图中文字还停在半年前劣质 AI 水平。归藏立下底线——“用 AI 做的门面内容，别让人一眼看出是 AI 做的”；BP 与官网是人与人建立信任的 GUI，Koji 借星巴克创始人《将心注入》作喻，呼吁把用心放回细节。

三、关键词二 CLI：AI 抹平记忆障碍，与大厂开放的商业博弈

归藏用大白话科普 CLI（命令行接口）：GUI 是点按钮看画面，CLI 是按固定格式输入的纯文本伪代码指令。过去普通人没法用 CLI，死穴在于记不住命令——连 FFmpeg 作者都背不下上千页文档的成百上千条参数；纯文本大模型天生懂语法，用户只需说“把码率降一下”，AI 瞬间译成准确命令，最大门槛归零。

技术障碍消失后，商业博弈浮出水面。归藏点名微信、小红书、美团、滴滴、携程、飞猪等垄断性应用至今未开 CLI，怕丢入口、沦为无头管道且数据外流。钟天杰换位坦言自己当决策者也难痛快开放，佩服 Google 与飞书的魄力，但也笑言这类工具本非大厂核心利润中心；他预测美团、滴滴、携程不会全面开放公有 CLI，而会与微信 AI、iPhone、OPPO、vivo 签有限的 AI-to-AI 双向渠道协议（提及前两天“美团、滴滴、携程纷纷投诚”接入微信 AI 的新闻）。归藏认为线下履约公司的价值本就不全在线上那个“头”上。

钟天杰将开放与否抽离为商业判准：每家公司都在向社会交换价值（整理公开信息、采集水下结构化信息赚溢价、或提供商品服务），CLI 是与 Agent 交换需求的接口——只要借 AI 能更快把价值送到用户手里（如瑞幸加速咖啡因触达），就该开放。归藏补充还有抢跑曝光红利，宛如“金谷园饺子馆宣布接受比特币支付”，未必真有人付却赚足传播。

被问“只能许愿一款软件开放 CLI”，归藏脱口选微信——所有活都自动化了，唯独和客户聊天还在微信里敲字太痛苦，却自觉难说服张小龙。钟天杰不指望老平台自我革命，更期待 AI-first 新服务（最近去新加坡、马来西亚和台湾清境农场全是 Manus 帮查，绕开了小红书）。Koji 设想若豆包能互加好友并让 Agent 读群聊，或许倒逼微信防御性改变；话题顺势转到抖音聊天（DAU 已达 1 亿，叠加“小火人”助推），归藏点破“内容在哪里，聊天就在哪里”。Koji 援引扎克伯格内部分享承认低估 TikTok 靠分享内容抢走 WhatsApp 聊天，归藏补刀微信屏蔽外链反把熟人关系推向抖音群聊，若未来豆包、微信、飞书打通将极具颠覆力。

四、关键词三 Skill：把个人品味封装成资产，但“奶奶只认品牌 Agent”

高频 Skill 与变现现实：归藏首推倾注心血最多的 PPT skill，坦言自己几乎不用别人的 Skill（唯一外装是飞书 CLI 系列 skill），反倒装了不少 MCP（如开发测试必备的浏览器控制 CDP MCP）。他虽靠真格 Token Grant 拿到赞助，却直言直接向 C 端收费极难——用户已付模型 Token 费，必须先试用并横向比出明显质量差才可能付费。钟天杰常用归藏 PPT skill、播客标题/金句/摘要 skill、按会议类型（朋友交流、天使投资、播客前采）自动分模板归档 Notion 的会议 skill，以及高频决策工具 Grill Me（“榨干你”）——连环发问把脑中模糊念头逼出来助决策。

自我沉淀与存续周期：归藏透露 PPT skill 首版是在分享前一天、只用一句话让 AI 读个人 memory 和旧项目样式代码提取出来的，本质是把个人品味提炼为可复用资产。他提到 Hermes 与 OpenAI Codex 作者公开的提示词（扫全部聊天自动提炼 5—6 个重复流程草稿），但强调 AI 只是猜测，必须经人校正。论及 Skill 会长存还是过渡：归藏认为按 AI 尺度（半年到一年即算长期）会长存——模型虽会吃掉浅层提示技巧（如 GPT Image 2.0 一句话出好图，不再像用 Nano Banana 那样精雕 prompt），但 Skill 已成共识，消化更慢。钟天杰则坚持终局属于“品牌级 Agent”：普通人难分辨两款 Skill 的边界差别（nuance），检验标准是“你奶奶会不会学什么叫 Skill”——奶奶不说“用 PageRank”，只说“Google 一下”，只信能稳稳买回咖啡的品牌 Agent。归藏的 Skill 也已上架 Kimi、WorkBuddy 等产品。

谁是中国的 Claude Code，与小红书 Skill 生态：归藏直言中国 Agent 进度偏慢：国产模型在长程任务和 Agent loop 上不及海外顶尖两家，且软件本无壁垒却追赶吃力；统治级 Agent 大概率出自头部模型厂，重度用户宁付溢价（premium）买稳定，钟天杰补刀“差模型不只伤效率，还伤代码库”。对小红书上线 Skill 商店，归藏力挺其补齐了 GitHub 缺乏作品预览、评价与评论区艾特反馈的短板，批不少 Agent 只机械爬取 ClawHub、GitHub 却不优化不共建，并认为哪怕不出统治级 Agent，也可能诞生跨 Agent 超高装机量的统治级 Skill。生态尚存三处混沌：缺权威榜单（只能看 GitHub 星标如 Open Design 6.6 万星或 skills.sh）、分发后难自动更新（Koji 提议在 skill.md 首行写“检测更新”，归藏打趣不用的新旧版都是“薛定谔的猫”）、以及何时做 CLI、何时做 Skill、何时做 MCP尚无共识。他也点赞 Garry Tan 把 YC Office Hours 文字稿与 Lenny 播客打包成对话式 Skill，实现信息平权。

五、关键词四与五：Agentic Economy 的大基建周期，与 OpenClaw 百日遗产

第四个关键词 Agentic Economy（智能体经济）指向面向 Agent 的基础设施，包括沙箱、记忆系统、专属数据库、Agent 支付网络乃至给 Agent 配 WhatsApp、手机号与邮箱。钟天杰给出的创业建议非常务实：起步优先基于 Pydantic AI、AI SDK 等现成开源框架，别自己从头造轮子；至于给 Agent 配手机号和支付网络等前沿试验，他刷到过但尚未实测。他用 1999 年互联网泡沫敲响 timing 警钟：当年无数 dot-com 公司在超级碗天价砸广告却留不住用户，导致吃过亏的人到了移动互联网时代反而不敢烧钱获客、错失周期。如今距 Agent 起步刚满 500 天，主旋律依然是让 Token 更智能、更便宜的上游大基建时代，下游繁荣或许还要等上 5 年甚至更久。

但有一件事钟天杰确信必将成真：脱离人类社交圈的新型供需信息匹配网络——比如找隐秘小岛、找合适 Skill、做作品级精准人才筛选。社会上从来不缺对口的人或资源，缺的是把足够丰富的供需表达公开接入机器网络的公共品；一旦 Token 足够廉价高效，这个网络就会水到渠成。他同时抛出一个极易被忽视的金融视角：Token 价格不是单向跌到底，而是随能源、电力、模型代差、内存供需和资本市场浮动的商品。比如内存大涨价直接推高长上下文模型的 Token 成本，今天 200 美元买到的 Claude Max 额度，三个月后可能完全不同；他还观察到有基础设施玩家（转写记作 SpaceX）甚至不必亲自训模型，专卖算力和底座照样撑起极高估值。

第五个关键词 OpenClaw 上线不过百余天，Koji 却调侃如今再提“养虾”已有点像当年喊“奥利给”般显得过气。热度退潮后它究竟留下了什么？两位嘉宾给出互补的定调：

  • 钟天杰（暴力塑造全行业共识）：2026 年 1 月起，一线已察觉 Agent 定义从 Manus 剧变到 Claude Code，但投资圈、创业圈与普通大众尚未完成认知切换。OpenClaw 以近乎暴力的方式强行拉齐了全社会共识，也顺手把 Skill 概念普及开来。
  • 归藏（验证 IM 形态，也暴露运维硬伤）：它反向坐实了 CLI 对大众依然过难，同时证明了即时通讯（IM）界面（WhatsApp、Slack 乃至未来微信）的天然亲和力——用户不用面对一长串冰冷的 thread list，第一次像跟“一个人”聊天般持续维护上下文。但安装坎坷、莫名宕机后让人彻底失去重启热情，也决定了尝鲜无法自动变成留存。

六、关键词六 Token Grant，以及下一个 500 天的“十倍产能抖音”

最后一个关键词落回扶持早期创造者的 Token Grant——真格基金与十字路口联合发起，向从 0 到 1 的 AI 开发者无偿提供 5 万元人民币 Token 算力赞助、不占任何股份。Koji 解释背后的逻辑变迁：今天独立开发者靠 AI 写代码未必缺招人钱，最刚性的生产资料是 Token，因此在天使投资之外新增 Token Grant 切入最早阶段。

节目现场拆解了两个极具代表性的受资助项目：

  • CodePilot（归藏开源，GitHub 6,000 star）：定位足够开放、高度本地化的 Agent 客户端，愿景是把用户的整套个人 harness（Skill、Memory、CLI）牢牢留在本地资产里，既可以套在 Claude Code 或 Codex 外壳上复用自己的体系，也可以自由接入任何划算的第三方 API，不被单一厂商锁定。
  • UU Agent（钟天杰支持，创作者袁浩）：一场前卫的“赛博数字生命实验”。团队发现它时刚存在 30 多天，录节目时已运行 100 多天；创作者最初只给了它一个目标——“作为一个孩子，你要超越 Claude Code”，它便从 0 行代码一路自行演化到了 10 万行代码，下一步创作者打算赋予它新目标“为人类创造价值”。

压轴展望下一个 500 天，钟天杰把关键词落到“拥抱变化与推倒重来的勇气”：去年大家还以为深度思考（thinking）是贯穿始终的主旋律，转眼就被 Agent loop 覆盖；在这个行业犹豫一两个月，窗口便已关上。

归藏则献上一记反直觉的终局猜想：所有人都在苦苦寻找 AIGC 之后形态迥异的下一代超级 App，但过去一二十年移动端已经把人类最顺手的前端交互打磨到极致（例如抖音上下滑几乎再难改写）。因此下一个抖音未必是某种全新界面形态，而可能是背后生产效率暴涨 100 倍、1,000 倍催生的“10 倍产能的抖音”。他打了个生动的农业工业化比方：过去每家每户散养猪鸡拿到集市交换，电力与资本介入后出现集约化养殖场，以更低成本稳定产出更高品质的产品，由此诞生大型龙头企业。未来的视频形态或许依然是视频，但供给规模与工业化生产方式将面目全非。两位嘉宾最后坦然笑道，500 天后回看今天的预言多半会错，Koji 则笑着立下约定：第 1000 天再录一场。

机制：一条用户需求怎样穿过 CLI、API、MCP 与 Skill

归藏在节目中提到，业界眼下对“何时做 CLI、何时做 Skill、何时做 MCP”仍处混沌期。以下用本文自拟的“会后整理与决策跟进”流程，把四层工具的真实分工与错误处理链条拆开：假设用户对 Agent 说“整理今天的三场会，标出需要我亲自拍板的事项”。Agent 先判断读取哪些会议纪要，再通过已授权接口拉取原文，按既定规则提取议题、结论与待决项，最后把附带原文出处的摘要呈给用户；若涉及发送邮件或改日程等写操作，则必须单独申请权限与确认。

层级技术本质在这条工作流中的分工适用边界与典型短板
API程序间结构化数据与能力契约底层的身份鉴权、拉取邮件/纪要原文、写回 Notion 数据库稳定可靠、权限粒度清晰，但开发与维护成本高，模型不直接看原始文档时需二次封装
CLI纯文本格式化的命令行执行接口把本地音视频转码（如 FFmpeg）、读取本地仓库或调用飞书/Gmail 命令变成单行纯文本调用对大语言模型极其友好、零额外协议栈、便于组合管道；但强依赖本机环境、安装与报错排查对普通人门槛高
MCP应用向模型暴露工具与上下文的标准协议向 Agent 统一声明“浏览器控制（CDP）”“日历查询”等工具的输入参数与返回结构适合跨客户端复用的标准化能力接入；但由工程师编写，普通用户较难自行定制和微调
Skill可复用的任务说明、模板、品味规则与脚本集合教 Agent 先区分会议类型（投资评估 / 播客前采 / 朋友闲聊），再按对应模板抽取待决项并保留原话归属沉淀的是人类领域判断与审美，非工程师也能编写传播；但版本分发、自动更新与跨模型稳定性尚不成熟

四层工具并非互斥替代，而是纵向叠加：Skill 决定“按什么标准做”，Agent 据此编排步骤，再借 CLI、MCP 或底层 API 触发真实动作。把点击按钮换成自然语言并不会自动消灭工程异常——转录可能漏字、人名可能张冠李戴、接口授权可能过期。可靠的自动化输出必须把证据链接指回原始记录，并在所有写操作前明确变更对象、预期影响与失败回滚方式。

独立判断：减少操作不等于取消可检查性

一、界面与机器接口解决的是两类瓶颈，好产品重在划清“托管与审阅”边界

钟天杰的“Headless 叙事”和归藏拿 Codex 视频预览反证“GUI 依然重要”，表面存在张力，实则共同指向同一条产品分水岭：重复性采集、批处理、格式转换与机械流转适合彻底无头化交给 CLI / API；而成果对比、风险复核、审美打磨与拍板决策仍高度依赖高密度的可视化界面。如果一款 Agent 只把操作过程藏进黑盒，却不提供清晰的信息来源、失败日志与待决项高亮，看似省下了点按钮的体力，实则把成本转嫁成了更耗神的核对焦虑。正如两人痛批的“粗糙 AI BP”，省掉制作工序后，审美与信用背书反而变得更值钱。

二、Skill 的护城河不在提示词长度，而在经过真实报错打磨的可验证判断

随着基座模型不断进化，仅仅封装“帮我总结重点”或简单画图修饰词的浅层 Skill，确实会像归藏所说被下一代模型直接吞并。真正具备长期复用价值的 Skill，凝结的是具体场景里反直觉的业务边界——比如区分哪三类会议、在什么证据缺失时强制反问、输出必须满足哪些格式与事实核对红线。检验一条 Skill 究竟是资产还是安慰剂，不应只看 GitHub 星标或转发热度，而应拿同一批真实材料对照“有无该 Skill”的遗漏率、事实错归率以及用户手工返工字数。

三、开放 CLI 不是非黑即白的勇气题，而是交易结构与价值捕获题

平台愿不愿意向外部 Agent 开放 CLI，本质上取决于单位交易的净收益算账。当外部 Agent 能显著扩充增量订单、而平台核心壁垒落在供应链、履约网络或云端存储时（如咖啡茶饮、开发工具或非核心利润入口），开放接口利大于弊；相反，当平台商业模式高度依赖停留时长、信息流广告或封闭社交关系链时，全面无头化意味着直接抽空变现底座。因此，未来更可能出现的不是“全部大厂拥抱公有 CLI”，而是“只读能力有限开放 + 写操作受控鉴权 + 头部渠道间定向 AI 协议”的混合博弈格局。

四、“十万行自演化代码”不能直接等同于自主智能跃迁

节目中提到的 UU Agent 从 0 行代码自行演化到 10 万行代码，作为早期算力资助下的探索实验极具话题性与启发性；但从软件工程和能力评测角度看，代码行数（LOC）只衡量代码生成体积，并不自动证明架构健康度、真实任务通过率或超越 Claude Code 的实质能力。正如前文工程经验所示，缺乏外部硬验证环境的自动扩写很容易堆积冗余甚至陷入自我循环——观察这类数字生命实验真正有价值的指标，是它在后续真实外部需求与独立测试集下的存活率与演化质量。
