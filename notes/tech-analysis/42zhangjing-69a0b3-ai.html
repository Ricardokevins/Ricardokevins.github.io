对谈 Wanaka 创始人张阳：AI 游戏如何成为熟人社交的共同内容

本期背景与内容导览

本期是曲凯与 Wanaka 创始人张阳围绕“AI＋游戏＋社交”的产品复盘。张阳此前经历小米、字节及多个创业团队，做过社交、内容、工具、增长和商业化；本期讨论的是他把这些经验用于新创业后的假设、迭代和早期内测。节目方称 Wanaka 已开启内测，但没有披露留存、收入或规模化增长结果。 对话的核心不是“AI 能更快做游戏”，而是两个更难的问题：普通人怎样把场景与玩法表达成可玩的作品，普通作品又为什么值得被别人消费。Wanaka 的答案是图形化场景搭建与自然语言逻辑生成结合，让用户定义角色、资产与熟悉场景；消费上优先服务熟人共同游玩，而非直接复制抖音式推荐流。小范围内测中，手办变成可动 3D 角色并进入游戏带来惊喜，是本期最具体的早期反馈，但样本和后续行为均未披露。 Roblox 是双方反复使用的参照：它的价值不只是编辑器，也包括既有朋友关系、共同玩法和持续内容供给。张阳据过去的用户访谈，认为部分北美年轻人减少公开社交表达，转向 Story、DM 及 Roblox、Minecraft 中的熟人活动。这一观察支持 Wanaka 的产品假设，但不能当作北美整体用户普查或 Roblox 增长的单因果证明。 后半期还讨论了 LiveIn、Answer.ai 及字节经历对增长和产品方法的塑造，区分工具产品与泛娱乐产品的传播方式。当前测试重点被表述为用户是否愿邀请朋友，以及创作侧能否出现做出独特内容的人。最后关于 AI 对话社交、个人助理、C 端爆发与隐私权限的内容，都是开放判断，与 Wanaka 已交付功能及经营结果分开。

团队曾考虑上下滑，但很快因创作天花板而否决。他们区分了“内容短”与“工具只能做出短内容”：早期抖音的短主要是分发选择，拍摄工具本身能做长视频；依赖少数轮 Prompt 直出的互动内容则受工具可控性、复杂度和同质化限制。这里的核心不是模型完全没有能力，而是普通人能否把需求表达清楚、模型是否有合适的操作环境。曲凯以自己使用即梦时只能写两句 Prompt、专业用户能写分镜，以及三维场景里城堡从 A 点移到 B 点很难只靠自然语言精确定位为例。张阳据此提出两个边界：人需要可操作的界面，模型也需要工具与环境；Manus、Cursor 及“助理模型”的讨论属于对产品架构的设想，未披露 Wanaka 的具体模型训练或 API 实现。

曲凯先问，UGC 与 AI Coding 内容消费性不强是技术阶段问题，还是游戏形态的问题。张阳的回答是“人的问题”：即便模型能力继续增强，普通人与专业导演、懂镜头语言的人做出的内容仍可能差距很大。他的重点不是否认模型进步，而是创作所需的审美、表达与需求定义不会自动随工具分发而平等。与此同时，他并不把上下滑本身判死：如果工具能支持创作者做出好内容，小众内容仍可能像抖音早期运镜、跳舞那样破圈；当前主要瓶颈是直接套用模型直出的生产能力。

双方随后区分“游戏”和“互动内容”。张阳认为当时多数产品的核心玩法或 game loop 太弱，更适合称互动内容。这里的 game loop 指玩家反复执行“行动—反馈—再行动”的玩法循环，例如移动、躲避、获得奖励并继续挑战；不是有按钮或能点击就等于有完整游戏循环。Wanaka 希望先做更重度一点的内容，再让足够好的工具向下覆盖短平快互动内容，这是能力目标。

曲凯提出两种消费困境：好游戏可能一玩数小时，用户不像刷短视频那样不断切换；太轻的互动内容又可能像早期 Flash 小玩法，难以支撑每天持续使用。张阳的回应形成两条路线判断：轻互动内容更可能从视频和多模态生成上长出来，与世界模型等探索更接近，和 Coding 距离较远；偏游戏的内容可能单局更耐玩、可重复消费，并通过朋友联机成为日常娱乐。后一条只是一种可能的使用场景，不是 Wanaka 已实现留存的证据。
