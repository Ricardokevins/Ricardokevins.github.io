本期播客是《全球大模型季报》第九集。主持人张小珺开篇即点明本集情绪复杂：一方面，AI革命正急速进化，另一方面，社会层面随之进入“白领通缩与失业”的窗口期。

她转述嘉宾广密的核心判断：Coding（编程）正将AI从以聊天机器人（Chatbot）为代表的第一幕，推向能实际执行任务的智能体（Agent）第二幕。领先的Coding模型如同领先的GPU，是新的“AI加速器”，甚至让顶尖研究员不再亲自写代码。广密在节目引言中强调，如果一家领先的模型公司不重视Coding，很可能会掉出第一梯队。他观察到，硅谷“御三家”（OpenAI, Anthropic, Gemini）的领先地位在过去三年中不断交替，今天的成功秘诀可能成为明天的“毒药”，例如OpenAI因在ChatGPT上过于成功，反而专注ToC（面向消费者）市场而忽视了Coding。

在正式对话中，张小珺首先回顾了往期季报中对Coding的反复强调，并询问广密在2026年Q1的最新感受。广密回应，过去一个季度的变化极快，他将主要分享三方面内容：1. 硅谷一线体感与观察；2. 对Coding作为当前主线任务的最新理解；3. 对硅谷“御三家”在战略、组织和文化层面的观察。他还预告了后续将讨论模型作为新一代操作系统的终极形态，以及AI对社会（如白领通缩）和投资的潜在影响。

Coding在本对话中，Coding（编程）不仅指写代码这一行为，更是一种核心的AI能力和战略方向。它使AI能将自然语言描述的任务，转化为可执行的、精确的解决方案（代码），从而完成复杂的、高价值的数字世界任务。它是推动AI从“聊天机器人”（Chatbot）进化到“智能体”（Agent）的关键，被视为加速AGI实现的“加速器”。
Agent / Agentic指具备自主执行任务能力的AI系统。输入是用户的指令或目标（通常是自然语言），输出是AI完成该任务的一系列实际操作和最终结果。与仅能对话的Chatbot不同，Agent能够理解复杂指令、规划步骤、并与数字环境（如操作系统、软件、网络）交互来“干活”，例如自动编写和调试代码、处理数据、完成线上预订等。
硅谷御三家在本对话中，特指在大型语言模型领域处于领先地位的三家公司：OpenAI、Anthropic和Google（其模型为Gemini）。这个称谓借用了日本文化中的概念，形象地比喻这三家公司在AI领域的顶尖和竞争关系。
白领通缩指由于AI自动化了大量白领知识工作者的任务，导致这些岗位的市场需求下降，从而引发相关从业人员薪资水平下降或停滞的经济现象。这是一种结构性的通缩，主要影响依赖信息处理、分析和创造性工作的脑力劳动者。

主持人张小珺提到，2026年Q1的发展速度超乎预期，许多人感到“跟不上”。她询问广密，过去一季度最关键的转折点是什么。

广密明确指出，最本质的转折点是Anthropic的Opus模型从4.5到4.6的迭代。他认为这次跨越堪比GPT-3到GPT-4的“跨时代提升”，标志着AI从简单的聊天问答（Chat）模式，真正进入了能执行高价值复杂任务的智能体（Agent）模式。他体感上认为，过去一个季度模型智能水平的进步幅度，甚至超过了2025年全年。他还预告，Anthropic的Mythos和OpenAI的Spud等新模型即将发布，可能在今年6、7月前再次实现GPT-3到GPT-4级别的跨越，届时将真正迈入GPT-5时代。广密判断，“AI的奇点时刻应该已经到了”。

为了让听众更有体感，张小珺追问硅谷一线的真实案例。广密分享了几个观察：

1. 工作方式改变：前沿实验室的AI研究员和顶尖程序员已基本不写代码。一年前系统里人写的代码可能占70-80%，现在已低于1%。工作模式变为“AI写，人来审”，甚至人的审查能力都已跟不上。像Claude Code和Codex在很多任务上已达到公司CTO或首席架构师（对标Meta的E8/E9级别）的水平。

2. 研发效率加速：一个想法从构思到代码跑通，过去需要2-3周，现在只需1-2天。这使得Coding和Agentic能力成为加速AGI实现的关键要素，重要性仅次于GPU。

3. AI加速AI：许多近期的AI研究突破是由Codex或Claude Code带来的，而非人类工程师。例如，模型能快速解决困难的数学题或Debug，并显著加速了多模态等其他领域的研究，数据处理迭代周期从一两个月缩短到几天。

4. 生产力放大：Coding能力极大地放大了最顶尖1%甚至千分之一人才的生产力，可达几十倍。Anthropic在50多个工作日内发布了70多款产品和功能，这种速度在互联网时代是不可想象的。

最后，张小珺询问这些变化是否带来了显著的营收增长。广密确认，Anthropic已宣布其ARR（年化经常性收入）超过OpenAI，更关键的是，其少数（约一两百万）高价值用户贡献的收入，超过了OpenAI数千万订阅用户。这表明，衡量指标正从DAU（日活跃用户）转向高价值用户的“token usage”（token使用量）。他预测，若势头持续，年底OpenAI和Anthropic的ARR可能达到800-1000亿美元，明年或将冲击2000多亿美元，成为新时代的“Mag 7”级别公司。Coding业务的收入增长速度，已超过了Google Cloud过去近二十年的积累。

主持人张小珺回顾去年已在讨论Coding，并询问广密如今对Coding的理解有何新变化。广密提出了四个核心观点：

1. “语言即世界，代码即方案”：他提出一个核心假设，即Code（代码）可以表达数字世界绝大多数任务的解决方案（solution），而自然语言则是对世界的描述。如果此假设成立，做好了Coding Agent，就意味着大部分白领知识工作者的电脑操作任务都可被自动化。

2. Coding是战略必需品：领先的模型公司若不重视Coding，必将掉队。他强调，不存在只供内部使用的Coding模型，因为自家任务的数据分布不足以训练出最强模型。同时，过度依赖别家（如Anthropic）的Coding模型存在被“断供”的风险，广密举了 OpenAI 与 xAI 的例子，说到 Google 时用的是推测口吻。因此，Coding不仅是一个应用场景，更是AI路线图中的“加速器”，其战略地位堪比GPU。

3. Coding是“敲门砖”：他将Coding比作亚马逊早期卖书，通过这个切入点，打通了整个流程（数据、工具链、用户），之后再横向扩展到其他任务会更容易。Coding之所以最先跑通，是因为其反馈闭环（feedback loop）最清晰、最短。

4. AGI进程的第二幕：广密将AI发展划分为三幕：第一幕是ChatGPT代表的Chatbot；第二幕是当前所处的Coding Agent时代，模型能干活并加速AGI进程，他用“90%”形容对编程能力的看重，没有给出衡量 AGI 完成度的尺度；第三幕则是“自动化的AI研究员”，届时AI将能解决基础科学问题。他将AGI的实现比作攀登科学高山，而我们目前尚在山脚。

张小珺追问，既然Coding如此重要，为何并非所有公司都全力投入？广密透露，多数AI Lab在近1-3个月才将Coding提升至最高优先级，但做好并不容易。他认为关键难点在于“组织和文化”以及“数据”，这已超越纯粹的技术know-how，成为战略和组织问题。他指出，很难组织几百个顶尖人才去all-in做数据清洗等“脏活累活”，因为他们更倾向于做0到1的突破性研究。而Anthropic的创始人从一开始就意识到数据是根本，其首席科学家Jared Kaplan甚至亲自带队搞数据。此外，Anthropic战略专注，果断放弃了多模态、Reasoning Model和ToC等方向。

关于其他公司为何没能早期专注Coding，广密分析，这源于战略选择和思维包袱。当时存在两条路线：一是追求C端流量（如ChatGPT、Gemini），二是追求高价值任务（Anthropic被迫选择）。2025年是C端窗口期，OpenAI和Google忙于抢占该窗口，从而错过了Coding的窗口。他认为，未来两条路大概率会融合，但高价值用户的Token使用量可能比C端DAU更有意义，因为顶尖人才的生产力会更加集中。

主持人张小珺邀请广密逐一分析硅谷“御三家”的战略、组织与文化，首先聚焦于Anthropic。她询问Anthropic是如何下定决心All-in Coding的。

广密解释，Anthropic并非第一天就想清楚，而是在探索中发现的。一方面是由于错过了C端窗口，另一方面是2024年夏天发布的Sonnet 3.5在Coding上获得了积极反馈，从而明确了路线。他总结了Anthropic的几个关键特点：

1. 战略专注与执行力：自24年夏天后，公司只All-in Coding这一件事，并果断放弃了ToC。战略上非常自上而下（Top-down），目标高度一致，创始人也亲力亲为（hands-on）地参与技术和数据工作。

2. 文化与人才：团队非常稳定，人才流失少。员工普遍对AGI有近乎宗教般的信仰，创始人也善于传递这种信念。公司招聘时偏好“underdog”（不被看好但有潜力的人）而非行业大牛，且文化面试严格，会考察候选人对AGI实现后社会问题的看法。广密感觉其早期员工都是AGI使命驱动的。

3. 务实与集体主义：公司不神化某个技术环节（如预训练或RL）或个人，而是像一个工业化体系，踏实地把每个环节都做好。相比之下，OpenAI更像VC，喜欢创造概念并神化某些环节，导致摇摆不定。

4. 产品与模型结合：产品团队很多成员是懂模型的工程师和研究员，能高效地将模型能力转化为产品体验。例如，Claude Code的创始人本身就是顶尖程序员，他没有跟风做IDE，而是创造了终端（Terminal）形态的产品，认为这更能承接模型能力的指数级增长红利。

5. 创始人特质：CEO Dario Amodei和首席科学家Jared Kaplan都是物理学家出身，他们更倾向于从物理观察的角度理解和优化AI规律（如数据、架构、工程效率），而非执着于创造新范式。

关于护城河，广密认为取决于Coding本身的难度系数。虽然竞争激烈，但Anthropic仍有信心在现有范式下保持优势。他指出的一个风险是算力，由于需求爆发超出预期，算力规划可能偏保守，这成为实现千亿美金ARR的最大瓶颈。另一个特点是其高定价策略，专注于服务金字塔塔尖的用户群，这使其可以不计成本地把模型做得更大、效果最好，并保持高利润率。

最后，广密总结Anthropic的成功是“战略、产品专注和文化的胜利”。对于上市计划，他猜测可能在年底。谈及上市对员工的影响，他观察到，即便是最顶尖的AI研究员也普遍感到焦虑，担心一两年后工作被AI自动化，认为当下是他们最后的工作和赚钱窗口。

核心判断：Coding 是第二幕，也可能是 AGI 的“加速器”而非终点

广密把 AI 的产品演进分成三幕：Chatbot 负责对话，Coding Agent 负责干活，自动化 AI Researcher 负责提出和验证新知识。Coding 位于中间，不只是因为程序员愿意付费，而是因为它同时满足三个稀缺条件：代码覆盖数字世界的大量方案、执行结果可以被机器判断、失败后能快速重试和修复。

语言即世界

自然语言描述对象、意图与约束，覆盖开放世界的任务空间。

代码即方案

程序把方案变成可执行、可组合、可测试的数字对象。

Coding 即加速器

模型写数据、训练、评估和产品代码，进一步缩短 AI 自身的研究反馈。

Insight：Coding 的真正资产是可回放的失败代码仓库、Issue、Pull Request、测试和运行日志，把“哪里错了、如何改、是否修好”保存为可学习轨迹。模型公司如果只买更强的基模，却没有把失败轨迹回收到训练和产品，优势会很快被消耗。

进一步推演：这期季报留下的七条 Insight

  1. Coding 是验证器经济的首个大市场。 它的优势来自执行反馈，而非“知识工作天然适合模型”。下一个大市场应寻找同样短、可信、难以钻漏洞的闭环。
  2. Agentic Coding 是 AI 的二阶生产函数。 模型不只交付软件，也在生产数据管线、训练基础设施和评估环境；因此 Coding 领先可能会放大模型差距，但也会放大组织瓶颈。
  3. 组织焦点本身是一种技术资产。 在窗口快速轮换的行业里，能否让聪明人长期做数据、评估和脏活，可能比单个算法点子更决定交付速度。
  4. Harness 是管理学的机器可执行版本。 它把角色、流程、权限和复盘写进运行时；但若没有独立验收，它也会把组织盲点自动化。
  5. 模型 OS 只有在接口、身份、状态和结算同时稳定时才成立。 只有“模型很强”只说明有 kernel，不说明出现了操作系统生态。
  6. 生产率与就业不是同一条曲线。 顶尖使用者的效率可以上升几十倍，而 Junior 的学习机会同时下降；政策和企业必须把经验获得设计进新工作流。
  7. Token 是燃料表，不是生产率里程表。 真实账本必须把任务价值、返工、人工审查、延迟和尾部风险一起计入。

如何证伪这套叙事

  • 若在等成本和等人工监督下，Coding 反馈并不能带来跨领域研究加速，“AI 加速器”只是局部体验。
  • 若没有复杂 Harness，单一模型也能在真实长期任务中稳定交付，系统工程的相对价值会下降。
  • 若模型 OS 生态长期没有稳定接口、第三方应用和可替换性，“OS”只是平台营销比喻。
  • 若 Junior 岗位和学习路径并未下降，或新型学徒制迅速补上，关于经验阶梯断裂的担忧需要改写。
  • 若模型公司的公开审计收入、毛利和单位任务价值远低于 token 使用叙事，节目中的估值推演不成立。
