当前 _site/ 已在列表里，但仓库 实际仍包含 117 MB _site。原因可能是历史 commit 时期 .gitignore 尚未加上 _site，git 已经在跟踪这些文件，.gitignore 不会自动取消跟踪。

修复方向：git rm -r --cached _site/，再 commit；可选择保留 keep_files: [".git", ".svn"] 不影响 _site 跟踪。

_config.yml 残留

  • analytics 仍启用：google.tracking_id: G-CXPEJCV19X 与 compress_html.clippings: all，影响加载性能。
  • comments / staticman 残留：第 24-49 行的 comments 配置项实际无人调用，但会让 --safe 模式行为不一致。
  • exclude 名单过长：约 25 个路径逐个列入 exclude:，应当用 exclude: ["vendor", "node_modules", ...] 简写列表并改用 .gitignore 兜底。
  • plugins 与 whitelist 不一致：jekyll-paginate 既出现在 plugins 又出现在 whitelist，GitHub Pages 部署时不会重复加载，但容易让人误以为缺一不可。
  • Hawkins 插件：Gemfile 里有 hawkins，但 _config.yml 的 whitelist/plugins 都没有；属于配置漂移。

Gemfile 配置

  • 用 github-pages 而非直接 jekyll，导致本地 bundle exec jekyll serve 与 GH Pages 实际版本不易对齐。
  • 缺 .ruby-version；CI 走 setup-ruby@v1 ruby-version: '3.1'，本地无固定版本。

7跨文件 Heading ID 冲突（35 处）

问题

每个章节内部的二级/三级/四级标题使用自增 ID（如 h-0856），但编号器没有按文件隔离，导致 5 个不同章节里都出现 h-0862。TOC 锚点全部混乱：用户点 "h-0862" 会跳到不确定的某一章。

修复方向

  • 把全局自增 ID 改成 h-XXX-{filename} 文件局部命名空间。
  • 或：把 ID 改用 slugify(title)，让标题本身就是 ID（但需注意重复标题）。
  • 最佳实践：把 ID 写进 Jekyll/Liquid 模板而不是手工编号；用 {% include anchor heading="..." %} 类的方式管理。

8cite.py 算法效率与 CI 集成

当前实现

me = sch.get_author(2193557733)         # 仅 1 次
...
for i, line in enumerate(lines):        # 1 次
    for paper in me.papers:             # N × M 次 ❌
        if paper.paperId == paper_id:
            ...
with open('./_pages/about.md', 'w') as fp:
    file.writelines(lines)               # ❌ 不带原子写入

复杂度

  • 外层 about.md 行数 N（数十行），内层 author.papers 长度 M（数十到数百），最坏 O(N×M)。
  • 每次 CI 触发都拉取整本论文列表，并 for-loop 全文对比，浪费 Semantic Scholar API 配额。
  • 没有缓存、没有 dict 索引、没有"跳过未引用"优化。
  • file.writelines 直接覆盖原文件，如果中途异常会导致 about.md 损坏。

改进建议

# 建议写法
papers_by_id = {p.paperId: p for p in me.papers}  # 一次性建索引
new_lines = []
for line in lines:
    if line.startswith('[![citation]'):
        m = re.search(r'/([a-f0-9]{40})', line)
        if m and m.group(1) in papers_by_id:
            paper = papers_by_id[m.group(1)]
            line = re.sub(r'citation-\d+', f'citation-{paper.citationCount}', line)
    new_lines.append(line)

# 原子写入
tmp = './_pages/about.md.tmp'
with open(tmp, 'w') as fp:
    fp.writelines(new_lines)
os.replace(tmp, './_pages/about.md')

CI 集成

  • GitHub Actions 走 cron: '0 */4 * * *'，每 4 小时跑一次；Semantic Scholar 没有鉴权，单 IP 频繁调用会触发限流（429）。
  • 没有 commit 推送：脚本改完 about.md 但不 commit、不 push，下次构建又会被 git status 看到修改。
  • 没有 cache：每次拉全量 author 列表，浪费配额。
